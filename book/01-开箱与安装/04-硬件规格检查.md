# 04　硬件规格检查

## 完成结果

确认 CPU 型号、内存容量、存储容量和 GPU 型号与购买描述一致。

## 开始前需要准备什么

- 设备已开机，有操作系统界面（参考[第 3 章](03-第一次开机.md)）；
- 如果设备预装了 Ubuntu 或其他 Linux 系统，可以打开终端执行命令；
- 如果设备预装了 Windows，可以在 Windows 下通过任务管理器或 CPU-Z 查看，后续安装 Ubuntu 后再次核验；
- 订单确认页面截图或购买记录，作为对比依据。

## 在 Ubuntu / Linux 下查看硬件信息

打开终端（快捷键 `Ctrl+Alt+T` 或在应用菜单搜索 “Terminal”），执行以下命令：

**查看 CPU 型号**

```bash
grep -m1 "model name" /proc/cpuinfo
```

正常输出示例：

```
model name : AMD Ryzen AI Max+ 395
```

**查看内存容量**

```bash
free -h
```

正常输出示例（128 GB 设备）：

```
              total        used        free
Mem:          125Gi       ...
```

注意：操作系统显示的可用内存会比标称值略小（例如 128 GB 显示为约 125 GB），这是正常现象。如果显示低于购买描述的一半，需要核查。

**查看存储容量**

```bash
lsblk -d -o NAME,SIZE,MODEL
```

正常输出示例：

```
NAME   SIZE MODEL
nvme0n1  1T  Samsung SSD 990
```

**查看 GPU 型号**

```bash
lspci | grep -i vga
```

或：

```bash
lspci | grep -i display
```

正常输出示例：

```
... AMD/ATI ... Radeon RX ...
```

如果是 Max395，GPU 部分应当出现 AMD 或 Radeon 相关字样。

**汇总查看**

如果安装了 `neofetch` 或 `inxi`，可以一次性显示主要信息：

```bash
inxi -F
```

如果提示命令不存在，先用前面单独的命令查看即可。

## 在 Windows 下查看硬件信息

右键点击任务栏 → 任务管理器 → 性能选项卡：

- **CPU**：显示处理器名称和核心数；
- **内存**：显示总内存容量；
- **GPU**：显示显卡型号；
- **磁盘**：显示存储设备名称和容量。

Windows 显示的内存数字和实际安装容量一致（不扣除操作系统保留）。

将查看到的规格与购买订单上的描述逐项对照：

## 正常结果

CPU 为 AMD Ryzen AI Max+ 395，内存容量、存储容量与订单描述一致，GPU 含 Radeon 8060S 相关字样。

## 看到不同结果怎么办

**内存容量明显低于购买描述**（例如订单写 128 GB，但系统显示 60 GB 以下）：
- 重启一次再检查；
- 如果仍然不对，联系卖方。

**存储容量不对**：
- 确认 lsblk 输出了所有磁盘，可能设备有多块 SSD；
- 如果只有一块，且容量明显低于购买描述，联系卖方。

**CPU 型号不含 Max+ 395**：
- 部分型号用 “Ryzen AI Max 395” 或 “Ryzen AI Max+” 等近似字样，属正常；
- 如果显示的是完全不同的 CPU 系列，记录实际显示内容，联系卖方。

## 联系卖方前需要保存的信息

- 运行以上命令的终端截图；
- 订单页面截图；
- 型号和序列号（第 1 章已记录）。

## 完成检查

- CPU 型号与订单一致吗？
- 内存容量与订单一致吗？
- 存储容量与订单一致吗？
- GPU 含 AMD / Radeon 相关字样吗？
