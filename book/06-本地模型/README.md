# 06　本地模型

**完成结果**：手机上能和自己家的模型对话，别的程序能通过接口调用它，手上有一份这台机器的模型实测记录。

对应学习路线的进度 50。这一卷是全书的转折点：前五卷把环境铺好，从这一卷开始，这台机器真的在干活。

## 主线案例

**把这台机器变成全家或全公司的 ChatGPT。** 第 1 章到第 6 章就是这条线：看懂模型名字、下载、装 Ollama、装浏览器界面、手机连上、传文件提问。做到第 5 章，主线就算完成了。

第 7 章往后是按用途扩展，用得上哪个看哪个。

## 这一卷不给数字

全卷不写“这台机器能跑多快”“能供几个人用”这类结论。别人机器上的数字不是你的数字：整机散热、内存配置、模型、量化档、上下文长度，任何一项不同结果就不同。第 15、16 章给的是测法和空白表，测出来的数填进[第 4 卷第 16 章](../04-Max395硬件/16-设备基线.md)的设备基线。

模型仓库名、版本号这类会变的信息，正文都标了核验日期。动手当天以官方页面为准。
