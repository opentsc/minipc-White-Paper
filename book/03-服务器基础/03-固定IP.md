# 03　固定 IP

## 这一章的任务

让这台机器的地址不再变。

做完之后，第 2 章记下来的那个地址就是它长期的门牌号，写进笔记、写进脚本、存成浏览器书签都行，重启机器、重启路由器之后还是它。

两种做法，选一种做就够了。**推荐先试第一种**，改的是路由器，机器上什么都不动，没有把自己弄断网的风险。

## 开始前

- 第 2 章做完，手上有这台机器现在的地址；
- 用第一种做法要能登录路由器的管理页面，也就是要知道路由器的管理员密码，通常印在路由器机身的贴纸上；
- 用第二种做法要有 `sudo` 权限，并且**人在机器跟前**，显示器和键盘接着；
- 30 分钟。

## 新词

**DHCP**：路由器自动给设备分配 IP 地址的机制。设备接上网，喊一声“给我个地址”，路由器从自己的地址池里挑一个给它。你家里所有设备的地址都是这么来的。

**租约**（Lease）：DHCP 分给你的地址是有期限的，到期前设备会去续期。第 2 章 `ip a` 输出里的 `valid_lft 84521sec` 就是这个地址还剩多久到期。

**静态地址**（Static IP）：不通过 DHCP，由人指定、写死在设备上的地址。

**MAC 地址**：每块网卡出厂时带的编号，形如 `a1:b2:c3:d4:e5:f6`，六段十六进制。IP 地址会变，MAC 地址不变，路由器就是靠它认出“这台设备还是上次那台”。

**网关**（Gateway）：局域网通向外面的那个出口，也就是你的路由器。设备要访问局域网以外的东西，数据先交给它。

**子网掩码**：划定局域网范围的一个数值。家用网络几乎都是 `255.255.255.0`，写成 `/24` 是同一个意思，含义就是第 2 章说的“前三段一样的算一个网”。

**DNS**：把域名换成 IP 地址的服务。浏览器能用 `www.example.com` 而不用记一串数字，靠的是它。

## 地址为什么会变

DHCP 分配的地址是租来的，不是买断的。下面这几种情况都可能让它换一个号：

- 路由器重启或者断电来电，重新分配了一轮；
- 机器关机时间长了，租约到期，那个号被发给了别的设备；
- 家里同时在线的设备多了，分配顺序变了；
- 机器从网线换成 Wi-Fi，或者换到另一个路由器下面。

**地址一变，前面记下来的东西全部失效**：第 4 章用地址远程登录，连不上了；第 5 章传文件的命令，报的是找不到主机；浏览器里存的那个面板书签，打开是空白。而且这些都不会提前通知你，都是你要用的时候才发现。

所以固定地址不是讲究，是后面所有章节能不能长期用下去的前提。

## 两种做法怎么选

| 做法 | 改哪里 | 好处 | 代价 |
| --- | --- | --- | --- |
| 一、路由器里绑定 | 路由器的管理页面 | 机器上什么都不动，重装系统之后照样有效，不可能因为填错把机器弄断网 | 换路由器要重做一遍；少数路由器（多见于运营商送的那种）没有这个功能，或者被锁住 |
| 二、机器上设静态地址 | 这台机器自己的网络配置 | 不依赖路由器，路由器换了地址也不变 | 填错会当场断网；机器搬到别的网络环境要改回来；地址可能和路由器分配给别人的撞车 |

**先试第一种。** 路由器里找不到对应的菜单，再用第二种。

两种同时做也可以，但要保证两边填的是同一个地址，否则会互相打架，表现是时好时坏，很难查。

## 做法一、在路由器里绑定

### 第一步，拿到这台机器的 MAC 地址

在 Mini PC 上执行：

```bash
ip link
```

作用：列出所有网络接口，比 `ip a` 少了地址那部分。

输出里找 `enp` 开头那一段，下面一行是：

```
    link/ether a1:b2:c3:d4:e5:f6 brd ff:ff:ff:ff:ff:ff
```

`link/ether` 后面那串 `a1:b2:c3:d4:e5:f6` 就是有线网口的 MAC 地址，抄下来。

**有线和无线是两块网卡，MAC 地址不一样。** 你打算用网线就绑有线那个（`enp` 开头），用 Wi-Fi 就绑无线那个（`wl` 开头）。绑错了不会报错，只是不生效。

### 第二步，找到路由器的地址

```bash
ip route | grep default
```

输出一行，类似：

```
default via 192.168.1.1 dev enp2s0 proto dhcp src 192.168.1.23 metric 100
```

`via` 后面的 `192.168.1.1` 就是路由器，也就是网关。第二种做法也要用这个数字。

### 第三步，在路由器里绑定

打开浏览器，地址栏输 `http://192.168.1.1`，用管理员密码登录。

要找的菜单，各家叫法不同，常见的有这么几种写法：

- DHCP 服务器 → 静态地址分配；
- 地址保留；
- IP 与 MAC 绑定；
- 静态 DHCP、DHCP Reservation、Address Reservation。

多数路由器在这个页面上直接列出了当前在线的设备，能从列表里点选 Mini PC，MAC 地址和当前地址自动填好，这是最省事的走法。

**挑哪个地址**：

- 就用它现在这个地址最省事，认准了直接保存；
- 想换一个的话，避开 DHCP 的分配池。分配池的范围在同一个页面上通常看得到，家用路由器常见是 `192.168.1.100` 到 `192.168.1.199`。那就在池子外面挑，例如 `192.168.1.50`。挑在池子里面的话，可能被发给别的设备，撞车之后两台机器都上不了网。

填好保存。

### 第四步，让它生效

绑定不会立刻起作用，要等这台机器下一次去要地址。最快的办法是在 Mini PC 上把网线拔下来插回去，或者：

```bash
sudo reboot
```

开机之后确认：

```bash
hostname -I
```

显示的是你绑定的那个地址，就成了。

## 做法二、在机器上设静态地址

**改机器上的网络配置，填错一个数字就会把这台机器的网络整个断掉。** 正在用远程连着的时候改，会当场断开而且连不回去。所以这一节的操作要在机器跟前做，显示器和键盘接着——真断了，本地登录进去把配置改回来就行，两分钟的事。

动手之前先备齐三个数字：

- **地址**：你要固定的那个，例如 `192.168.1.50`。挑法和上面一样，避开 DHCP 分配池；
- **网关**：上面 `ip route | grep default` 查到的那个，例如 `192.168.1.1`；
- **DNS**：填网关地址就行，路由器会转发。想再加一个公共的，例如 `223.5.5.5`。

子网掩码填 `255.255.255.0`，等同于地址后面写 `/24`。

有桌面就用下面的图形界面，那条路退回去最容易。没装桌面的机器用后面的 netplan。

### 图形界面

1. 点右上角的状态菜单，选“设置”，左边选“网络”；
2. 找到“有线”那一项，点右边的齿轮图标；
3. 切到 **IPv4** 标签页；
4. 把“IPv4 方式”从“自动（DHCP）”改成“**手动**”；
5. 下面的“地址”那一行填三个格子：地址 `192.168.1.50`、子网掩码 `255.255.255.0`、网关 `192.168.1.1`；
6. 再下面的 DNS 那一行，把“自动”开关关掉，填 `192.168.1.1`。要填两个的话用逗号隔开；
7. 点右上角的“应用”。

设置完不会马上生效。回到“网络”页面，把“有线”那个开关**关掉再打开**，新配置就应用上了。

确认：

```bash
hostname -I
```

**填错了怎么退**：回到同一个页面，把“IPv4 方式”改回“自动（DHCP）”，应用，再把开关关掉打开。地址会重新变回路由器分配的那个，网络恢复。

### netplan

Ubuntu 用 netplan 描述网络配置，配置文件放在 `/etc/netplan/` 目录下。

```bash
ls /etc/netplan/
```

文件名各机不同，装了桌面的机器上常见 `01-network-manager-all.yaml`，服务器版常见 `50-cloud-init.yaml`。下面的命令里把文件名换成你看到的那个。

**先备份**：

```bash
sudo cp /etc/netplan/01-network-manager-all.yaml /etc/netplan/01-network-manager-all.yaml.bak
```

netplan 只读 `.yaml` 结尾的文件，`.bak` 结尾的它不会读，放在同一个目录里不影响。

打开编辑：

```bash
sudo nano /etc/netplan/01-network-manager-all.yaml
```

改成这样：

```yaml
network:
  version: 2
  renderer: NetworkManager
  ethernets:
    enp2s0:
      dhcp4: false
      addresses:
        - 192.168.1.50/24
      routes:
        - to: default
          via: 192.168.1.1
      nameservers:
        addresses: [192.168.1.1, 223.5.5.5]
```

四处要按你的机器改：

- **`renderer`** 保持文件里原来那一行不动。装了桌面的机器是 `NetworkManager`，服务器版是 `networkd`，改错了配置不生效；
- **`enp2s0`** 换成 `ip a` 里看到的接口名；
- **`192.168.1.50/24`** 是你要固定的地址，后面的 `/24` 别丢；
- **`192.168.1.1`** 两处，一处是网关，一处是 DNS，换成你的路由器地址。

`dhcp4: false` 是关掉自动获取，不写这一行的话它会一边自动要一边用静态的，结果不确定。

**YAML 用空格缩进，不能用 Tab 键**，每一层缩进两个空格。缩进错了 netplan 会直接报语法错误，不会应用，这一点上它是安全的。

按 `Ctrl+O` 回车保存，`Ctrl+X` 退出。

配置文件权限太松的话执行时会有一行警告，顺手收紧：

```bash
sudo chmod 600 /etc/netplan/01-network-manager-all.yaml
```

然后试着应用：

```bash
sudo netplan try
```

作用：应用新配置，然后停在那里等你按回车确认。**不按回车的话，默认 120 秒之后它自己还原成改之前的样子。** 配置写错把网断了，等两分钟就回来了，这是这一节最有用的一条。

网络正常、能确认没问题，按回车留下新配置，屏幕上出现 `Configuration accepted`。

有的环境下 `netplan try` 会提示不支持，那就用：

```bash
sudo netplan apply
```

这条没有自动还原，出问题要自己改回来。

**断网了怎么恢复**：接上显示器和键盘，在机器本地登录，把备份换回去：

```bash
sudo cp /etc/netplan/01-network-manager-all.yaml.bak /etc/netplan/01-network-manager-all.yaml
sudo netplan apply
```

## 验证

不管用哪种做法，做完都走一遍这四步。

**一、地址对不对**：

```bash
hostname -I
```

**二、能不能到路由器**：

```bash
ping -c 3 192.168.1.1
```

不通说明网关填错了。

**三、能不能出网、DNS 通不通**：

```bash
ping -c 3 223.5.5.5
ping -c 3 www.example.com
```

第一条通、第二条不通，说明网络是好的，DNS 那一项填错了，回去改 DNS。两条都不通，先看网关。

**四、重启之后还是不是它**：

```bash
sudo reboot
```

开机之后再执行一次 `hostname -I`。**这一步是真正的验收**，前面三步都过了但重启之后地址变回去，说明配置没有真的存下来。

最后回到笔记本上，用第 2 章的办法 `ping` 一次新地址，通了这一章就结束了。

**把这个地址记下来。** 记在笔记里、贴在机器上都行，第 4 章到第 10 章每一章都要用它。用新地址之后，第 2 卷[第 9 章](../02-Ubuntu/09-Docker.md)那个监控面板的访问地址也跟着变，浏览器书签记得改一下。

有哪一步做不出来，到[第 15 卷：故障排查](../15-故障排查/README.md)按症状查。

## 事实来源和版本日期

- netplan 配置文件的文件名和默认的 `renderer` 随 Ubuntu 版本和安装方式变化，以 `ls /etc/netplan/` 和你机器上文件里的实际内容为准；
- `netplan try` 不确认时的自动还原时间默认是 120 秒，可以用 `--timeout` 改；
- 路由器上绑定功能的菜单名称由各家厂商决定，本章列的是几种常见叫法，以你路由器上实际看到的为准；
- 本章核验日期：2026-08-14。
