# 08　第一个账户

## 完成结果

主账户已创建，能正常登录桌面，账户已加入 GPU 相关用户组，主机名已设置。

## 开始前需要准备什么

- Ubuntu 已安装，能进入桌面（参考[第 7 章](07-安装Ubuntu.md)）；
- 打开终端（快捷键 `Ctrl+Alt+T`）。

## 账户名和主机名的选择

安装过程中已经创建了一个账户。如果你在安装时已经设置好，这里直接确认即可。

**账户名规则**：

- 只用小写英文字母、数字和下划线；
- 不要用中文、空格或特殊符号；
- 例如 `roland` 或 `minipc_user`。

**主机名规则**（设备在局域网里的名称）：

- 只用小写英文字母、数字和连字符（减号）；
- 例如 `minipc-01` 或 `ai-station`；
- 主机名会显示在终端提示符里，建议取一个能区分设备的名字，方便后续管理。

## 查看当前账户名和主机名

打开终端：

```bash
whoami
```

显示当前账户名。

```bash
hostname
```

显示当前主机名。

## 修改主机名（可选）

如果你想修改主机名：

```bash
sudo hostnamectl set-hostname 新主机名
```

例如：

```bash
sudo hostnamectl set-hostname minipc-01
```

修改后需要重新打开一个终端才能看到提示符里的新名称。

## 加入 GPU 用户组

后续运行 AI 推理工具时，账户需要有权限访问 GPU 设备。执行以下命令把当前账户加入对应组：

```bash
sudo usermod -aG render,video $USER
```

执行后**需要注销并重新登录**，才能使权限生效。

验证是否已加入：

```bash
groups
```

输出应当包含 `render` 和 `video` 两个词。

## 确认 sudo 权限

确认账户有管理员权限（sudo）：

```bash
sudo whoami
```

输入密码后，输出应当是 `root`。如果提示 “user is not in the sudoers file”，参考“看到不同结果怎么办”。

## 账户设置完成后的状态

终端提示符应当类似：

```
roland@minipc-01:~$
```

其中 `roland` 是账户名，`minipc-01` 是主机名，`~` 表示当前在主目录，`$` 表示普通用户。

## 正常结果

能以设定的账户名登录，主机名已设置，账户已加入 `render` 和 `video` 组，有 sudo 权限。

## 看到不同结果怎么办

**groups 输出里没有 render 或 video**：
- 确认执行了上面的 `usermod` 命令；
- 注销后重新登录；
- 再次运行 `groups` 检查。

**sudo whoami 提示 “not in sudoers”**：
- 安装时创建的第一个账户通常自动有 sudo 权限。如果这个账户没有，说明安装时有问题；
- 重启进入恢复模式（Recovery Mode），在 root shell 里执行 `usermod -aG sudo 你的用户名`，然后重启。

**忘记密码**：
- 重启，在 GRUB 菜单选择 “Advanced options for Ubuntu” → 进入恢复模式 → root shell；
- 执行 `passwd 你的用户名` 设置新密码，重启。

## 完成检查

- `whoami` 输出的账户名是你设定的账户名吗？
- `hostname` 输出正确吗？
- `groups` 输出包含 `render` 和 `video` 吗？
- `sudo whoami` 输出 `root` 吗？
