# 商业产品交付手册

这里保存 6 套产品的交付结构。公开市场价格只用于观察，不作为本项目的统一报价。

| 产品 | 主要客户 | 收入环节 | 手册 |
| --- | --- | --- | --- |
| 预装本地 AI 工作站 | 没有本地 AI 运维人员的小团队 | 硬件、预装、培训、维护 | [查看](local-ai-appliance/README.md) |
| 企业私有知识库 | 律所、会计、咨询、研究团队 | 文档处理、RAG、权限、更新 | [查看](private-rag/README.md) |
| OCR 与文档抽取 | 财务、物流、合同和档案部门 | 流程分析、字段提取、系统接入 | [查看](document-ocr/README.md) |
| 企业内部 AI API | 有现有软件和云端调用的团队 | 接口迁移、路由、权限、监控 | [查看](local-api/README.md) |
| Agent 与 RPA | 有重复后台流程的团队 | 工作流、接口、审批、维护 | [查看](agent-rpa/README.md) |
