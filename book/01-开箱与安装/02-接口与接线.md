# 02　接口与接线

## 完成结果

主机已接好显示器、键盘、鼠标和网络，但还没有接电源。

## 开始前需要准备什么

- 显示器（带 HDMI 或 DisplayPort 或 USB-C 视频接口）；
- USB 键盘；
- USB 鼠标；
- 网线（推荐有线网络，安装系统时更稳定）或 Wi-Fi 环境；
- 主机包装里的电源适配器；
- 电源插座。

暂时不要插电源。先接好所有外设，再接电源。

## 接口说明

不同品牌的 Max395 Mini PC 接口位置和数量不完全相同。以下描述常见情况，对照实物找对应接口。

**视频输出接口**

显示器连接方式因型号而异：

- **HDMI 口**：矩形接口，较宽，两侧有小豁口。如果随机附带了 HDMI 线，直接使用；
- **DisplayPort（DP 口）**：比 HDMI 口小，一侧有斜角；
- **USB-C 口**：椭圆形，较小，部分型号支持通过 USB-C 输出视频。

> **注意**：不是所有 USB-C 口都支持视频输出。如果设备有多个 USB-C 口，只有标有 DisplayPort 或视频图标（带有 DP 字样）的那个支持视频。具体参考你的型号说明书。

先接显示器，确认接口匹配后再接线。如果显示器接口和主机不匹配，需要转接头（主机不附带）。

**USB 接口**

- 键盘和鼠标接 USB-A 口（矩形，较大）；
- 如果键盘或鼠标是 USB-C 接头，接 USB-C 口（不用于视频的那个）。

**网络接口**

- 网线接 RJ45 口（矩形，较 USB-A 口宽，通常有黄色或绿色指示灯）；
- 部分型号有两个网线口（例如 Beelink GTR9 Pro），只需接其中一个。

**电源接口**

- 电源适配器的圆形直流插头接主机背面或侧面的电源口；
- 另一端接墙壁插座，但先不要通电。

## 接线顺序

按照以下顺序接线：

1. 接显示器视频线；
2. 接键盘 USB 线；
3. 接鼠标 USB 线；
4. 接网线（如果使用有线网络）；
5. 电源适配器直流端接主机电源口；
6. 电源适配器另一端接插座，但暂时不要按开机键。

## 接线后的状态

- 显示器已连接主机，显示器电源已开启；
- 键盘、鼠标已插入；
- 网线已连接（如果使用有线网络）；
- 电源适配器已连接主机和插座，但主机还未开机。

## 正常结果

所有线缆插入到位，接口方向正确，没有强行插入或弯折。

## 看到不同结果怎么办

**接口不匹配**：不要强行插入，检查接口形状，确认是否需要转接头。

**USB-C 接显示器无信号**：确认该 USB-C 口是否支持视频输出。查看型号说明书，或尝试用 HDMI 口。

**不确定哪个口接什么**：对照型号说明书的接口图，或查找品牌官网的设备规格页面。

## 完成检查

- 显示器已接好，能用对应线缆连接主机和显示器吗？
- 键盘和鼠标已插入 USB 口？
- 网线已连接（或确认将使用 Wi-Fi）？
- 电源适配器已连接主机和插座，但主机还未开机？
