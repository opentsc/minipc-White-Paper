# 13　速度与准确率实测

## 这一章的任务

测出自己这套东西的真实水平。

**前十二章一个速度数字、一个准确率数字都没给。** 那不是漏了，是刻意的——[第 4 章](04-单张跑通.md)、[第 5 章](05-批量处理.md)、[第 7 章](07-错的怎么拦.md)、第 8 到第 10 章，每一章最后都写着同一句话：**要给客户一个数，按第 13 章那套办法在你自己的机器上测。**

**这一章就是那套办法。**

**它给的是两样东西：一套能重复跑的测法，和两张空白记录表。** 数字要你自己填，**因为那个数只可能是你自己那台机器在你自己那批材料上跑出来的。**

## 开始前

**先说清楚这一章和[第 7 卷第 17 章](../07-RAG/17-准确率验收.md)的分工，因为很多人会把这两件事当成一件。**

| | [第 7 卷第 17 章](../07-RAG/17-准确率验收.md)的验收 | 这一章的实测 |
| --- | --- | --- |
| 对象 | 那个知识库答得对不对 | **这条 OCR 流水线多快、多准** |
| 谁出题、谁定答案 | **客户出题，答案双方一起写** | **你自己标，客户不参与** |
| 什么时候做 | **交付那一次** | **跟客户谈之前** |
| 结果给谁看 | **双方签字，各存一份** | **你自己，不外发** |
| 进不进合同 | **进，是验收单的附件** | **不进，这一章最后一节专讲** |
| 材料换了怎么办 | 重新走一次验收 | **重测** |

**一句话：那一章是当着客户的面把一个项目结掉，这一章是关起门来把自己的底数摸清楚。**

**两件事的共同点只有一条，而且是最要紧的那一条：自己先测清楚，再跟客户谈。**

**所以那一章那套验收流程七步、不许承诺的三件事、人工计时对比怎么设计才公平，本章不重抄。** 本章只写 OCR 这边特有的测法，**以及人工计时对比在这个场景下要补的两条**。

**准备这些：**

- [第 5 章](05-批量处理.md)跑完，`out/` 里有一批 JSON，`ledger.csv` 在；
- [第 7 章](07-错的怎么拦.md)跑完，你知道这一批里可疑件有多少；
- **一批和客户实际材料同一类的单据。** 拿干净的样张测出来的数没用（[第 10 章](10-变体-旧档案批量数字化.md)那条“用真实扫描件跑”）；
- **机器上没有别的重活在跑**（[第 6 卷第 16 章](../06-本地模型/16-模型测试表.md)那五条测试纪律的第三条）；
- **半天到一天。** 速度那一半一个小时够了，**准确率那一半的时间全在人工标注上**。

## 新词

**中位数**：一串数从小排到大，**排在正中间的那一个**。[第 10 章](10-变体-旧档案批量数字化.md)那条“取中间那个数不取平均”说的就是它——**一份特别慢的会把平均数拽走，拽不动中位数**。

**标准答案**：**一份人工逐格标出来的、当成正确答案用的记录。** 准确率的全部意义在于和它比，**所以它自己必须是对的**。

**逐字段比对**：**一格一格地比，不是整张地比。** 这一章准确率那一半的核心口径。

**口径**：**判断“算对还是算错”的那条线定在哪儿。** `3,296.00` 和 `3296.00` 算不算一样，多一个空格算不算错——**这些要事先定死并且写下来**，不然两次测出来的数没法比。

**样本**：这次拿来测的那一批材料。**任何一个测出来的数，都只对这批样本成立**，本章最后一节专讲这件事。

## 一、速度怎么测

### 为什么要分成两段

**一份单据从进去到出来，中间是两件不同的事：**

```text
第一段　PDF 转成图片　　pdftoppm 干的活。吃 CPU，不碰模型
第二段　模型读那张图　　llama-server 干的活。吃 GPU，不碰 PDF
```

**只记一个总时间，你不知道慢在哪一段，也就不知道该调什么。**

**分开记之后，判断立刻变得直接：**

- **第二段占大头** —— 正常情况。要快就往模型和参数那边想（[第 6 卷第 16 章](../06-本地模型/16-模型测试表.md)）；
- **第一段占了不小的比例** —— **多半是 DPI 给高了或者页数给多了**。`--dpi 300` 转出来的图比 200 大一圈，转得慢、发得慢、模型读得也慢，**一个开关同时拖了两段**；
- **两段都不慢，但总时间很长** —— 看是不是第一份还含着模型加载（[第 6 卷第 7 章](../06-本地模型/07-多模型切换.md)）。

**[第 5 章](05-批量处理.md)那个批量脚本只打一份的总时间**，那是给你看进度用的，不是用来测的。**这一节这个脚本才是量尺。**

### 计时脚本

新建 `~/ai/scripts/ocr_timing.py`，**和前面几个脚本放在同一个目录里**（它要用 `ocr_one.py` 里的东西）。**照抄**：

```python
#!/usr/bin/env python3
# ocr_timing.py —— 跑固定份数，把 PDF 转图和模型识别两段分开计时
# 用法：python3 ~/ai/scripts/ocr_timing.py ~/ai/data/invoices-2026-08 --limit 20
# 前提：和 ocr_one.py 放在同一个目录里，第 2 章那个服务在跑
# 它只读原件、只发请求，不写任何结果文件

import argparse
import json
import statistics
import sys
import tempfile
import time
import urllib.error
from pathlib import Path

from ocr_one import (
    API_BASE, IMAGE_SUFFIXES, PROMPT, SCHEMA_FILE,
    detect_model, http_json, load_schema, response_format,
    to_data_uri, to_images,
)

DOC_SUFFIXES = IMAGE_SUFFIXES | {".pdf"}


def list_docs(indir):
    """这个目录和它的子目录里所有单据，按文件名排好序。"""
    found = [
        path for path in indir.rglob("*")
        if path.is_file() and path.suffix.lower() in DOC_SUFFIXES
    ]
    return sorted(found)


def read_prompt(prompt_path):
    """提示词从文件里读，不给就用 ocr_one.py 里那段发票的。"""
    if not prompt_path:
        return PROMPT
    return Path(prompt_path).expanduser().read_text(encoding="utf-8").strip()


def time_one(src, schema, api_base, model, prompt, dpi, max_pages, timeout):
    """一份单据，返回（转图秒数，识别秒数，页数）。"""
    with tempfile.TemporaryDirectory() as workdir:
        started = time.time()
        pages = to_images(src, dpi, max_pages, workdir)
        convert_spent = time.time() - started
        if not pages:
            raise RuntimeError("一页都没转出来")
        content = [
            {"type": "image_url", "image_url": {"url": to_data_uri(page)}}
            for page in pages
        ]
        content.append({"type": "text", "text": prompt})
        payload = {
            "model": model,
            "messages": [{"role": "user", "content": content}],
            "response_format": response_format(schema),
            "temperature": 0,
            "max_tokens": 2048,
        }
        started = time.time()
        answer = http_json(api_base + "/chat/completions", payload, timeout=timeout)
        model_spent = time.time() - started
    json.loads(answer["choices"][0]["message"]["content"])
    return convert_spent, model_spent, len(pages)


def line(name, values):
    """一行统计：份数、中位数、最短、最长、合计。"""
    if not values:
        return "%s 没有数据" % name
    return "%s  中位数 %.1f 秒　最短 %.1f　最长 %.1f　合计 %.1f" % (
        name, statistics.median(values), min(values), max(values), sum(values),
    )


def main():
    parser = argparse.ArgumentParser(description="OCR 两段分开计时")
    parser.add_argument("indir", help="放单据原件的目录")
    parser.add_argument("--api", default=API_BASE, help="第 2 章那个服务的地址")
    parser.add_argument("--model", default=None, help="模型名，不填就问服务要")
    parser.add_argument("--schema", default=str(SCHEMA_FILE), help="第 3 章那份 schema")
    parser.add_argument("--prompt", default=None, help="提示词文件，不填就用发票那段")
    parser.add_argument("--dpi", type=int, default=200, help="PDF 转图片的清晰度")
    parser.add_argument("--max-pages", type=int, default=2, help="每份最多读前几页")
    parser.add_argument("--timeout", type=int, default=600, help="每份最多等多少秒")
    parser.add_argument("--limit", type=int, default=20, help="跑前几份")
    parser.add_argument("--keep-first", action="store_true",
                        help="把第一份也算进统计。默认剔掉，因为它可能含模型加载")
    args = parser.parse_args()

    indir = Path(args.indir).expanduser()
    if not indir.is_dir():
        sys.exit("找不到这个目录：" + str(indir))

    schema_path = Path(args.schema).expanduser()
    if not schema_path.is_file():
        sys.exit("找不到 schema 文件：" + str(schema_path) + "，先做完第 3 章")
    schema = load_schema(schema_path)
    prompt = read_prompt(args.prompt)

    docs = list_docs(indir)[:max(1, args.limit)]
    if not docs:
        sys.exit("这个目录里没有找到 PDF 或者图片：" + str(indir))

    try:
        model = args.model or detect_model(args.api)
    except urllib.error.URLError as error:
        sys.exit("连不上服务（" + args.api + "）：" + str(error.reason))

    print("目录　　  %s" % indir)
    print("模型　　  %s" % model)
    print("DPI %d，每份最多 %d 页，一共跑 %d 份"
          % (args.dpi, args.max_pages, len(docs)))
    print("")

    converts = []
    models = []
    pages = []
    failed = 0

    for index, src in enumerate(docs, start=1):
        print("[%d/%d] %s" % (index, len(docs), src.name), end=" ", flush=True)
        try:
            convert_spent, model_spent, page_count = time_one(
                src, schema, args.api, model, prompt,
                args.dpi, args.max_pages, args.timeout,
            )
        except Exception as error:
            failed += 1
            print("失败：%s" % error, flush=True)
            continue
        print("转图 %.1f 秒，识别 %.1f 秒，%d 页"
              % (convert_spent, model_spent, page_count), flush=True)
        converts.append(convert_spent)
        models.append(model_spent)
        pages.append(page_count)

    if not converts:
        sys.exit("一份都没跑成，先按第 15 卷查")

    dropped = ""
    if not args.keep_first and len(converts) > 1:
        converts = converts[1:]
        models = models[1:]
        pages = pages[1:]
        dropped = "（第一份已剔除，它可能含模型加载）"

    totals = [a + b for a, b in zip(converts, models)]

    print("")
    print("--- 统计，一共 %d 份%s ---" % (len(totals), dropped))
    print(line("PDF 转图", converts))
    print(line("模型识别", models))
    print(line("一份合计", totals))
    print("一份平均 %.2f 页" % (sum(pages) / len(pages)))
    print("模型识别占一份合计的 %.0f%%" % (100 * sum(models) / sum(totals)))
    if failed:
        print("另有 %d 份没跑成，没算进上面的统计" % failed)
    print("")
    print("把上面几行抄进本章那张速度记录表，条件那几栏别留空。")


if __name__ == "__main__":
    main()
```

**这个脚本只读原件、只发请求，不写任何结果文件。** 它跑完 `out/` 里什么都不会多，**所以它不影响[第 5 章](05-批量处理.md)那个“跑过的跳过”**，随时可以重跑。

> **它没有用 `read_one`，而是把里面那几步拆开重写了一遍**——因为 `read_one` 把转图和请求包在一个函数里，**从外面量不到中间那条线**。这是这个脚本唯一一处和[第 5 章](05-批量处理.md)不一样的地方。

### 跑一次

```bash
python3 ~/ai/scripts/ocr_timing.py ~/ai/data/invoices-2026-08 --limit 20
```

**屏幕上是这样**（**下面所有的数都是 `x`，形状是真的，数字要你自己跑出来**）：

```text

[2/20] 票据-0731-019.pdf 转图 x.x 秒，识别 xx.x 秒，1 页
...
[20/20] 票据-0801-007.pdf 转图 x.x 秒，识别 xx.x 秒，2 页

把上面几行抄进本章那张速度记录表，条件那几栏别留空。
```

**跑二十份是个起点。** 太少了中位数不稳，太多了你不愿意重跑——[第 7 卷第 7 章](../07-RAG/07-评测问题集.md)那条“觉得重跑一遍太麻烦，那就是出多了”，在这里同样成立。

### 影响速度的五件事

**这五件里，任何一件变了，上一次测的数就不能直接拿来比。**

**一、页数。** 一页的和三页的差着一倍以上。**所以脚本把“一份平均几页”也打出来了**，两次测的这个数对不上，速度就没有可比性。

**二、DPI。** `--dpi 300` 比 200 慢，**而且两段一起慢**：图大了转得慢，视觉 token 多了读得也慢（[第 4 章](04-单张跑通.md)那个开关）。

**三、上下文长度。** 服务启动时 `-c` 给多少（[第 2 章](02-环境准备.md)），**这个数要记进记录表**。

**四、机器上同时还跑着什么。** Open WebUI 里有人在聊天、另一个批量任务在跑、浏览器开着几十个页面——**都会把这次的数拖歪**（[第 6 卷第 16 章](../06-本地模型/16-模型测试表.md)第三条纪律）。

**五、第一份含不含模型加载。** 服务刚起来的话，第一份要等模型读进内存（[第 6 卷第 7 章](../06-本地模型/07-多模型切换.md)）。**脚本默认把第一份剔掉了**，要连它一起算就加 `--keep-first`。

> **换模型、换量化档、升级 llama.cpp 之后要重测。** 判断标准和[第 4 卷第 16 章](../04-Max395硬件/16-设备基线.md)那份基线一样——**条件变了，旧记录不能直接拿来比。**

## 二、准确率怎么测

### 先说清楚这一节测的是什么，不测什么

**测的是**：**跑成功的那些单据里，每一格读对了没有。**

**不测的是**：**跑失败的那几份。**

**这两个是不同的数，不要混。** [第 5 章](05-批量处理.md)那个 `failed/` 里的是根本没读出来的，**它们连一格都没有，谈不上对错**。那一档要单独记一个数——**跑成功的份数除以总份数**，和准确率分开写。

**混在一起会出两种错**：把失败的算成“全错”，准确率会低得离谱；把失败的当不存在，你会漏掉“有一成材料这套东西根本处理不了”这个事实。**后面那种更危险。**

### 第一步，做一份标准答案

**这一步占这一节九成的时间，而且它决定了后面所有数字有没有意义。**

**先抽样。** 从跑成功的那一堆里**随机抽**，不要挑——[第 7 章](07-错的怎么拦.md)那条道理在这里更硬：**你自己挑，手会伸向看着眼熟的那几份。**

下面那个比对脚本自带一个抽样功能：

```bash
python3 ~/ai/scripts/compare.py ~/ai/projects/invoice-ocr ~/ai/projects/invoice-ocr/truth.csv --make 30
```

作用：**从台账里随机抽 30 份，出一张空表**，第一列是文件名，后面每一格都是空的，等人填。

**抽多少份，本教材不给建议值。** 要考虑的是两件事：**够不够代表这批材料**，以及**你愿不愿意真的一格一格标完**。标不完的样本量等于没有样本。

**然后填。** 照第一列的文件名打开原件，**一格一格照票面抄进去**。

**这一步有一条不能破的规矩：**

> **填标准答案的时候，不要看跑出来的结果。**

**这一条和[第 7 卷第 17 章](../07-RAG/17-准确率验收.md)那条“期望答案必须在跑之前写下来”是同一件事。**

那一章的理由在这里一字不改地成立：**先看结果再标答案，就变成了对着结果找理由**——它读成什么样，你的手就往哪儿靠。**双方都会不自觉地这么干，不是谁不诚实。**

**所以那个 `--make` 出来的是一张空表，不是把跑出来的结果填好让你改。** 这是刻意的。

**标注的口径要在开始之前定死，而且写进记录表：**

```text
□ 金额照票面写，还是去掉千位分隔符（本章的比对脚本按数值比，两种写法都算对）
□ 日期照票面原样写（第 3 章那段提示词要求的就是原样）
□ 票面上根本没有的格，标准答案填什么（本章的做法是留空，留空的格不参与比对）
□ 票面上有但人也看不清的格，算不算（本章的建议是当成“没有”，留空，另外记一笔有几格是这样）
```

**最后那一条要单独说。** 一格连人都认不出来，**拿它去考机器没有意义**，但它本身是个重要的数——**这批材料里有多少格是人也看不清的**，这个数直接决定了你该不该接这一单（[第 9 章](09-变体-物流单与表格件.md)那条“先看样张再报价”）。

### 第二步，按字段统计，不按张统计

**这是这一节的核心口径。**

一张发票有八个字段。**错一个，不等于整张废：**

- **购买方名称少两个字** —— 这一行照样能用来对账，**改一格就好了**；
- **价税合计错一位** —— **这一行不能用**。

**把这两种情况都算成“一张错”，你得到的数没有任何指导作用。**

**按字段统计之后，表上会直接告诉你两件事：**

- **哪一格最容易错。** 集中在某一格，**那不是准确率问题，是回[第 3 章](03-定义字段.md)改提示词的问题**；
- **错的那几格要不要紧。** 全集中在“发票种类”上，和全集中在“价税合计”上，**是完全不同的两件事**。

> **整张全对的份数也值得看一眼，但它是附带的。** 本章那个脚本会把它打出来，**记录表上也留了一栏**，但正经的口径是那张按字段的表。

### 比对脚本

新建 `~/ai/scripts/compare.py`，**照抄**：

```python
#!/usr/bin/env python3
# compare.py —— 拿人工标好的标准答案，逐字段比一遍跑出来的结果
# 用法：
#   先出一张空表：python3 ~/ai/scripts/compare.py ~/ai/projects/invoice-ocr truth.csv --make 30
#   填完之后比对：python3 ~/ai/scripts/compare.py ~/ai/projects/invoice-ocr truth.csv
# 前提：第 5 章跑完，out/ 里有一批 JSON，同一个目录里有 ledger.csv

import argparse
import csv
import json
import random
import sys
from pathlib import Path

KEY_COLUMN = "文件名"

# 台账里这几列不是识别出来的，不参与比对
SKIP_COLUMNS = {"处理时间", "明细行数"}

# 这几格按数值比，3,296.00 和 3296.00 算一样。别的格一个字都不能差
NUMBER_FIELDS = {
    "金额", "税额", "价税合计",
    "数量", "单价", "合计数量", "合计金额",
}


def clean(text):
    """两头的空白去掉，别的一个字不动。"""
    return str(text if text is not None else "").strip()


def as_number(text):
    """把票面上的金额变成一个数。变不了就返回 None。"""
    cleaned = text.replace(",", "").replace("，", "")
    cleaned = cleaned.replace("¥", "").replace("￥", "").replace("元", "")
    cleaned = cleaned.replace(" ", "")
    if cleaned == "":
        return None
    try:
        return float(cleaned)
    except ValueError:
        return None


def same(field, want, got):
    """这一格算不算对。改了这里的口径，要记进准确率记录表。"""
    if field in NUMBER_FIELDS:
        left = as_number(want)
        right = as_number(got)
        if left is not None and right is not None:
            return abs(left - right) < 0.005
    return want == got


def read_ledger(outdir):
    """台账的表头就是要比的那几列，第一列是每一份的文件名。"""
    ledger = outdir / "ledger.csv"
    if not ledger.is_file():
        sys.exit("找不到台账：" + str(ledger) + "，先做完第 5 章")
    with ledger.open("r", newline="", encoding="utf-8-sig") as handle:
        rows = [row for row in csv.reader(handle) if row]
    if len(rows) < 2:
        sys.exit("台账里一行数据都没有：" + str(ledger))
    header = rows[0]
    fields = [
        name for name in header
        if name != KEY_COLUMN and name not in SKIP_COLUMNS
    ]
    names = [row[0] for row in rows[1:]]
    return fields, names


def make_truth(outdir, truth_path, count):
    """出一张空的标准答案表：随机抽几份，每一格留空，等人照原件填。"""
    if truth_path.exists():
        sys.exit("这个文件已经有了，不覆盖：" + str(truth_path))
    fields, names = read_ledger(outdir)
    picked = sorted(random.sample(names, min(count, len(names))))
    with truth_path.open("w", newline="", encoding="utf-8-sig") as handle:
        writer = csv.writer(handle)
        writer.writerow([KEY_COLUMN] + fields)
        for name in picked:
            writer.writerow([name] + [""] * len(fields))
    print("从台账 %d 行里随机抽了 %d 份，空表写在：%s"
          % (len(names), len(picked), truth_path))
    print("下一步：照第一列的文件名打开原件，一格一格照票面填。")
    print("填之前不要去看跑出来的结果，理由见本章那一节。")


def read_truth(truth_path):
    """把填好的标准答案读进来。"""
    with truth_path.open("r", newline="", encoding="utf-8-sig") as handle:
        reader = csv.DictReader(handle)
        names = reader.fieldnames or []
        if KEY_COLUMN not in names:
            sys.exit("标准答案里没有 %s 这一列，现在的表头是：%s"
                     % (KEY_COLUMN, names))
        fields = [
            name for name in names
            if name != KEY_COLUMN and name not in SKIP_COLUMNS
        ]
        rows = {}
        for row in reader:
            key = clean(row.get(KEY_COLUMN))
            if key:
                rows[key] = row
    return fields, rows


def compare(outdir, truth_path):
    """逐字段比一遍，出两张表：按字段的统计，和不一样的那些格。"""
    json_dir = outdir / "out"
    if not json_dir.is_dir():
        sys.exit("找不到这个目录：" + str(json_dir) + "，先做完第 5 章")
    fields, truth_rows = read_truth(truth_path)
    if not truth_rows:
        sys.exit("标准答案里一行都没有：" + str(truth_path))

    stats = {
        name: {"比了": 0, "一样": 0, "不一样": 0, "答案空着": 0}
        for name in fields
    }
    diffs = []
    missing = []
    checked = 0
    all_right = 0

    for key in sorted(truth_rows):
        target = json_dir / (Path(key).stem + ".json")
        if not target.is_file():
            missing.append(key + "：out/ 里没有它的 JSON")
            continue
        try:
            record = json.loads(target.read_text(encoding="utf-8"))
        except ValueError as error:
            missing.append(key + "：JSON 读不出来，" + str(error))
            continue
        checked += 1
        row_right = True
        for field in fields:
            want = clean(truth_rows[key].get(field))
            got = clean(record.get(field))
            if want == "":
                stats[field]["答案空着"] += 1
                continue
            stats[field]["比了"] += 1
            if same(field, want, got):
                stats[field]["一样"] += 1
            else:
                stats[field]["不一样"] += 1
                row_right = False
                diffs.append([key, field, want, got])
        if row_right:
            all_right += 1

    diff_path = outdir / "diff.csv"
    with diff_path.open("w", newline="", encoding="utf-8-sig") as handle:
        writer = csv.writer(handle)
        writer.writerow(["文件名", "字段", "标准答案", "读出来的"])
        writer.writerows(diffs)

    stat_path = outdir / "accuracy.csv"
    with stat_path.open("w", newline="", encoding="utf-8-sig") as handle:
        writer = csv.writer(handle)
        writer.writerow(["字段", "比了", "一样", "不一样", "答案空着"])
        for field in fields:
            item = stats[field]
            writer.writerow([
                field, item["比了"], item["一样"],
                item["不一样"], item["答案空着"],
            ])

    print("标准答案 %d 份，比上了 %d 份" % (len(truth_rows), checked))
    for note in missing:
        print("  没比：" + note)
    print("")
    print("字段 | 比了 | 一样 | 不一样 | 答案空着")
    for field in fields:
        item = stats[field]
        print("%s | %d | %d | %d | %d" % (
            field, item["比了"], item["一样"],
            item["不一样"], item["答案空着"],
        ))
    print("")
    print("每一格都对的份数 %d（附带看一眼，正经口径是上面那张按字段的表）" % all_right)
    print("按字段的统计写在：%s" % stat_path)
    print("不一样的那些格写在：%s" % diff_path)
    print("")
    print("这几个数只对这批样本、这个模型、这段提示词、这个 DPI 成立。")


def main():
    parser = argparse.ArgumentParser(description="逐字段比对标准答案")
    parser.add_argument("outdir", help="第 5 章那个放结果的目录")
    parser.add_argument("truth", help="标准答案 CSV 放哪儿")
    parser.add_argument("--make", type=int, default=0,
                        help="出一张空的标准答案表，抽这么多份")
    args = parser.parse_args()

    outdir = Path(args.outdir).expanduser()
    truth_path = Path(args.truth).expanduser()
    if args.make > 0:
        make_truth(outdir, truth_path, args.make)
        return
    if not truth_path.is_file():
        sys.exit("找不到标准答案：" + str(truth_path)
                 + "，先用 --make 出一张空表并填完")
    compare(outdir, truth_path)


if __name__ == "__main__":
    main()
```

**这个脚本不连服务、不读模型**——它只读 `out/` 里那堆 JSON 和你填的那张表，**和[第 7 章](07-错的怎么拦.md)那个 `validate.py` 是同一类东西**。

### 怎么看这张表

**跑完不是看那个数字，是看哪一格错了。** [第 7 卷第 7 章](../07-RAG/07-评测问题集.md)那句话在这里一字不改。

**打开 `diff.csv`，按“字段”那一列排一次序**，同一格的错会挨在一起。然后按这三档分：

- **错的集中在某一格** —— **回[第 3 章](03-定义字段.md)改提示词。** 提示词里关于那一格的那句话没说到位。改完把整批重跑，**再用同一份标准答案比一遍**；
- **错的散在各格，而且原件都很糊** —— **调 `--dpi 300` 重跑一批试试**（[第 4 章](04-单张跑通.md)那个开关）。**代价是速度，回上半章重测一次**；
- **错的散在各格，原件也很清楚** —— 这一档最难办，**多半要换模型或者换量化档**（[第 6 卷第 16 章](../06-本地模型/16-模型测试表.md)）。

**然后是那条不能破的规矩**：**一次只动一个，动完把整批重跑、重比一遍**（[第 7 卷第 6 章](../07-RAG/06-切分与检索调优.md)那条，[第 7 卷第 7 章](../07-RAG/07-评测问题集.md)复述过一遍，在这里第三次成立）。

**改完之后用的还是同一份标准答案，一个字不改。** 换一批样本就没法和上一轮比了，**而且你会怀疑自己是不是抽到了简单的那一批。**

## 三、人工计时对比，这一章只补两条

**[第 7 卷第 17 章](../07-RAG/17-准确率验收.md)那一节“人工计时对比怎么设计才公平”给了五条，照做，本章不重抄。**

**那五条在 OCR 场景里一条都不改**：题目从已有的里挑不另出、人工那边给他平时用的全部工具、找最熟的人比、两边同时开始记在同一张纸上、**机器这边要把核对那一步算进时间**。

**这一章要补的是那第五条在 OCR 上的具体形态，以及一条 OCR 特有的。**

**补充一：机器这边的时间，要把复核队列算进去。**

那一章说的是“点开引用、翻到原文对一眼”，**在这一卷对应的是打开 `review.csv`、照第三列去看那几行原件、改 JSON、重跑**（[第 7 章](07-错的怎么拦.md)那个五步流程）。

**这一步是必须做的，就必须计时。** 不算它，这个对比是假的——**而且是那种客户用两个月之后才会发现的假。**

**补充二：人工那一边的活是“看着单据敲进表格”，不是“核对”。**

**这一条容易搞混，搞混了对比就歪了。**

- **人工那一边**：从零开始，看着单据把八格敲进 Excel。**这是客户现在真实在做的事**；
- **机器这一边**：跑完，加上复核那几行，加上抽检。

**两边的产出要是同一样东西**——一张填好的表。**不能拿“机器跑完”和“人工敲完加自己复核一遍”比**，人工那边敲完本来就还要自己看一遍。

> **那一章那条“允许人工赢几道”在这里也成立。** 三五份单据的时候，人工敲完可能真的更快——**机器要启动、要加载、要走完整套流程**。**这种照实记下来**，它反而增加可信度，**而且它顺带告诉你这个客户的量够不够。**

## 四、这三件事必须写清楚

**这一节是本章最硬的一节。上面所有东西都是方法，这一段是纪律。**

### 一、这个数只对这批样本有效

**测出来的每一个数——速度也好，准确率也好——只在四样东西全部不变的前提下成立：**

```text
这批材料　　这个模型与量化档　　这个 DPI 与提示词　　这台机器当时的状态
```

**四样里任何一样变了，那个数就不是那个数了。**

**理由和[第 5 卷第 19 章](../05-驱动与ROCm/19-后端选择.md)、[第 6 卷第 16 章](../06-本地模型/16-模型测试表.md)那条是同一条**：别人机器上的数字不是你的，**你上个月的数字也不一定是你这个月的。**

### 二、样本换了要重测

**这一条是上一条的直接后果，但它值得单独说，因为它是最常被跳过的一条。**

**换客户要重测。** 上一家的发票是激光打印的电子发票，这一家是复写纸的第二联（[第 9 章](09-变体-物流单与表格件.md)那条），**两边的数差得远。**

**同一个客户换一批材料也要重测。** 他这次给的是去年的旧档，**纸的状况和上次不一样**（[第 10 章](10-变体-旧档案批量数字化.md)那五样）。

**做法很省事**：这一章那两个脚本跑一遍，加上标注那一段。**第一次测慢，之后每次快得多**——脚本现成，流程现成，只有标注要重来。

### 三、不许把这个数写进合同当承诺

**这一条最重要，也最容易在客户追问的那一刻被破掉。**

**[第 7 卷第 17 章](../07-RAG/17-准确率验收.md)那一节“不承诺准确率百分比”的三条理由，在这里一条不少地成立**，而且 OCR 这边还多一条：

**客户以后拿来跑的材料，不是你测的这批。** 你测的是他给你的样张，**他以后会往里丢什么，你管不了**——歪的、糊的、复印了三代的、手写批注满页的。

**那你拿什么跟客户谈？**

**拿[第 7 章](07-错的怎么拦.md)那三句话，加这一章测出来的两样东西的用法：**

- **速度那个数可以说，但要带着条件说。** “我在我这台机器上，拿您给我的那三十份，测下来一份大概多少秒”——**这是一句关于过去的陈述，不是一句关于未来的承诺**。而且要紧跟一句：**“您那批材料如果和这三十份不一样，这个数要重测。”**
- **准确率那个数不说。** 不说数字，说边界——**校验拦得住什么、拦不住什么、抽检怎么做、抽多少由您定。**

> **可以照念的一段：**
>
> “准确率我不给数字，因为它兑现不了——您以后丢进去什么材料我管不了。我给您的是另一样东西：算不平的、缺格的、格式不对的，一份都跑不掉，全会挑到一张表上等您看。剩下那一类它读成了另一个看着也正常的值，机器拦不住，靠抽检，抽多少您定，写进验收单。”
>
> **这一段就是[第 7 章](07-错的怎么拦.md)那三句话，一个字都没变。** 这一章测出来的那些数，**是让你自己心里有底地说出这段话，不是让你把数报出去。**

**验收怎么走、验收单怎么签、责任怎么划，在[第 13 卷](../13-项目交付/README.md)。本章不给合同条款，也不给法律意见。**

## 五、测完并进设备基线

**这一步照[第 6 卷第 16 章](../06-本地模型/16-模型测试表.md)那套做，本章不重讲基线表的结构。**

**那一章的做法是：模型测试表整张单独存，基线里只放一行。** 这一章同理——**两张记录表整张单独存，[第 4 卷第 16 章](../04-Max395硬件/16-设备基线.md)那份基线里只加几行。**

**加在基线表第八组“跑模型满载”那一段下面：**

| 基线里加这一行 | 从本章哪儿来 |
| --- | --- |
| OCR 模型与量化档 | 速度记录表条件那一段 |
| OCR 服务的 -c | 同上 |
| OCR 一份合计的中位数（秒） | 速度记录表结果那一段 |
| 其中模型识别占几成 | 同上 |
| 测这个数用的 DPI 与页数 | 同上 |
| 这一批材料是什么 | 速度记录表最上面那一栏 |

**只加这几行，不要把整张表塞进基线。** [第 6 卷第 16 章](../06-本地模型/16-模型测试表.md)说过理由：**基线要的是一组固定条件下的对照值，不是一张选型表。**

**准确率那张表不进基线。** 它和这台机器的状态没关系，**它是关于材料和提示词的**——**跟着项目走，不跟着机器走。**

**还有一件事照[第 4 卷第 16 章](../04-Max395硬件/16-设备基线.md)那条规矩办**：这两张表存两份，**机器上一份，机器之外一份**，旧的不要删。
