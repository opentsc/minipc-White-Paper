# 04　账户与权限

## 这一章的任务

给家人或同事建一个受限账户。

做完之后，登录界面上多一个用户。他能用这台机器、能在自己的家目录里存东西，但装不了软件、改不了系统设置、也进不去你的文件。你自己那个管理员账户不受影响。

顺带认识文件权限——`ls -l` 输出里那串横杠和字母怎么读，怎么改成你要的样子。

## 开始前

- 用[第 1 卷第 8 章](../01-开箱与安装/08-第一个账户.md)建的管理员账户登录，那个账户已经有 `sudo` 权限，这一章不重新建它；
- 想好新账户给谁用、账户名叫什么（小写英文字母，例如 `lily`）；
- 一个给他用的初始密码，建好之后让他自己改；
- 20 分钟。

## 新词

**root**：系统里权限最高的账户，能改任何文件、停任何服务。Ubuntu 默认把它锁着，不能直接登录，所有管理员操作都通过 `sudo` 临时借用它的权限。

**用户组**（Group）：一组账户的集合。权限经常按组来给，加进某个组就一起拿到那个组的权限。[第 1 卷第 8 章](../01-开箱与安装/08-第一个账户.md)把你的账户加进 `render` 和 `video` 两个组，就是为了让它能访问 GPU。

**sudo 组**：一个特殊的组，加进去的账户就有管理员权限。判断一个账户是不是管理员，看它在不在这个组里。

**属主和属组**（Owner / Group）：每个文件和目录都记着一个属主（哪个账户的）和一个属组（哪个组的）。系统靠这两项加上权限位，决定谁能读、谁能写。

## 建账户

```bash
sudo adduser lily
```

把 `lily` 换成你要的账户名。

这条命令是交互式的，会依次问几件事：

```
正在添加用户'lily'...
正在添加新组'lily' (1001)...
正在添加新用户'lily' (1001) 到组'lily'...
创建主目录'/home/lily'...
新的 密码：
重新输入新的 密码：
```

- 输密码时屏幕上**不显示任何字符**，连星号都没有，这是正常的，照打就是；
- 密码之后会问全名、房间号、工作电话、家庭电话、其他，这几项直接回车跳过；
- 最后问 `这些信息是否正确？ [Y/n]`，输入 `Y` 回车。

一条命令做了 3 件事：建账户、建家目录 `/home/lily`、建一个同名的用户组 `lily`。

确认建好了：

```bash
ls -ld /home/lily
```

能列出这个目录，说明账户和家目录都在。

老教程里还有一条 `useradd`。那是底层命令，不建家目录也不问密码，用它建出来的账户往往登录之后一片混乱。本教材统一用 `adduser`。

## 要不要给他 sudo

**给了 `sudo` 就等于给了整台机器的控制权。** 有 `sudo` 的账户能装任何软件、删掉任何人的文件、改系统配置、停掉正在跑的服务，包括你的模型服务。

判断标准很简单：这台机器由你负责，就不给。对方需要自己装软件、自己管服务，并且清楚会影响到谁，才给。

不给的话，什么都不用做——`adduser` 建出来的账户默认就没有 `sudo`。

要给的话：

```bash
sudo usermod -aG sudo lily
```

`-aG` 里的 `a` 是追加的意思。别漏掉它，只写 `-G` 会把这个账户原有的组全部替换成你列出的那些，之前加的 `render`、`video` 之类会一起丢掉。

给完之后要**注销重新登录**才生效。

想收回：

```bash
sudo gpasswd -d lily sudo
```

作用是把 `lily` 从 `sudo` 组里移出去，账户本身还在。

查看某个账户在哪些组里：

```bash
groups lily
```

输出是一串组名。里面有 `sudo` 就是管理员，没有就不是。

## 切换账户

**图形界面**：点右上角状态菜单，展开你的账户名，选“切换用户”，回到登录界面选新账户登录。两个人的桌面各自留着，切回来的时候程序还开着。

**终端里**：

```bash
su - lily
```

作用是在当前终端里临时变成 `lily`。要输入 `lily` 的密码。执行后提示符会变成 `lily@主机名`，之后所有命令都以他的身份执行。`-` 这个短横线表示连他的环境变量和家目录一起切过去，不加的话人切了但还停在你的目录里。

回到自己：

```bash
exit
```

用途上，图形切换适合真的换个人来用，`su -` 适合你想验证一下“他登录进来会看到什么”。

## 让他看不到你的文件

新账户默认进不去你的家目录还是能进去，取决于系统版本的默认设置，先看一眼：

```bash
ls -ld /home/*
```

输出类似：

```
drwxr-x--- 18 roland roland 4096  8月14日 10:22 /home/roland
drwxr-x---  3 lily   lily   4096  8月14日 11:05 /home/lily
```

看每行开头那串字符的最后 3 位。是 `---` 就已经关好了，别人进不来；是 `r-x` 说明其他账户能进你的家目录看文件。要关上：

```bash
chmod 750 /home/你的账户名
```

改自己的家目录不需要 `sudo`。执行完再 `ls -ld` 看一次，最后 3 位应该变成了 `---`。

`750` 是什么意思，下一节讲。

## 读懂 `ls -l` 那串字符

```bash
ls -l ~/ai
```

输出：

```
drwxr-xr-x 2 roland roland 4096  8月14日 10:22 models
-rw-r--r-- 1 roland roland  128  8月14日 10:25 note.txt
```

开头那 10 个字符是关键。

**第 1 个字符是类型**：`d` 是目录，`-` 是普通文件，`l` 是链接。

**后面 9 个字符分成 3 组，每组 3 位**，依次是属主能干什么、属组里的人能干什么、其他所有人能干什么。

每组的 3 位固定是 `r`、`w`、`x` 的顺序，有权限就显示字母，没有就显示横杠：

- `r` 读。对文件是能看内容，对目录是能列出里面有什么；
- `w` 写。对文件是能改、能删，对目录是能在里面新建和删除文件；
- `x` 执行。对文件是能当程序运行，对目录是**能进去**（`cd` 进去）。目录没有 `x`，就算有 `r` 也用不了。

再看中间那两个名字，第一个是属主，第二个是属组。

把上面的例子读一遍：`-rw-r--r--` 是一个普通文件，属主 `roland` 能读能写，`roland` 组里的人和其他人只能读。`drwxr-xr-x` 是一个目录，属主能读能写能进，其他人能读能进但不能在里面新建东西。

## 用 `chmod` 改权限

权限用数字写更快。`r` 是 4，`w` 是 2，`x` 是 1，一组里有哪几样就把数字加起来。3 组就是 3 个数字。

日常够用的就 4 个：

- **`644`**：属主能读能写，别人只能读。普通文件的常规设置；
- **`755`**：属主能读能写能执行，别人能读能执行。目录和脚本用这个；
- **`600`**：只有属主能读能写，别人连看都不行。密钥、密码、含个人信息的文件用这个；
- **`700`**：只有属主能进能改。私人目录用这个。

用法：

```bash
chmod 600 ~/ai/scripts/api-key.txt
```

```bash
chmod 755 ~/ai/scripts/backup.sh
```

改完用 `ls -l` 看一眼，那串字符应该跟着变了。

改自己的文件不需要 `sudo`。**一个文件要加 `sudo` 才能改，说明它不属于你**，先弄清楚它是谁的、为什么要改，再动手。

## 用 `chown` 改属主和属组

你用管理员账户往新账户的家目录里放了一批资料，这批文件的属主还是你，他能看不能改。把属主转给他：

```bash
sudo chown -R lily:lily /home/lily/data
```

- 冒号前面是属主，后面是属组，这里两个都改成 `lily`；
- `-R` 表示连同子目录和里面所有文件一起改；
- 改别人的文件需要 `sudo`。

改完让他登录进去试着新建一个文件，能建出来就是对了。

## 删除账户

```bash
sudo deluser lily
```

删掉账户，`/home/lily` 这个家目录留着。

```bash
sudo deluser --remove-home lily
```

**这条连他的家目录一起删掉，里面的文件全部消失，没有回收站。** 删之前先把要留的东西复制到别的地方，或者先用上一条不带 `--remove-home` 的版本，确认没有人再要那些文件，过些天再手动清理。

有哪一步做不出来，到[第 15 卷：故障排查](../15-故障排查/README.md)按症状查。

## 完成检查

- 登录界面上能看到新建的账户吗？
- 用新账户登录，能在自己的家目录里新建文件吗？
- 用新账户执行一条 `sudo` 命令，如果你没打算给他管理员权限，是不是被拒绝了？
- `ls -ld /home/*` 输出里，你自己家目录那一行最后 3 位是 `---` 吗？
- `-rw-r--r--` 这一串，你能说出属主、同组、其他人分别能干什么吗？
- `600` 和 `755` 分别用在什么文件上？
