# 02　终端

## 这一章的任务

用命令把第 1 章的事再做一遍。

再拿一批资料，这次不碰鼠标：在终端里建目录、从 U 盘复制文件、改名、挪位置、核对结果。做完之后 `ai/data` 下面多一个批次目录，里面是这次复制进来的文件。

图形界面和命令做的是同一件事，改动的是同一个硬盘上的同一批目录。这一章结束时你会亲眼看到这一点——第 1 章用鼠标建的 `ai` 目录，在终端里用 `ls` 一样能列出来。

- 30 分钟。

## 新词

**shell**：终端窗口里真正接收和执行命令的那个程序。你在终端里打字，字交给 shell，shell 看懂了再去让系统干活。Ubuntu 默认的 shell 叫 bash。

**当前目录**（Working Directory）：shell 现在停在哪个目录。所有不写完整路径的命令，都是相对当前目录去找东西。换目录用 `cd`，下面就讲。

**选项**：跟在命令后面、用来改变命令行为的短标记，通常以一个或两个减号开头，例如 `ls -l` 里的 `-l`。同一条命令加不同选项，输出不一样。

**Tab 补全**：打了开头几个字母之后按一下 `Tab` 键，shell 自动把剩下的补齐。名字打错是新手最常见的失败原因，能补全就不要手打。

**通配符**：`*` 代表任意一段文字。`*.pdf` 表示所有以 `.pdf` 结尾的文件。

## 打开终端，看懂提示符

按 `Ctrl+Alt+T`，终端窗口打开。也可以按 `Super` 键搜“终端”。

窗口里第一行是提示符，大概长这样：

```
roland@minipc-01:~$
```

拆开看：`roland` 是账户名，`@` 后面的 `minipc-01` 是主机名（这两项在[第 1 卷第 8 章](../01-开箱与安装/08-第一个账户.md)设过），冒号后面的 `~` 是当前目录，`$` 表示你是普通用户。

`~` 这个符号就是你的家目录。刚打开终端时人在家目录，所以显示 `~`。换到别的目录，`$` 前面的这一段会跟着变。

## 我在哪

```bash
pwd
```

作用：打印当前目录的完整路径。

正常输出：

```
/home/roland
```

`roland` 换成你自己的账户名。这一行和提示符里的 `~` 是同一个地方，`~` 是它的简写。

## 这里有什么

```bash
ls
```

作用：列出当前目录下的文件和子目录。

正常输出（家目录下）：

```
ai  公共  模板  视频  图片  文档  下载  音乐  桌面
```

第一个 `ai` 就是你第 1 章用鼠标建的那个目录。后面几个是系统自带的目录，终端里显示的是中文名还是 `Documents` 这类英文名，取决于安装时选的语言，两种都正常。

想看得更细：

```bash
ls -l
```

作用：一行一个，同时显示权限、属主、大小和修改时间。这串信息第 4 章会用到，现在只要知道去哪儿看。

```bash
ls -lh
```

`-h` 让大小显示成 `4.0K`、`1.2G` 这种可读格式，不加就是一长串字节数。

```bash
ls -a
```

`-a` 连隐藏文件一起列出来，也就是第 1 章按 `Ctrl+H` 看到的那些点号开头的目录。

选项可以合起来写，`ls -lah` 等于同时加 `-l`、`-a`、`-h`。

## 换个地方

```bash
cd ai
```

作用：进入当前目录下的 `ai` 目录。执行完提示符会变成 `~/ai$`。

再执行一次 `pwd`，输出变成 `/home/roland/ai`。执行 `ls`，列出的是你建的 5 个子目录。

几个常用写法：

- `cd ..` 回到上一级目录，`..` 就是“上一级”；
- `cd ~` 回家目录，不管现在在哪；
- `cd` 后面什么都不写，效果和 `cd ~` 一样；
- `cd ~/ai/data` 一步跳到 `data`。

打目录名时用 `Tab`。输入 `cd mo` 再按 `Tab`，shell 会补成 `cd models/`。按一下没反应，说明以这几个字母开头的东西不止一个，再按一下会把候选列出来。

## 路径的三种写法

同一个 `data` 目录，可以这样写：

- **`/home/roland/ai/data`**：从根目录 `/` 开始写全，在任何位置执行都指向这里；
- **`~/ai/data`**：`~` 是家目录的简写，等价于上一条，短很多，本教材主要用这种写法；
- **`data`** 或 **`./data`**：从当前目录出发，只有当前目录正好是 `ai` 的时候才对。

路径里某一段带空格，把那一段用引号包起来：

```bash
cd ~/ai/data/"2026-08 发票"
```

不加引号的话，shell 会把空格当成分隔符，认为你在说两个不同的东西，然后报找不到文件。

引号不要把 `~` 一起包进去。`~` 写在引号里就不再是家目录的简写，shell 会当成一个真的叫 `~` 的目录去找，然后报错。带空格的目录名本来就麻烦，这也是本教材约定目录名只用小写英文的原因。

## 建目录

先回到 `data`：

```bash
cd ~/ai/data
```

建一个批次目录：

```bash
mkdir manuals
```

作用：在当前目录下建一个名叫 `manuals` 的目录。执行成功没有任何输出，这是正常的——命令行里“没有消息”通常就是“做成了”。

用 `ls` 确认它出现了。

想一次建出好几层：

```bash
mkdir -p ~/ai/data/2026-08/invoice
```

`-p` 的作用是路上缺哪一层就补哪一层。不加 `-p` 的话，`2026-08` 还不存在，命令会直接报错。

## 从 U 盘复制过来

插上 U 盘，先找到它在系统里的位置。U 盘挂载在 `/media/你的账户名/` 下面，目录名就是 U 盘的卷标：

```bash
ls /media/$USER/
```

`$USER` 是一个变量，shell 执行时自动换成你的账户名。输出是一行 U 盘的卷标，例如 `KINGSTON`。

看看 U 盘里有什么：

```bash
ls /media/$USER/KINGSTON/
```

把 `KINGSTON` 换成你实际看到的卷标。这个名字如果带空格，整个路径要加引号。

复制整个目录：

```bash
cp -r /media/$USER/KINGSTON/manuals ~/ai/data/
```

- 作用：把 U 盘上的 `manuals` 目录整个复制到 `~/ai/data/` 下面；
- `-r` 表示连同里面的子目录一起复制。复制目录必须加 `-r`，不加只会报一句“忽略目录”；
- 正常输出：没有输出。文件多的时候会等几秒到几分钟；
- 只想要其中一类文件，用通配符：`cp /media/$USER/KINGSTON/*.pdf ~/ai/data/manuals/`，这条只复制 U 盘根目录下的 PDF 文件。

**`cp` 遇到同名文件会直接覆盖，不问你一句。** 目标目录里已经有同名文件时，加上 `-i`：

```bash
cp -ri /media/$USER/KINGSTON/manuals ~/ai/data/
```

`-i` 的意思是每遇到一个要覆盖的文件就停下来问一次，输入 `y` 覆盖，`n` 跳过。

## 改名和挪位置

`mv` 一条命令干两件事，区别只在目标写法。

改名：

```bash
mv ~/ai/data/manuals ~/ai/data/product-manuals
```

目标是一个还不存在的名字，效果就是把目录改名。

挪位置：

```bash
mv ~/ai/data/report.pdf ~/ai/projects/
```

目标是一个已经存在的目录，效果就是把文件挪进去，原位置不再有这个文件。

**`mv` 同样会覆盖同名文件，也不提示。** 同名文件有可能被盖掉的时候，加 `-i`。

## 核对结果

看这批文件复制过来几个、占多大：

```bash
ls ~/ai/data/product-manuals | wc -l
```

`|` 是管道符，把左边命令的输出交给右边继续处理；`wc -l` 数一共几行。输出是一个数字，就是文件个数。

```bash
du -sh ~/ai/data/product-manuals
```

`du` 统计目录占用，`-s` 只给总数，`-h` 可读格式。输出类似 `356M	/home/roland/ai/data/product-manuals`。

把这两个数字和 U 盘上的对一遍，对得上就是复制完整了。核对完弹出 U 盘：

```bash
udisksctl unmount -b /dev/sda1
```

设备名 `/dev/sda1` 要换成你自己的，不确定就回到图形界面点侧栏那个三角形，效果一样。**弹出之后才可以拔。**

## 删除不在这一章

命令行里的删除没有回收站，`rm` 删掉的东西不经过“已删除”目录，直接没有。日常清理请在“文件”里做右键删除，那条路进回收站，删错了还能拿回来。

## 回头看一眼

在终端里执行 `ls ~/ai`，列出的 5 个目录，就是第 1 章用鼠标建的那 5 个。打开“文件”看 `ai/data`，这一章用命令建的批次目录也在里面。两边操作的是同一个硬盘上的同一批目录，只是入口不同。

有哪一步做不出来，到[第 15 卷：故障排查](../15-故障排查/README.md)按症状查。

## 完成检查

- `pwd` 能输出当前位置，`cd ~/ai` 之后再执行 `pwd`，输出跟着变了吗？
- 用 `mkdir` 建的批次目录，在“文件”里能看到吗？
- U 盘的资料已经用 `cp -r` 复制进 `ai/data` 下的批次目录了吗？
- `ls | wc -l` 数出来的文件个数，和 U 盘里的对得上吗？
- `~/ai/data`、`/home/你的账户名/ai/data` 这两种写法指向同一个地方，你清楚为什么吗？
- `cp` 和 `mv` 碰到同名文件会怎么样，加哪个选项能让它先问一句？
