# 演示脚本（模板）

对应教材[第 10 卷第 2 章](../../../book/10-产品化/02-打包一个演示.md)。断网那一段的完整做法在[第 7 卷第 9 章](../../../book/07-RAG/09-断网演示.md)。

**用法**：另存成 `演示脚本.md` 再填，别改这个原件。填完把括号里的说明删掉。

**四段的时间是 2／5／5／3 分钟，顺序不能换。** 第三段最长是刻意的——**演示里唯一有效的是他自己动手的那一段。**

---

## 空表

```text
========== 演示脚本（15 分钟）==========
案例：　　　　　　　　　　　（填你要演的那一个，一个场子只演一个）
客户：　　　　　　　　　　　（公司名；练习场写“虚构”）
演示日期：　　　　在哪儿演：　　　　　（他办公室 / 你这儿）
用的是谁的数据：　　　　　　（客户给的 / 公开的 / 自己造的，标虚构没有）
谁在场：　　　　　　　　　　（用的人要在，能拍板的人也要在）

---------- 第一段　先问他要什么（2 分钟）----------
问的三句（照念）：
  1.
  2.
  3.
他答完记在这儿：

（这三条记下来，第二段照他的话演，不照你原来准备的那套）

---------- 第二段　你演一遍（5 分钟）----------
动作 1：　　　　　　　　　　照念的话：
动作 2：　　　　　　　　　　照念的话：
动作 3：　　　　　　　　　　照念的话：

（最多三个动作。多了你记不住，也一定超时）
本案例的当场效果排在第几个动作：　　（放动作 2 或 3，不要放第一个）

---------- 第三段　把手交给他（5 分钟）----------
交给他的是什么：　　　　　　（键盘 / 鼠标 / 一叠他自己的材料 / 那个文件夹）
让他做几次：　　　　　　　　（不少于三次）
他卡住的时候你怎么接：　　　（只说下一步按哪儿，不要接过键盘）
他问出你答不了的怎么答：　　（“这个我回去查了给您准信”，不要现编）

---------- 第四段　断网证明（3 分钟）----------
断哪几样：　　　　　　　　　（网线 / 无线 / Tailscale，三样都要）
谁来断：　　　　　　　　　　（他来断。这一条不让步）
断完让他验什么：　　　　　　（他自己挑一个今天没打开过的网址）
断网之后演哪一段：　　　　　（见下面那张表，不是每个案例都一样）
演完谁把网接回去：　　　　　（当着他的面接回去，不要留一台断网的机器）

---------- 收尾（30 秒）----------
最后一句照念的话：
留下的东西：　　　　　　　　（一页说明书 / 一张验收单样表）
约的下一步：　　　　　　　　（什么时候、做什么、谁准备什么）

---------- 自己掐表走一遍 ----------
走的日期：　　　　　用了多少分钟：
超时的是哪一段：　　删掉了哪个动作：
断网那一段走通没有（是 / 否）：
========================================
```

## 各案例的当场效果和断网那一段

| 案例 | 当场效果是哪一下 | 断网之后演什么 |
| --- | --- | --- |
| **私有知识库** | 点开引用，让他自己翻到原文那一段 | 让他出一道新题，答案和引用照常出来 |
| **发票台账** | 一叠单据变成一张表那一下 | 再跑一批，台账照样出来 |
| **抓取日报／工作流** | 明天早上自己出现的那一份 | **换个演法**：不演抓取（它本来就要联网），只演摘要那一步 |

**第三行是最容易演砸的一处。** 抓取那一步断了网就是一个报错，**断网要证的是模型在本地，不是这条流程不用网。** 照念的一句：

> “抓网页当然要网，那是去外面拿东西。您的内容交给谁看，才是这台机器自己在做的——现在网是断的，它照样在摘。”

---

## 三条禁忌

```text
一、不演没跑通的　　　　　　“这个其实也能做，我给您比划一下”——这句话不要说
二、不演需要你救场的　　　　中间要你把键盘拿回来的那一步，不该在脚本里
三、不当场改代码　　　　　　出错就照实说、记下来、接着往下走
```

出错时照念：

> “这一处不对，我记一下，回去改完给您准信。咱们接着看下一段。”

## 填好的样子（虚构示例）

**下面这一份是虚构示例。** 客户、人名、数据和对话全部虚构，不对应任何真实的人和公司。

```text
========== 演示脚本（15 分钟）==========
案例：　　发票台账
客户：　　远岭机械（虚构）
演示日期：2026-08-20　　在哪儿演：他办公室
用的是谁的数据：客户上周给的 12 份，演完当天删并出书面确认
谁在场：出纳（每天在录票的那个人）、财务主管（能拍板的）

---------- 第一段　先问他要什么（2 分钟）----------
问的三句（照念）：
  1. “您这边一个月大概多少张票？”
  2. “现在是谁在录、录进哪儿？”
  3. “录错了通常是错在哪一格？”
他答完记在这儿：一个月三百多张；出纳录进一个 Excel；
　　　　　　　　最常错的是价税合计和开票日期

---------- 第二段　你演一遍（5 分钟）----------
动作 1：把那 12 份拖进收件文件夹　　照念：“东西就丢这儿，别的不用管。”
动作 2：打开跑出来的台账　　　　　　照念：“这一叠现在是一张表了。”
动作 3：打开复核那张表　　　　　　　照念：“这两张它算不平，挑出来了，等人看。”
本案例的当场效果排在第几个动作：动作 2

---------- 第三段　把手交给他（5 分钟）----------
交给他的是什么：他自己柜子里再抽的几份，和键盘
让他做几次：三次以上
他卡住的时候你怎么接：只说“拖到这个文件夹里”，不接键盘
他问出你答不了的怎么答：“这个我回去查了给您准信。”

---------- 第四段　断网证明（3 分钟）----------
断哪几样：网线、无线、Tailscale
谁来断：财务主管自己拔
断完让他验什么：他自己挑一个今天没打开过的网址
断网之后演哪一段：再跑一遍刚才那几份，台账照样出来
演完谁把网接回去：我，当着他的面

---------- 收尾（30 秒）----------
最后一句照念的话：“网您随时可以自己再拔一次，就这两下。”
留下的东西：一页说明书
约的下一步：下周三他给我一批上个月的真票，我跑完把台账发回来

---------- 自己掐表走一遍 ----------
走的日期：2026-08-18　　用了多少分钟：18
超时的是哪一段：第二段　　删掉了哪个动作：原来的动作 4（看 Excel 里求和）
断网那一段走通没有：是
========================================
```

## 演示前过一遍

```text
□ 1. 你自己完整走过一遍，包括断网那一段，一步不落
□ 2. 演示数据准备好了，来路和虚构标注都清楚
□ 3. 三个动作定死了，写在脚本上，不超过三个
□ 4. 断网那一段这个案例怎么演，事先定了
□ 5. 演示前十分钟随便问一句，让模型热起来
□ 6. 演完怎么把网接回去，你心里有数
```

**第 1 条是核心。断网之后出的错，你当场没法查，因为查也要上网。**
