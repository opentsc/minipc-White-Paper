# 07　安装 Ubuntu

## 完成结果

Mini PC 安装好 Ubuntu，可以正常登录桌面。

## 开始前需要准备什么

- 第 6 章制作好的 Ubuntu 安装 U 盘；
- Mini PC 已接好显示器、键盘、鼠标和电源；
- 网络连接（有线或 Wi-Fi）；
- 约 1 小时的操作时间。

> **⚠️ 安装 Ubuntu 会清空 Mini PC 硬盘上的所有内容。** 如果设备上有任何需要保留的数据，先备份到外部存储设备。安装过程不可逆。

## 第一步：调整 BIOS 设置

不同品牌的 BIOS 界面不同。进入 BIOS 的按键和选项名称因品牌而异，下面分品牌说明。

### 进入 BIOS

开机后，在出现品牌 Logo 的瞬间，快速连续按对应按键：

| 品牌 | 常见进入 BIOS 的按键 |
| --- | --- |
| GMKtec EVO-X2 / EVO-X3 | `Del` 或 `F2` |
| Beelink GTR9 Pro | `Del` 或 `F2` |
| Framework Desktop | `F2` 或按住电源键等待提示 |
| HP ZBook Ultra G1a | `F10` 或 `Esc` |
| 其他品牌 | 通常是 `Del`、`F2` 或 `F12` |

如果第一次没进去，重启再试。不同设备窗口期不同，有些需要在 Logo 出现后 1 秒内开始按。

### 调整 UMA 内存设置

进入 BIOS 后，找到显存或显示内存的分配设置。**不同品牌的选项名称不同**：

- **GMKtec / Beelink**：通常在 Advanced → GFX Configuration 或 UMA Frame Buffer Size，设置为最低值（通常是 512 MB 或 2 GB）；
- **Framework Desktop**：通常在 Advanced → AMD CBS → NBIO → GFX Configuration → UMA Frame Buffer Size；
- **HP ZBook Ultra**：通常在 Advanced → Video Configuration → UMA Frame Buffer；
- **其他品牌**：在 Advanced 或 Chipset 菜单下查找含有 “UMA”、“iGPU Memory”、“Integrated Graphics Memory” 或 “VRAM” 字样的选项。

将该值设置为**最低可选值**（常见是 512 MB；如果最低只有 2 GB，选 2 GB）。

> **为什么这样设置**：这个值只是 BIOS 保留的静态显存。设置低一些，后续 Ubuntu 运行时可以通过内核参数动态分配更多内存给 GPU 来运行大模型。如果设置过高，会减少可用的系统内存，且不会带来实际收益。

### 确认启动模式

确认 BIOS 启动模式为 **UEFI**（而不是 Legacy/CSM）。通常在 Boot 菜单里可以找到这个选项。大多数新机器默认已经是 UEFI 模式。

### 保存退出

按 `F10` 保存并退出（或找到 Save & Exit 选项）。设备会重启。

## 第二步：从 U 盘启动

重启时，插入 Ubuntu 安装 U 盘，然后进入启动设备选择菜单。

**进入启动选择菜单的按键**（因品牌而异）：

| 品牌 | 常见按键 |
| --- | --- |
| GMKtec / Beelink | `F7` 或 `F12` |
| Framework Desktop | `F12` |
| HP ZBook Ultra | `F9` |
| 其他品牌 | 通常是 `F12` 或 `Esc` |

在启动选择菜单里，选择你的 U 盘（通常显示品牌名称或 “UEFI” + U 盘品牌字样）。

如果没有出现 U 盘选项，检查 U 盘是否插好，或者进入 BIOS 确认 USB 启动未被禁用。

## 第三步：进入 Ubuntu 安装程序

从 U 盘启动后，显示器出现 Ubuntu Logo，然后进入安装程序。

1. 选择语言（中文或英文均可）；
2. 选择安装方式：选 **“安装 Ubuntu”**（不是“试用”）；
3. 键盘布局：按默认或选择对应键盘，点击继续；
4. 网络：如果使用有线网络，此时应已自动连接；如果使用 Wi-Fi，这里可以选择 Wi-Fi 网络并输入密码；
5. 更新和其他软件：选 **“正常安装”**，勾选 **“安装 Ubuntu 时下载更新”** 和 **“安装第三方软件”**。

## 第四步：分区

> **⚠️ 这一步会清空 Mini PC 硬盘上的所有内容。确认已备份。**

安装程序会询问安装类型：

**选择“清除整块磁盘并安装 Ubuntu”**。

程序会显示将要格式化的磁盘名称（通常是 `/dev/nvme0n1`）。确认是 Mini PC 的内置 SSD，不是你的 Ubuntu 安装 U 盘。

> 如果不确定哪个是正确的磁盘，回到上一步，或在安装程序的其他选项里查看磁盘容量，选容量和购买 SSD 一致的那个。

确认后点击 **“现在安装”**，弹出确认对话框再次确认，点击“继续”。

## 第五步：完成基本设置

分区和安装文件期间，程序会询问：

- **时区**：选择你所在的时区；
- **账户设置**：这一步会在第 8 章详细说明，这里先按程序提示填写。

## 第六步：等待安装完成

安装文件复制通常需要 10-30 分钟，取决于 SSD 速度。进度条走完后，程序提示 **“安装完成，需要重启”**。

**重启前拔出 U 盘**，然后点击“立即重启”。

## 重启后

重启后，显示器出现 Ubuntu 登录界面（输入你在安装时设置的密码）。登录后能看到 Ubuntu 桌面，说明安装成功。

## 正常结果

重启后进入 Ubuntu 登录界面，输入密码后显示桌面。

## 看到不同结果怎么办

**开机后仍然进入旧系统（Windows 或进入 BIOS）**：
- 确认 U 盘已经拔出；
- 进入 BIOS，确认启动顺序，把 SSD 排在第一位；
- 保存退出。

**安装程序卡在某个步骤超过 30 分钟**：
- 确认网络连接正常（如果勾选了下载更新，慢网络会拖慢进度）；
- 如果卡住超过 1 小时，长按电源键关机，重新从 U 盘启动安装，这次安装时先不勾选“安装时下载更新”。

**安装完成重启后黑屏**：
- 等待 1-2 分钟，有时 GPU 驱动首次加载较慢；
- 如果超过 3 分钟还是黑屏，参考第 12 章硬件问题处理。

**提示磁盘错误或安装失败**：
- 重启从 U 盘再次进入安装程序；
- 在分区步骤选“手动分区”，删除旧分区，重新建立 EFI 和根分区，再安装；
- 如果仍然失败，记录错误信息，参考第 12 章或联系卖方。

## 联系卖方前需要保存的信息

- 安装失败时的错误提示截图；
- 安装的 Ubuntu 版本；
- 操作步骤描述（到哪一步失败的）。

## 完成检查

- 重启后进入了 Ubuntu 登录界面吗？
- 输入密码后能看到桌面吗？
- U 盘已经拔出了吗？
