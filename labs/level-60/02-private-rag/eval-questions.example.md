# 评测问题集（模板）

这份是骨架，**里面的题、期望答案、文件名和数字全部是虚构的示例**，用来说明每一栏该怎么填。**一道都不要直接用**——按你自己那批文件重出二十道。

对应教材[第 7 卷第 7 章](../../../book/07-RAG/07-评测问题集.md)。跟客户一起做验收的时候照[第 17 章](../../../book/07-RAG/17-准确率验收.md)那套流程走。

用法：

```bash
cp eval-questions.example.md eval-questions.md
```

**填过的那一份里有客户的真实问题和真实答案，它本身就是客户资料，不要外发、不进 Git。**

## 出题的规矩

- **四类各五道，一类都不能少。** A 类单份文件里直接找得到、B 类要综合几份、C 类库里根本没有、D 类容易混淆。
- **出题的人必须知道答案。** 你自己读过那批文件，或者让天天回答这些问题的人来出。
- **A 类挑有数字、有天数、有条件的。** “某某流程是怎样的”这种不要出，**正确答案说不清楚，你判不了对错**。
- **C 类那五道从教材第 7 卷第 5 章那张测试表搬过来，不重新出。** 优先挑“像有其实没有的”。
- **B 类里故意留一两道它答不好的**（要通读全库才能答的那种）。留着有用：你自己心里有数，演示的时候你主动说出来。
- **D 类出不满五道很正常。** 出几道算几道，别硬凑。
- **期望答案要在跑之前写好**，双方都看过。跑完再写就变成了对着结果找理由。
- **题集出好之后就别改了。** 要加题，加在后面，编号往下续，**已有的题一个字都不动**。

## 表头

```text
库名：____________________      题集版本：v____
测试日期：______年__月__日      测试人：____________
本次改动：（这次动了什么。什么都没动就写“无”）
____________________________________________________
```

**“本次改动”那一栏别留空。** 三个月后你翻出五张表，只有这一栏能告诉你中间发生过什么。

## 记分

```text
三个格子全是 √ 的：____ / 20

不合格的题号：____________________________________
```

**这个数只在你这个库、这批文件、这套题上成立。** 换一批文件、换一组题、换一个模型，它就不是这个数了。**不要把它当成这套系统的准确率写进任何对外材料。**

## 不合格的题怎么记

每道不合格的题，先做同一件事：**点开引用，看它检索到了什么。** 然后按教材第 7 卷第 6 章那三种情况分。

```text
题号____  引用点开是（对/不对），回答是（对/不对） → 情况____
题号____  引用点开是（对/不对），回答是（对/不对） → 情况____
题号____  引用点开是（对/不对），回答是（对/不对） → 情况____

下一步动作（只写一条，一次只动一个）：
____________________________________________________
```

- **引用里的片段就不对** → 情况一，检索的问题。从换问法开始，最后才动片段大小。
- **片段是对的，回答错了** → 情况二，模型的问题。**别去动切分参数**，加强提示词或者换对话模型。
- **片段对，但漏了一份文件** → 情况三，召回不够。先把 Top K 调大试试。

**改完把整张表重跑一遍**，不是只跑上次错的那几道。

## 验收的时候多记两样

跟客户一起做验收时，除了上面这张表，还要记这两项（教材[第 7 卷第 17 章](../../../book/07-RAG/17-准确率验收.md)）。

```text
断网演示
  断网方式：（拔网线 / nmcli networking off / 两样都做）
  断网之后问了几道：____  答案和引用正常的有几道：____
  客户自己验证过网确实断了：（是 / 否）

人工计时对比
  题目从哪几道里挑的：____________________
  人工那边是谁（熟不熟这批文件）：____________________
  人工用的工具：（文件夹 / 搜索 / 纸质本 / 问同事）
  两边各用多长时间（机器这边要把点开引用核对那一步算进去）：
  ____________________________________________________
  人工赢的题号：____________________
```

**记下来的是这几道题、这批文件、这个客户、这一次的结果，不是任何普适结论。** 不要转成倍数拿去做宣传。

## 剔除的题

客户出的题里，总会有几道的答案根本不在他给的那批文件里。**当场剔除，记在这儿，单独给他一张单子。**

```text
题号____  剔除理由：（答案不在文件里 / 正确答案说不清楚，判不了对错）
题号____  剔除理由：
```

**这张单子对客户是有价值的**——它告诉他哪几件天天被问的事，公司里根本没有白纸黑字的规定。
