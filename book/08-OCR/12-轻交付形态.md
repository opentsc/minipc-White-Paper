# 12　轻交付形态

## 这一章的任务

不装机器，只收文件出数据。

**前面十一章默认了一件事：客户有一台机器。**

**这一章把这个默认拿掉。** 客户什么都不买、什么都不装，**他把文件发给你，你在自己这台机器上跑完，把台账发回去。**

**这是一种更轻的做生意方式**，轻在三处：

```text
客户那一边　不用买机器，不用装环境，不用派人学
你这一边　　不用上门，不用远程，不用管别人机器上出的毛病
两边合起来　可以从三十份单据开始，不用从一个项目开始
```

**代价也有三处**，本章后半段专讲。**先说清楚这一章的立场**：轻交付不是整机交付的简版，**它是另一个形态，有自己适合的客户和自己的天花板。**

## 开始前

- [第 5 章](05-批量处理.md)和[第 7 章](07-错的怎么拦.md)做完，台账和复核队列都跑得出来；
- [第 11 章](11-对接.md)读过，**知道客户拿到台账之后要往哪儿放**；
- 有一个愿意先发三十份单据给你试试的人。**没有也能读，这一章的东西是提前定好规矩用的**；
- 本章不写代码，**要写的是几条规矩和两份文字**；
- 60 分钟。

## 新词

**轻交付**：**不交付机器，只交付结果。** 本章说的这个形态。**它是这本书里第一个不需要客户那边有设备的形态。**

**加密压缩包**：**打包的时候设一个口令，没有口令解不开。** 收客户文件用的就是它。

**有效期链接**：网盘生成的那种分享链接，**过了时间自己失效**，也可以随时手动撤掉。

**校验和**：**一段文件算出来的一串字符**，文件差一个字节，这串就完全不同。**它用来确认“你收到的和他发出的是同一份东西”。** 这一卷用 `sha256sum`。

**交接单**：**一张写清楚“什么时候收到什么、什么时候交回什么、什么时候删掉什么”的纸。** 这一章的核心产出之一。

**删除确认**：**做完之后你出具的一份书面说明**，写清楚删了什么、什么时候删的。**这一章另一个核心产出，而且是这个形态里最值钱的一张纸。**

## 这个形态是什么

**一句话：客户发文件，你发结果。**

完整的一轮是这样：

```text
1. 客户把一批扫描件打包发给你
2. 你解开，放进自己机器上一个只属于这个客户的目录
3. 跑第 5 章那套，出台账
4. 跑第 7 章那套，出复核队列
5. 该复核的复核完
6. 台账、复核队列和一页说明，打包发回去
7. 到约定的时间，把这批东西从你机器上删干净
8. 出一份删除确认给客户
```

**第 7 步和第 8 步是这个形态的正主。** 前面六步是干活，**后面两步是这门生意能不能做第二次的原因。**

**技术上一个新东西都没有。** 用的还是 `ocr_batch.py` 和 `validate.py`，schema 和提示词按客户的单据类型选一套（第 8 到第 10 章那三个变体）。**这一章全部的新内容是流程和边界。**

## 适合什么客户

**三类，各有各的理由。**

**一、量不大的。**

一个月三五十份单据。**这个量买一台机器不值当**，学一套环境更不值当。**发过来跑一跑最省事。**

**二、一次性的。**

年底要把一箱子发票整理成台账、一次搬家前要把旧单据数字化、审计要一份汇总。**做完就没有下一次。**

**三、还在观望的。**

**这一类最要紧，也最容易被小看。**

他听说这件事能做，但不确定效果，**更不确定值不值得为它投一笔钱**。你让他先发三十份过来，**他的决策成本降到接近零**。

**这三类里，第三类是唯一会变成大单的。** 前两类做完就完了，第三类看完结果之后才开始真正的谈话——**那场谈话就是本章最后一节。**

## 怎么收文件

**这一节要认真，因为它是这个形态唯一一处真正的风险点。**

**客户发过来的是他公司的往来单位、金额和日期。** 这些东西在路上的每一段，都要说得清楚在哪儿。

### 三条能用的路

**一、加密压缩包，口令另发。**

客户那一头打包：

```bash
7z a -p -mhe=on 单据-2026-08.7z 单据目录/
```

作用：把一个目录打成一个带口令的压缩包。`-p` 是设口令，**`-mhe=on` 是连文件名一起加密**——不加这一项，别人解不开内容但看得见里面有哪些文件名，**而发票的文件名常常带着日期和单位名**。

没有 `7z` 的话装一下：

```bash
sudo apt install -y p7zip-full
```

Windows 那边用 7-Zip 图形界面，**勾上“加密文件名”那一项**。

**口令要走另一条渠道。** 压缩包发邮件，口令打电话或者发短信。**口令和包在同一条渠道里，加密等于没加。**

**二、客户自己网盘上的有效期链接。**

客户在他自己的网盘里生成一个分享链接，**设一个短的有效期，加一个提取码**。你下载完告诉他一声，**他当场撤掉链接**。

**这条路的好处是文件从头到尾在客户自己的账户里**，撤销权也在他手上。

**三、硬盘或者 U 盘。**

**最土的一条，也是量大的时候最快的一条。** 几千份扫描件几十个 GB，网上传半天，**跑一趟送过来十分钟。**

**这条路要在交接单上写清楚盘什么时候还、还的时候里面还有没有东西。**

### 一条不能用的路

**不要用聊天工具直接传含敏感信息的文件。**

**理由三条，一条比一条实际：**

- **那份文件会留在别人的服务器上。** 你和客户都管不了它留多久、留在哪儿。这跟这本书从第一卷开始讲的那件事是反的；
- **撤回不等于删除。** 对方看没看过、有没有自动下载、有没有被转发，你不知道；
- **群和人挨着。** 发错窗口这件事，**每个人一生都会干一次。**

**这一条要主动跟客户说，而且要说在他把文件发过来之前。**

> **可以照念的一句**：“别在微信里直接发我，那份文件会留在腾讯的服务器上，咱俩都撤不干净。您打个包设个口令，口令电话告诉我。”

**这句话本身就在替你说话。** 一个连收文件都要讲究一下的人，**客户会相信他后面处理数据也讲究。**

### 收到之后先做三件事

**一、一客户一目录，从头到尾不混。**

```bash
mkdir -p ~/ai/data/客户代号-2026-08
mkdir -p ~/ai/projects/客户代号-2026-08
```

**用代号，不用客户全名。** 你自己的截图、日志、屏幕录像里会出现这个目录名（[第 0 卷第 8 章](../00-使用说明/08-文件保护.md)那一套）。

**两个客户的单据绝对不能进同一个目录。** [第 5 章](05-批量处理.md)那个脚本是按目录跑的，**混进去的那一份会跑进别人的台账里**。这是这个形态里最不能犯的错。

**二、记一条收件记录，带校验和。**

```bash
sha256sum 单据-2026-08.7z | tee ~/ai/projects/客户代号-2026-08/收件校验.txt
```

作用：算出这个包的校验和，**同时打在屏幕上并存进一个文件**（`tee` 就是干这个的）。

**这一串要发一句给客户对一下。** 对得上，说明你收到的和他发出的是同一份。**以后要是有人说“我发的不是这个”，这一串是唯一说得清的东西。**

**三、数一遍文件数，和客户说的对一遍。**

```bash
7z x 单据-2026-08.7z -o$HOME/ai/data/客户代号-2026-08
find ~/ai/data/客户代号-2026-08 -type f | wc -l
```

作用：解开压缩包到那个目录，然后数一遍里面有多少个文件（[第 5 章](05-批量处理.md)那条命令的套路）。

**数出来的数要和客户说的那个数对上。** 对不上，**现在就问，不要跑完了再问**——跑完再问，你分不清是他少发了，还是你解压的时候漏了。

## 一批的完整动作

**七步，一步都不省。** 这张表可以直接印出来当工作清单。

```text
□ 1. 收件：包收到、校验和对过、文件数对过，写进交接单
□ 2. 跑：ocr_batch.py 先跑三份看一眼，形状对了再全跑（第 5 章）
□ 3. 拦：validate.py 出复核队列（第 7 章）
□ 4. 看：复核队列里那几行，人对着原件看一遍，改 JSON，重跑
□ 5. 抽：从判“通过”的那一堆里 shuf 抽几份对（第 7 章那条不能省的）
□ 6. 交：台账 xlsx、ledger.csv、review.csv，加一页说明，打包发回
□ 7. 删：到约定时间删干净，出删除确认
```

**第 5 步在这个形态里比在整机形态里更要紧。**

理由很实在：**整机交付的客户，机器在他那儿，他自己会用着用着发现问题；轻交付的客户只看到你发过去的那张表。** 你不抽检，**这张表的质量就没有任何人把过关。**

## 交回去什么

**四样，一样都不少。**

```text
1. 台账.xlsx        客户真正要的东西（第 11 章那个脚本）
2. ledger.csv       脚本直接出的那份，一起给
3. review.csv       复核队列。改过的行已经消失，剩下的是仍需要他看的
4. 一页说明         下面这一份
```

**第 3 样很多人会想省掉，不要省。**

**把复核队列一起交出去，是这个形态的信任来源。** 你交一张干干净净的表，客户没法判断它干不干净；**你交一张表加一张“这几行我看过、这几行请您再看一眼”的单子，他知道你在认真干活。**

**这跟[第 7 章](07-错的怎么拦.md)那三句话是同一件事**——不承诺全对，承诺错的被拦住。

### 那一页说明写什么

```text
本批处理说明

收到　　　　2026-08-15，共 __ 份（PDF __ 份，图片 __ 份）
处理　　　　成功 __ 份，失败 __ 份，失败原因见附件
校验　　　　通过 __ 份，可疑 __ 份，失败 __ 份
已复核　　　__ 行（复核队列里已经改过的）
仍需您看　　__ 行（review.csv 里剩下的，第三列写了每一行哪儿不对）
抽检　　　　从判“通过”的那一堆里随机抽了 __ 份，对了 __ 份

这批结果的适用范围
　　这些数字只对这一批材料成立。换一批单据要重新看。
　　校验拦得住的是：缺格、格式不对、算不平、买卖双方同名。
　　校验拦不住的是：读成了另一个看着也正常的值。这一类靠抽检。

失败那几份怎么办
　　原件本身看不清的，需要重新扫描。清单见附件。
```

**这一页的三段分别在说三件事**：干了多少活、这批东西的边界在哪儿、还有什么要客户做。

**“这批结果的适用范围”那一段不要删。** 它就是[第 7 章](07-错的怎么拦.md)那三句话的书面版，**说出口容易，写下来才算数**（[第 7 卷第 17 章](../07-RAG/17-准确率验收.md)那一句）。

## 数据怎么处理干净

**这一节是本章的正主。**

**先把这个形态的实情说明白**：轻交付这件事，**本质上是客户的业务数据到了你的机器上**。这跟“数据不出客户场所”那个卖点是相反的。

**所以这个形态能不能长期做下去，全看一件事：你能不能把“处理完就干净了”这件事做实，而且拿得出凭据。**

### 约定一个删除时点

**这件事要写在交接单上，在收文件之前就定好。**

```text
删除时点：客户确认收到结果之日起 __ 日内
```

**天数由双方定，本教材不给数字。** 要定的是三件事：**从哪一天起算、几天、谁来提醒。**

**留一段时间的理由是实在的**：客户拿到台账之后可能会问“第 47 行是哪一份”，**这时候原件还在你手上才答得出来**。**到期就删，不要因为“说不定还有用”留着。**

### 删除清单

**删的时候按这张单子走，一条一条打钩。** 漏的通常是后面几条。

```text
□ 原件目录　　　　~/ai/data/客户代号-2026-08/
□ 结果目录　　　　~/ai/projects/客户代号-2026-08/
　　　　　　　　　（out/ 里每份单据一个 JSON、failed/ 里的副本、台账、复核队列）
□ 发回去的那个包　你自己留的那一份
□ 收到的那个压缩包
□ 回收站
□ 邮箱里的附件　　收件箱、已发送、草稿
□ 聊天记录里的文件（本来就不该走这条路，走过就要清）
□ 备份　　　　　　你的自动备份如果覆盖了这两个目录，那一份也在里面
```

**倒数第一条是最容易漏的一条。**

[第 3 卷](../03-服务器基础/README.md)那套自动备份要是把 `~/ai/` 整个包进去了，**你把目录删了，备份里还有一整份**。**做轻交付之前，先确认这两个目录在不在备份范围里**——最省事的做法是把客户目录排除掉。

命令就是普通的删除：

```bash
rm -rf ~/ai/data/客户代号-2026-08 ~/ai/projects/客户代号-2026-08
```

> **`rm -rf` 没有回收站，没有撤销。** 敲之前把路径念一遍。这一条[第 2 卷](../02-Ubuntu/README.md)说过，**在这一章它是刻意的**——你要的就是删干净。

> **一句实话**：普通的删除，是把文件从目录里摘掉，**盘上那块地方在被别的东西写上去之前，理论上还有痕迹**。固态盘上，那些用来“彻底擦除”的老办法（比如 `shred`）**因为盘自己的写入调度，效果和机械盘上不一样**。
>
> **本教材不在这一层做承诺。** 你能写进确认书的是**你删了什么、什么时候删的**，**不是“数据已被物理销毁”**。这两句话差得远，**后面那句不要写。**

### 一份书面确认

**这是这个形态里最值钱的一张纸。**

**它值钱的原因不是法律效力，是它把一件看不见的事变成了看得见的事。** 客户把文件发给一个陌生人，**他心里那点不踏实，只有这张纸能落地。**

```text
数据处理与删除确认

客户　　　　　　____________________
本批材料　　　　____________________（名称、批次）
收到时间　　　　______年__月__日
收到方式　　　　加密压缩包 / 有效期链接 / 移动硬盘
收到数量　　　　____ 份
交付时间　　　　______年__月__日
交付内容　　　　台账、复核队列、处理说明

处理方式
　　全部处理在本方自有设备上完成。处理过程中未将贵方材料
　　上传至任何第三方在线服务，也未用于任何其他用途。

删除时间　　　　______年__月__日
删除范围　　　　原始材料、处理过程产生的中间文件、台账与复核队列、
　　　　　　　　本方留存的交付副本、相关备份
留存内容　　　　无
　　　　　　　　（有留存的，写清楚是什么、为什么留、留到什么时候）

处理方签字　　____________　日期　______年__月__日
```

**三处措辞值得单说。**

**一、写的是“未上传至任何第三方在线服务”，不是“绝对安全”。**

**这是一句架构事实**——这整本书讲的就是模型跑在本地（[第 6 卷](../06-本地模型/README.md)），**所以这句话你说得出口，而且经得起问**。

**“保证数据绝对安全”“保证永不泄露”这类话不要写**，那是结果担保，**你兑现不了。**

**二、“留存内容”那一栏不能留空，也不能想当然写“无”。**

真的留了东西就写清楚。**最常见的一种留存是你想留几份当样本**——那更要写，**而且要先问客户同不同意。**

**三、这不是法律文本。**

**上面这份是一个起点。** 真要用在合同里，**具体条款怎么写、由谁签、有什么效力，见[第 13 卷](../13-项目交付/README.md)，而且应当由执业律师审阅。** 本章不提供法律意见。

## 这个形态的边界

**三条，越往后越硬。**

### 一、量大了不划算

**每一批都有一套固定动作**：收文件、对校验和、数文件、解压、建目录、跑、复核、抽检、打包、发回、删、出确认。

**这些动作不随量减少。** 三十份要走一遍，三千份也要走一遍。

**结果是这样的**：量小的时候，这些动作占的时间比跑本身还多；量大的时候，跑的时间上来了，**但那些动作一次都少不了，而且每个月都要重来。**

**所以这个形态有一个天然的量的上限**，那个数是多少要你自己算——[第 14 章](14-按页计价.md)给算法。

### 二、你的机器在给别人的数据打工

**一台机器，同一时间只能跑一批。**

轻交付客户多起来之后，**你会开始排队**。而排队这件事在这个形态里特别难受：**客户看不见你的机器，他只知道他等了三天。**

**这一条也是升单的理由之一**：他自己有一台，就不用排队了。

### 三、有一类客户根本不会让文件出门

**这一条最硬，而且它不是技术问题。**

**律所的案卷、诊所的病历、财务的全套凭证**——这几类客户里有相当一部分，**从制度上就不允许把材料发给外面的人**，跟你讲不讲究没关系。

**碰到这一类，轻交付这条路直接不通。**

**但这不是坏消息。** 这恰恰说明**这个客户需要的是另一样东西**——[第 7 卷第 11 章](../07-RAG/11-变体-律所合同库.md)那个卖点在这里同样成立：**他要的正是“东西不出我家门”。**

**这就是升单路径**，下一节说。

> **还有一类单不接，跟量和敏感度都没关系。** 涉密单位的材料**不碰**，那有专门的资质要求。这一条在[第 13 卷](../13-项目交付/README.md)。

## 和整机交付的关系

**这两个形态不是二选一，是一前一后。**

| | 轻交付（本章） | 整机交付（第 10 卷、第 13 卷） |
| --- | --- | --- |
| 客户要买什么 | 什么都不买 | 一台机器加一套部署 |
| 材料在哪儿处理 | **你的机器上** | **客户自己的机器上** |
| 客户的决策成本 | 接近零 | 一笔预算、一次内部审批 |
| 你的固定动作 | **每一批都要重来** | 装一次，之后基本不用管 |
| 适合的量 | 小、一次性、试水 | 长期、每月都有 |
| 敏感材料 | **过不了这一关** | **这正是它的卖点** |
| 现金流 | 一次一次收 | 一次性加月费 |
| 天花板 | 有，而且不高 | 高得多 |

**一句话：轻交付是入口，整机是升级。**

**入口的价值不在它自己赚多少钱，在它让客户见到了结果。** [第 7 卷第 17 章](../07-RAG/17-准确率验收.md)最后那句话在这里换了个形式——**你能把笔记本打开让他自己问一句，比你说什么都强**；在这一章，**你能把他自己那三十份单据跑成一张表发回去，比你说什么都强。**

### 那场谈话

**第一批交完，客户看着那张表，这时候才是谈的时候。**

> **可以照念的一句**：“这三十份是我在我这儿跑的。您要是以后每个月都有这么多，或者这些东西您不希望出您公司的门，那就该在您那儿放一台机器，我给您装好。那是另一套报价，我单独给您。”

**这句话里有三件事，都是故意的：**

- **“我在我这儿跑的”** —— 把当前形态的边界摆明，**不含糊**；
- **“不希望出您公司的门”** —— 这一句是给上面第三类客户听的。**他没想到还有这个选项，你替他想到了**；
- **“那是另一套报价”** —— **这一句必须说出口。** 不说，客户会默认装机器也是这个价。

**怎么报、报多少，在[第 14 章](14-按页计价.md)和[第 11 卷](../11-客户与报价/README.md)。本章不下价格结论。**
