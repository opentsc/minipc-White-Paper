# Mini PC 家用本地算力服务器入门

Roland Wayne 著·本白皮书免费开源，欢迎在线或本地阅读与分享

当前版本：`0.1.0`

当前状态：公开草稿。

## 关于本书

这本书写给第一次使用 Mini PC 的人。

全书按主题分章。每章只处理一个问题。章内再按 section 展开。所有完整案例集中放在第 6 章，不分散到其他章节。

## 关于作者

Roland Wayne，获澳大利亚联邦政府全额资助博士生奖学金，现于澳大利亚昆士兰大学医学学部攻读博士学位。

AI 实践从研究延伸到企业工作流程，也包括内容生产系统。实际搭建过 Agent、自动化工作流、本地知识库和多模型协作系统，关注 AI 能否解决具体问题、控制使用成本，并由普通用户长期维护。Mini PC 是这些实践中的一部分。相关测试包括 Ubuntu 部署、本地模型运行，以及本地算力与云端模型的配合。资料处理和知识检索可以留在本地，需要更强模型时再转到云端。

本书基于实际部署和测试经验编写。本书为个人研究整理，不代表任何机构立场。

## 为什么免费开源

- 一章只讲一个主题。
- 案例只放在第 6 章。
- 其他章节可以解释方法，但不展开完整案例。
- 每个案例写清输入、过程、结果、失败、恢复和证据状态。
- 性能、成本和收入都绑定具体设备和运行记录。
- Markdown 是正文来源，PDF 后续生成。
