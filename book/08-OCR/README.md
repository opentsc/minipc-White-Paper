# 08　OCR

**完成结果**：一个文件夹的单据自动变成一张台账，错的会被挑出来，能送进 Excel 和数据库，知道这个能力怎么收钱。

对应学习路线的进度 60。这是第二个可以直接卖钱的能力。

## 主线案例

**一个文件夹的发票，自动变成一张 Excel 台账。** 第 1 章到第 7 章是这条线：先看结果、起服务、定字段、单张跑通、批量处理、自动监测、拦住错的。做完第 7 章，一套能交付的东西就有了。

第 8 章往后是变体和生意：换成合同、物流单、旧档案，再是对接、轻交付、实测和计价。

## 这一卷的立场

**不承诺全对，承诺错的能被拦住。** [第 7 章](07-错的怎么拦.md)是全卷最值钱的一章：六条校验规则把可疑件挑进复核队列，其中「金额加税额等于价税合计」最管用。但那一章也写清了它拦不住什么——识别成另一个合法的值时，校验可能刚好通过，所以抽检仍然必要。

跟客户谈的时候，卖点是这个流程有拦截和复核环节，不是「识别很准」。

## 和第 7 卷的分工

第 7 卷处理能选中文字的 PDF，本卷处理扫描件和图片。第 7 卷第 2 章整理文档时分出的 `need-ocr` 那一堆，就是本卷的输入。两卷可以串起来：先用本卷把扫描件变成文字和字段，再用第 7 卷建成问答库——这也是一条自然的第二单。

## 这一卷不给数字

不写识别准确率，不写每张多少秒。[第 13 章](13-速度与准确率实测.md)给的是测法和空白表，测出来的数只对那批样本有效，样本换了要重测，**不许写进合同当承诺**。

[第 14 章](14-按页计价.md)也不给「多少钱一页」，因为公开材料里一条按页单价参照都没有。给的是算价方法和几条标注了证据等级的市场参照，人民币区间全部标明是估算不是成交价。
