# 12　硬件问题处理

## 完成结果

按看到的症状能找到对应的排查步骤，能区分硬件问题和系统问题，知道哪些情况不要自己拆机，能把报错信息收集好并描述清楚给卖方。

## 开始前需要准备什么

- 这一章按症状查，不需要从头读到尾。遇到问题时，在下面找到最接近的那一节；
- 第 10 章做好的恢复 U 盘（很多排查步骤要用它）；
- 手机（拍照记录报错画面）；
- 第 1 章记录的型号和序列号，第 5 章记录的卖方联系方式和保修期。

## 新词

**日志**（Log）：系统和程序把自己做了什么、遇到什么错误，按时间顺序写下来的记录。出问题时，日志是唯一能还原“当时发生了什么”的东西。Ubuntu 的系统日志用 `journalctl` 查看，内核自己的消息用 `dmesg` 查看。

**内核崩溃**（Kernel Panic）：内核遇到无法继续的错误后停下来，屏幕上出现大段白色或黄色文字，键盘鼠标没有反应，只能强制断电。Linux 上没有 Windows 那种蓝屏画面，对应的就是这种满屏文字，或者画面直接冻住不动。

**自检**（POST）：按下电源键后、加载操作系统之前，主板固件对硬件做的一轮检查。这个阶段还没有操作系统参与，所以这个阶段出的问题和系统无关。

**保修封条**：贴在机身螺丝或接缝处的一张贴纸，撕开或破损后能看出来。厂商用它判断机器有没有被打开过。

## 排查的通用顺序

不管什么症状，先做这三步。多数问题在这里就解决了，剩下的也能缩小范围。

**第一步：换线、换口、换设备。** 一次只换一样，换完试一次。同时换两样，问题好了也不知道是哪一样的原因。

**第二步：减到最小。** 拔掉所有非必需的东西——移动硬盘、U 盘、扩展坞、外接显卡、打印机、摄像头，只留电源、一台显示器、一个键盘。很多莫名其妙的问题是某个外设引起的。

**第三步：记录，不要边试边忘。** 每做一步，记下做了什么、结果怎样。这份记录后面给卖方看，比“我什么都试过了”管用得多。

> **⚠️ 不要在还没排查完的时候拆机。** 拆机可能影响保修（本章后面有说明），而且多数症状不用拆机就能定位。特别是还在退换货窗口内的机器，拆机之前先看[第 11 章](11-收货验收.md)的责任划分。

## 症状：按了电源键完全没反应

没有风扇声，没有指示灯，显示器无信号。

**最小排查**

1. 换一个插座。用手机充电器插上去，确认这个插座有电；
2. 检查电源适配器的指示灯（多数适配器上有一颗小灯）。不亮的话，问题在适配器或电源线，不在主机；
3. 把直流插头从主机上拔下来再插回去，插到底。有的插头要听到轻微的一声才算到位；
4. 电源适配器和电源线是分体的，换一根同规格的电源线试；
5. 拔掉所有 USB 设备和视频线，只留电源，再按一次开机键；
6. 断电放电：拔掉电源适配器，按住主机电源键 10 秒（这时没通电，是把机身内残余电放掉），再插电开机。

**怎么判断**

指示灯、风扇、硬盘灯全都没有动静，这个阶段还没到操作系统，和 Ubuntu 无关，是电源或主板的问题。

**什么时候直接联系卖方**

换过插座、换过线仍然没有任何反应，或者适配器指示灯不亮。不要拆机。

## 症状：通电有风扇声，显示器无信号

能听到风扇转、看到指示灯亮，但屏幕一直是黑的或提示“无信号”。

**最小排查**

1. 检查显示器自己：显示器电源开了吗，输入源选对了吗（显示器菜单里有 HDMI 1、HDMI 2、DP 这些选项，要选到实际插线的那个）；
2. 换一根视频线；
3. 换主机上的另一个视频口。HDMI 换到 DP，DP 换到 HDMI；
4. 换一台显示器，或者接到电视上试；
5. 拔掉所有 USB 设备，只留键盘；
6. 只接一台显示器，不要同时接两台。

**为什么“换口”这一步不能跳**

主机上的多个视频口不一定由同一条输出通路驱动。有的机型在自检阶段只有特定的那个口有画面，进了系统之后其他口才工作（需要核验，以你的型号说明书为准）。

USB-C 口更要注意：不是所有 USB-C 口都支持视频输出，第 2 章已经说明。接了不支持视频的 USB-C 口，没有画面是正常的。

**怎么判断**

- 换一台显示器就好了：问题在原来那台显示器或那根线上，不是主机的问题；
- 换了显示器、线和口都没有画面，但主机能听出在跑（风扇转速有变化、硬盘灯闪、插上 U 盘有反应）：更可能是主板的显示输出部分；
- 完全接不上任何画面，连 BIOS 界面都进不去：属于自检阶段的问题，和系统无关。

**什么时候直接联系卖方**

三种线、两台显示器、所有视频口都试过，仍然一次画面都没有。

## 症状：开机后黑屏，但系统像在跑

能听到开机音、硬盘灯在闪、风扇转速有变化，甚至盲敲密码后有反应，但屏幕是黑的。

这一类更可能是显示驱动的问题，不是硬件坏了。

**最小排查**

1. 等 2 到 3 分钟。首次加载显示驱动有时候慢；
2. 开机时按住 `Shift` 键，或反复按 `Esc`，调出 GRUB 启动菜单；
3. 在 GRUB 菜单选 `Advanced options for Ubuntu`，选**上一个内核版本**启动。第 9 章说过 Ubuntu 会保留旧内核，就是为了这种时候；
4. 旧内核能进桌面：说明是新内核或新装的驱动引起的，处理方法见第 5 卷；
5. 旧内核也进不去：在 GRUB 里选 `Recovery mode`（恢复模式），进去后选 `root` 进入命令行。能看到命令行提示符，说明系统本身在跑，问题出在显示这一层；
6. 用第 10 章的恢复 U 盘启动，进 Live 模式。Live 模式能出画面，说明硬件的显示输出是好的。

> **⚠️ 不要在这一步随手改 GRUB 里的内核参数。** 参数改错会变成完全开不了机，比现在的情况更麻烦。真要改，按第 5 卷给的做法改，那里写了怎么退回去。临时试参数的办法是在 GRUB 菜单里按 `e` 编辑当前这一次的启动项，按 `Ctrl+X` 启动——这种改法只对这一次开机有效，重启就恢复原样，不会写进硬盘。

**怎么判断**

Live 模式有画面、装好的系统没画面 → 系统或驱动问题。Live 模式也没画面 → 更可能是硬件。

## 症状：反复重启

开机后几秒到几分钟自动重启，循环。

**最小排查**

1. 拔掉除电源、显示器、键盘之外的所有设备，尤其是移动硬盘、扩展坞、外接显卡；
2. 换一个插座，避开和空调、电热水壶这类大功率电器共用的插排；
3. 确认用的是原装电源适配器，不是别的设备的适配器；
4. 恢复 BIOS 默认值（做法见本章下面的品牌表）；
5. 开机后立刻进 BIOS，在 BIOS 界面停留 10 分钟，看会不会重启。

**怎么判断**

- 在 BIOS 界面停留也会重启：和操作系统无关，是硬件或供电问题；
- 只有进系统之后才重启：更可能是系统或驱动问题，重启后立刻查上一次开机的日志（本章后面有方法）；
- 接了外接设备就重启，拔掉就正常：是供电不足或那个设备的问题。

**什么时候直接联系卖方**

在 BIOS 界面就会重启，或者恢复默认值之后仍然反复重启。

## 症状：风扇一直高速转

风扇声音大，长时间不降下来。

**最小排查**

1. 先看是不是有程序在占满 CPU：

```bash
top
```

按 `q` 退出。看 `%CPU` 那一列，数字最高的是哪个进程。也可以用图形界面的“系统监视器”。

2. 刚装完系统、刚做完系统更新的那段时间，后台在建索引和处理更新，风扇转几分钟到十几分钟属于正常，等它跑完；
3. 检查进风口和出风口有没有被挡住，桌上的纸、布、其他机器都可能挡风；
4. 进 BIOS 找风扇策略选项（常见名称是 `Smart Fan`、`Fan Mode`、`Performance Mode`），有的机型出厂就设在性能档，改成自动或静音档能降转速。选项名称因品牌而异（需要核验）。

**怎么判断**

进 BIOS 界面（这时候不加载操作系统，CPU 基本空闲）风扇仍然狂转，更可能是温度或风扇控制本身的问题。进系统后空闲状态下转速正常、只在跑任务时高转，属于正常表现——这台机器满载功耗高，风扇转起来是设计如此。

## 症状：机身过热

**先确认什么算过热**

Max395 满载时功耗高，外壳温热、出风口吹出热风，都在设计范围内。要区分的是“热”和“不正常的热”。

**最小排查**

1. 设备四周留出空隙，不要贴墙、不要塞进封闭的柜子；
2. 不要放在毛毯、纸堆、布面上，底部进风口会被堵住；
3. 不要在上面叠放其他设备；
4. 装温度查看工具：

```bash
sudo apt install lm-sensors
sudo sensors-detect
```

第二条会问一串问题，一路按回车用默认值即可。然后：

```bash
sensors
```

看 `Tctl` 或 `edge` 这类读数。空闲和满载各看一次，记下两个数字。

具体多少度算正常，不同型号、不同环境温度差别很大（需要核验）。可用的判断方式是看两个状态的差别，以及温度上去之后 CPU 频率是不是被压得很低：

```bash
grep MHz /proc/cpuinfo
```

**什么时候直接联系卖方**

机身烫到手不能碰、闻到焦味、外壳变形或有异响。**立刻断电**，然后联系卖方，不要继续开机测试。

## 症状：USB 口或网口不识别

**USB 口**

1. 换一个设备插同一个口（排除是设备坏了）；
2. 同一个设备逐个口插一遍（找出是哪个口的问题）；
3. 前面板和后面板分开测；
4. 用命令确认：

```bash
lsusb
```

插上设备前后各执行一次，对比列表有没有多一行。

5. 接的是扩展坞或集线器的话，先把设备直接插到主机上测，排除扩展坞的问题。

**网口**

1. 看网口上的指示灯，插上网线后应当亮或闪；
2. 换一根网线；
3. 换路由器上的另一个口；
4. 用命令确认接口在不在：

```bash
ip link
```

输出里 `enp` 开头的那一行就是有线网口。

- 接口存在，但显示 `state DOWN`：接口在，链路没通，更可能是线或对端设备的问题；
- 接口根本不出现：驱动没加载，或者硬件层面就没被识别。

**品牌差异**

| 品牌 | 需要注意的地方 |
| --- | --- |
| GMKtec EVO-X2 / EVO-X3 | 前面板和后面板的 USB 口走的可能是不同的控制器，一面全不认、另一面正常，是有意义的线索，记下来 |
| Beelink GTR9 Pro | 两个网口要分别测，只有一个不工作和两个都不工作是不同的问题 |
| Framework Desktop | 前面板接口由扩展卡提供。先把卡拔下来重新插到底，再把卡换到另一个槽试，判断是卡的问题还是槽的问题 |
| HP ZBook Ultra G1a | 笔记本形态，机身接口少，外设多半接在扩展坞上。先把设备直接插到机身接口上测，排除扩展坞 |
| 其他品牌 | 按说明书的接口图，把每个口的位置和测试结果一一记下来 |

**怎么判断**

- 一两个口不认、其他正常：是那几个口的问题；
- 全部 USB 口同时不认（键盘鼠标都没反应）：更可能是主板问题；
- 从 Live U 盘启动后所有口都正常：说明硬件没问题，是装好的系统那边的问题。

**什么时候直接联系卖方**

全部 USB 口或网口同时失效，且在 Live 模式下同样失效。

## 症状：搜不到 Wi-Fi

**最小排查**

1. 确认天线装了。有的机型天线是单独包装的，要自己拧到机身背面的天线接口上。天线没装会导致搜不到远处的网络，或者信号只有一格；
2. 看有没有被屏蔽：

```bash
rfkill list
```

输出里如果有 `Soft blocked: yes`，执行下面这条解除：

```bash
sudo rfkill unblock all
```

`Hard blocked: yes` 表示被物理开关关掉了，笔记本形态的机器上可能有这样的按键组合（HP ZBook Ultra G1a 这类需要查说明书的键位）。

3. 确认无线接口存在：

```bash
ip link
```

`wl` 开头的那一行是无线网卡。有 → 硬件被识别了，问题在驱动或配置；完全没有 → 驱动没加载或硬件没被识别。

4. 路由器只开了 5 GHz 频段的话，把 2.4 GHz 也打开试一次。部分信道在某些地区不允许使用，网卡不会显示这些信道上的网络。

**怎么判断**

用第 10 章的恢复 U 盘启动进 Live 模式，看能不能搜到 Wi-Fi：

- Live 模式能搜到、装好的系统搜不到 → 系统或驱动问题；
- Live 模式也搜不到 → 更可能是天线没装或无线模块的硬件问题。

**什么时候直接联系卖方**

天线装好了，Live 模式下也搜不到任何网络，`ip link` 里没有无线接口。

## 症状：满屏白字报错或画面冻住

屏幕突然出现大段文字，或者画面停住不动，鼠标键盘都没反应。这是内核崩溃。

**第一件事：拍照**

用手机把整屏拍下来。重启之后这些文字就没了，日志里不一定记全。重点拍：

- 最上面几行（错误最初的原因通常在这里）；
- 含 `BUG:`、`Oops:`、`Call Trace`、`RIP:`、`kernel panic` 字样的行。

屏幕文字太多拍不清的话，分两三张拍，保证每一张的字能看清。

**然后**

1. 长按电源键 10 秒强制关机，再开机；
2. 开机后立刻查上一次开机的错误日志（方法见下一节）；
3. 强制断电之后系统提示要检查文件系统，按提示做完，不要跳过。

**怎么判断**

- 是在装完驱动、改完内核参数、做完系统更新之后开始出现的：更可能是系统问题，回退那次改动。第 5 卷的驱动章节写了怎么退；
- 在 BIOS 界面也会冻住，或者从 Live U 盘启动同样崩溃：更可能是硬件；
- 只在跑大负载（跑模型、编译）时出现，空闲时正常：可能是供电、散热或内存的问题。

**关于内存**

内存和供电问题会引起这种随机崩溃。多数 Max395 机型的内存焊在主板上，没有“拔下一条试试”这一步（你的机型内存能不能拆，以说明书为准，需要核验）。内存可拆的机型，也只在过了退换货窗口、并且确认拆机不影响保修之后才考虑单条测试。

在窗口内的机器，直接联系卖方，说明“随机冻屏，Live 模式下同样出现”，不要自己拆。

## 症状：硬盘识别不到

**先分清是在哪一层看不到**

1. 进 BIOS，在 `Boot` 或存储相关的菜单里，看有没有列出 NVMe 设备；
2. BIOS 里能看到 → 硬件在，问题在系统层；
3. BIOS 里也没有 → 硬盘没插到位，或者硬盘本身的问题。

**系统层面查**

```bash
lsblk
```

看有没有 `nvme0n1` 这样的设备。

```bash
ls /dev/nvme*
```

列出所有 NVMe 设备文件。

```bash
sudo apt install nvme-cli
sudo nvme list
```

第一条装工具，第二条列出 NVMe 硬盘的型号、序列号和容量。

**查硬盘健康**

```bash
sudo apt install smartmontools
sudo smartctl -a /dev/nvme0n1
```

关注 `Critical Warning`（正常是 `0x00`）、`Media and Data Integrity Errors`（正常是 `0`）、`Percentage Used`（已用寿命）。

> **⚠️ 开机状态下不要拔插 M.2 硬盘，会损坏硬盘和主板。** 自己加装的第二块 SSD 要重新插拔的话，先关机、拔掉电源适配器、按住电源键 10 秒放电，再动手。出厂就装好的那块内置盘，在退换货窗口内不要自己拆——拆了之后再出问题，责任说不清（见[第 11 章](11-收货验收.md)）。

**什么时候直接联系卖方**

出厂预装的那块 SSD 在 BIOS 里就认不到。这种情况不要拆机。

## 怎么判断是硬件问题还是系统问题

三个通用方法，前面各节反复用到，这里集中说一次。

**方法一：换到 Live 模式**

插上第 10 章做的恢复 U 盘，开机按启动菜单键选 U 盘，选“试用 Ubuntu”。

Live 模式跑的是 U 盘上一套干净的 Ubuntu，不读你硬盘上的任何配置和驱动。

- Live 模式下问题消失 → 更可能是系统、驱动或配置的问题，硬件本身没坏；
- Live 模式下问题照旧 → 更可能是硬件。

这是最有用的一招。很多看起来像硬件坏了的现象（搜不到 Wi-Fi、USB 不认、黑屏），在 Live 模式下一试就能分清。

**方法二：进 BIOS 停留**

BIOS 界面不加载操作系统。在 BIOS 里就出现的问题——重启、死机、风扇狂转、显示异常——和 Ubuntu 无关，不要在系统里找原因。

**方法三：减到最小**

只留电源、一台显示器、一个键盘，其他全拔掉，再试一次。问题消失了，就一个一个把设备接回去，接到哪一个复现，就是哪一个的问题。

## 恢复 BIOS 默认值

改过 BIOS 设置之后出问题，先把 BIOS 恢复到出厂默认值。这个操作不影响硬盘上的数据。

| 品牌 | 常见做法 |
| --- | --- |
| GMKtec EVO-X2 / EVO-X3 | 开机按 `Del` 或 `F2` 进 BIOS，找 `Load Optimized Defaults` 或 `Restore Defaults`（按 `F9` 通常是同一功能），再按 `F10` 保存退出 |
| Beelink GTR9 Pro | 开机按 `Del` 或 `F2` 进 BIOS，按 `F9` 恢复默认，`F10` 保存退出 |
| Framework Desktop | 开机按 `F2` 进 BIOS，在退出菜单里选 `Restore Defaults`，保存退出 |
| HP ZBook Ultra G1a | 开机按 `F10` 进 BIOS，在 Main 或 Exit 菜单里找 `Apply Factory Defaults and Exit` |
| 其他品牌 | 进 BIOS 后找 `Load Setup Defaults`、`Restore Defaults` 或 `Optimized Defaults`，按 `F10` 保存 |

菜单名称随固件版本变化，以你机器上实际看到的为准（需要核验）。

> **⚠️ 恢复默认值会把第 7 章设过的 UMA Frame Buffer 一起改回出厂值。** 恢复之后重新按第 7 章的说明把这一项设回最低值。这一步不做也能开机，但会占掉一部分内存。

进不去 BIOS 或者根本开不了机的情况下，还有一个不拆机的办法：拔掉电源适配器，按住电源键 10 秒放掉残余电，再插电开机。

打开机箱去拔主板电池、短接跳线来清除设置，这些做法都要拆机，会碰到保修问题，不建议自己做。

## 收集报错信息

给卖方的信息越具体，来回沟通的次数越少。

**拍照**

出现报错画面、异常显示、指示灯状态异常的时候，先拍照。这些东西重启之后就没了。拍的时候关掉闪光灯，屏幕上的字要能看清。

**查上一次开机的错误**

系统崩溃或自动重启之后，重启进桌面第一件事：

```bash
journalctl -b -1 -p err
```

拆开看：

- `-b -1` 表示上一次开机那一段（`-b 0` 或不带数字是本次开机，`-b -2` 是上上次）；
- `-p err` 表示只显示错误级别及以上的记录，把大量正常信息滤掉。

用方向键上下翻，按 `q` 退出。

正常系统也会有几条错误记录，不是每一条都代表故障。要看的是时间点和你出问题的时刻对得上的那几条。

**如果提示上一次开机的日志不存在**

看到 `Specified boot ID or offset -1 is not available` 这样的提示，说明系统没有保存上一次开机的日志。开启持久保存：

```bash
sudo mkdir -p /var/log/journal
sudo systemctl restart systemd-journald
```

之后每次开机的日志会写到硬盘上，重启之后还能查。这个改动会占用一些磁盘空间（通常几百 MB 到几 GB）。

**查内核消息**

```bash
sudo dmesg | tail -50
```

`dmesg` 显示内核自己的消息，`tail -50` 只取最后 50 行。硬件识别、驱动加载、硬件报错都在这里。

只看错误：

```bash
sudo dmesg --level=err,crit
```

带上时间：

```bash
sudo dmesg -T
```

`-T` 把内核内部的计时换成能读的日期时间，方便和你记的出问题时间对上。

**存成文件发给卖方**

```bash
journalctl -b -1 -p err > ~/last-boot-errors.txt
sudo dmesg -T > ~/dmesg.txt
```

`>` 表示把输出写进文件，`~` 是你的主目录。两个文件在“文件”程序的主目录下能看到，可以直接当附件发出去。

发之前打开看一眼，里面可能有主机名、账户名这类信息。

**怎么描述给卖方**

一次把这些写全：

- 品牌、型号、序列号；
- 购买日期、订单号、签收日期；
- **现象**：什么时候第一次出现、多久出现一次、能不能重复出现。写具体的：“每次开机后大约 10 分钟画面冻住，键盘鼠标无反应，一天出现 3 次”，不要写“经常死机”；
- **出现前做了什么**：装了什么、改了什么设置、有没有做过系统更新；
- **已经排查过的**：换过哪根线、换过哪个口、换过哪台显示器、恢复过 BIOS 默认值、Live 模式下试过没有、结果分别是什么；
- **系统信息**：Ubuntu 版本（`cat /etc/os-release`）、内核版本（`uname -r`）；
- **附件**：现场照片、上面两个日志文件、`smartctl` 输出（硬盘相关的问题）。

“开不了机”这样的描述，对方只能回一句“请检查电源”。“按下电源键后电源灯亮 2 秒然后熄灭，风扇不转，显示器一直无信号，换过 3 个插座和 2 根电源线，适配器指示灯常亮”，对方能直接判断。

## 拆机与保修

**保修封条**

很多机型在机身螺丝或接缝处贴了保修封条。撕开或弄破封条、自行更换内存或硬盘，可能影响保修资格。

**这件事没有统一答案**

有些品牌明确允许用户自行更换 SSD 和 Wi-Fi 模块，并不因此失去保修；有些不允许，或者只对被更换的部件免责。条款因品牌、批次和销售地区而不同（需要核验）。

**动手之前**

1. 在订单页面、说明书或品牌官网找保修条款，看清楚写了什么；
2. 找不到明确说法，直接问卖方，并且**保留书面回复**——用平台内的聊天问，记录留在平台上；
3. 拍照记录拆机之前的状态，包括封条完整的样子。

**退换货窗口内不要拆机**

规格不符或功能故障，走退换货比自己修划算得多。拆过之后再申请退货，卖方可能以此为由拒绝，这时候争起来很被动。窗口期限见[第 11 章](11-收货验收.md)。

**这里不写成绝对结论**：拆机是否影响保修，最终以卖方的售后条款和你所在地区的相关规定为准。上面说的是一般做法和常见风险，不是法律意见。

## 什么情况直接联系卖方，不要自己动手

- 完全不通电，或电源适配器指示灯不亮；
- 冒烟、焦味、外壳变形、有液体痕迹（先断电）；
- 出厂预装的 SSD 在 BIOS 里认不到；
- 全部 USB 口或全部网口同时失效；
- 在 BIOS 界面就出现死机、重启或风扇狂转；
- `free -h` 显示的内存明显低于订单描述的一半（核对方法见[第 11 章](11-收货验收.md)）；
- 机身有明显的物理损伤，或者开箱时就有；
- 还在退换货窗口内的任何硬件异常。

## 正常结果

遇到问题时，你能在这一章找到对应的症状，做完最小排查，判断出是硬件还是系统的问题，并且手上有一份可以直接发给卖方的记录和日志。

## 看到不同结果怎么办

**症状在这一章找不到对应的一节**：先做“排查的通用顺序”那三步和“怎么判断是硬件问题还是系统问题”那三招。多数情况到这里就能分清方向：判断为系统问题的，去[第 15 卷：故障排查](../15-故障排查/README.md)按症状查；判断为硬件问题的，按本章“收集报错信息”准备好材料联系卖方。

**排查过程中问题时好时坏，不能稳定复现**：把每次出现的时间点记下来，记满几次再看规律——是不是都在开机后固定时间、都在跑大负载时、都在接了某个设备之后。断断续续的问题最怕边试边忘，记录比记忆可靠。

**同时有好几个症状**：先处理最靠前的那个。开不了机就先解决开不了机，不要一起查。前面的问题解决之后，后面的症状有一部分会跟着消失。

**卖方要求你先自己拆机检查**：把要求留在聊天记录里，问清楚拆机之后保修怎么算。不接受就说明情况，要求走退换货或寄修。

## 联系卖方前需要保存的信息

- 品牌、型号、序列号；
- 购买日期、订单号、签收日期；
- 现象描述：第一次出现的时间、出现频率、能否重复出现；
- 报错画面的照片；
- `journalctl -b -1 -p err` 和 `sudo dmesg -T` 的输出文件；
- 硬盘相关问题另附 `sudo smartctl -a /dev/nvme0n1` 的输出；
- Ubuntu 版本和内核版本；
- 已经做过的排查步骤和每一步的结果；
- 第 11 章填好的验收表。
