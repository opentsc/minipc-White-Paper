# 主教材总目录

## 规模

主教材 16 卷，215 章，约 100 万字。加上[产品交付手册](../playbooks/README.md)的 9.7 万字和[分级实验](../labs/README.md)的 8.1 万字，全项目约 117 万字。

字数用于容纳步骤、截图、检查和恢复方法，不作为完成标准。

## 每章固定结构

1. 完成后会得到什么；
2. 开始前需要准备什么；
3. 本章出现的新词；
4. 操作步骤；
5. 每一步正常会看到什么；
6. 看到不同结果怎么办；
7. 完成检查；
8. 停止方法；
9. 恢复方法；
10. 可以解决什么问题；
11. 可以包装成什么服务；
12. 客户如何验收；
13. 事实来源和版本日期。

## 完成标准

读者达到 100 前，至少要完成：

- 安装并恢复过一次系统；
- 独立运行本地模型；
- 建立一个局域网 API；
- 建立一个带来源引用的知识库；
- 完成一个 OCR 或 Agent 工作流；
- 把实验整理成一个交付物；
- 制作演示、报价和项目范围；
- 用测试数据完成验收；
- 建立备份、监控和维护计划；
- 能说明哪些结果可以保证，哪些需要人工复核。
