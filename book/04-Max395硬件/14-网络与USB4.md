# 14　网络与 USB4

## 完成结果

知道这台机器上有几个网口、各是什么速率、Wi-Fi 和蓝牙认没认到、USB-C 口能干什么。知道这台机器当本地服务用的时候网线该怎么接、为什么走有线，也知道速率不能只看标称、要自己测一次。

## 开始前需要准备什么

- 一台装好 Ubuntu、能开终端的设备；
- 一根网线，一台能插网线的路由器或交换机；
- 局域网里另一台电脑（测速那一节要两台机器配合，只有一台就先跳过那一节）；
- 本章要装两个工具，其余是只读命令；
- 想测外接存储速度的话，准备一个 U 盘或移动固态硬盘；
- 30 分钟左右。

## 新词

**网口**（以太网口，Ethernet）：插网线的那个方口，插头卡进去会“咔”一声。机身上通常标着一个小图标，旁边有一到两个指示灯。

**速率**：单位时间能传多少数据，单位是 bps（每秒多少比特）。常见的写法有 `1 Gbps`、`2.5 Gbps`、`10 Gbps`。**注意 bps 和 B/s 不是一回事**：8 bit 等于 1 Byte，1 Gbps 的网口理论上每秒传 125 MB 左右，实际还要再打折。

**协商**：网口两端接上之后，会互相商量用哪个速率跑。**协商结果取一个双方都支持的值**——机器上是 2.5 Gbps 的口，接到只有 1 Gbps 的交换机上，最后跑的是 1 Gbps。网线质量不够也会协商到更低的档。

**Wi-Fi**：无线局域网。代际写作 Wi-Fi 5、Wi-Fi 6、Wi-Fi 6E、Wi-Fi 7，代数越新理论速率越高，前提是路由器那边也支持同一代。

**蓝牙**（Bluetooth）：短距离无线连接，接鼠标、键盘、耳机用。和 Wi-Fi 通常做在同一块模块上，所以两者常常一起认到、一起认不到。

**USB4**：一套接口协议标准，物理形状用的是 USB-C。它规定了这个口能同时跑数据、视频和供电。

**雷电**（Thunderbolt）：另一套接口标准，物理形状也是 USB-C，和 USB4 有部分兼容关系。**光看接口形状分不出一个 USB-C 口到底是普通 USB、USB4 还是雷电**，要看机身上的标识和厂商的规格表。

**DisplayPort Alt Mode**：让 USB-C 口输出视频信号的一种工作方式。一个 USB-C 口支不支持视频，就是看它有没有这一项。

**带宽**：一条通道最多能同时过多少数据。USB-C 口上的数据、视频、供电共用同一条通道，**接了高分辨率显示器之后，同一个口上外接硬盘的速度可能会降下来**，这是分带宽，不是故障。

**局域网**（LAN）：你家里或办公室里，路由器下面这一片互相能直接访问的网络。这台机器当本地服务用的时候，客户端和它要在同一个局域网里。

**延迟**：一个包发出去到收到回复要多久，单位毫秒（ms）。速率高不等于延迟低，两件事分开看。

## 有线网口：各家不同，先看自己这台

Max395 是 AMD 的芯片，**网口有几个、什么速率、用的哪家的网卡芯片，全部由整机厂决定**（第 1 章）。同一颗芯片的整机上，见过的配置包括：

- 一个 2.5 Gbps 网口；
- 两个网口（[第 1 卷第 11 章](../01-开箱与安装/11-收货验收.md)记录 Beelink GTR9 Pro 要“两个网口都要各插一次网线单独测”）；
- 笔记本形态的机型可能一个网口都没有，只能靠 Wi-Fi 或者转接（HP ZBook Ultra G1a 属这一类，**需要核验**）。

**速率写多少、有几个口，本项目未逐机型核对厂商规格表，全部需要核验。** 以你的订单页面和机器随附的说明书为准。机型差异的完整说明见第 15 章。

**怎么看自己这台**

```bash
ip -br link
```

`-br` 是简洁格式，一个网络设备一行。有线网口的名字通常以 `en` 开头（比如 `enp1s0`），无线以 `wl` 开头，`lo` 是机器自己和自己通信用的，不用管。**有几行 `en` 开头的，就是有几个有线网口。**

```bash
nmcli device status
```

这条列出每个设备的类型和连接状态，`connected` 表示已经连上。这条和[第 1 卷第 11 章](../01-开箱与安装/11-收货验收.md)验收时用的是同一条。

**看当前协商到的速率**

```bash
cat /sys/class/net/enp1s0/speed
```

把 `enp1s0` 换成你自己那个口的名字。输出是一个数字，**单位是 Mbps**：`1000` 就是 1 Gbps，`2500` 就是 2.5 Gbps。

没插网线的时候这条会报错或者输出 `-1`，**属正常**，插上线再读。

**看这个口本身支持到多少**

```bash
sudo apt install ethtool
sudo ethtool enp1s0
```

输出里有两处要看：

- `Supported link modes`：这个口**本身**支持的所有速率；
- `Speed`：**当前协商到的**速率。

两个数不一样很常见——口支持 2.5 Gbps，但对端交换机只有 1 Gbps，那就跑 1 Gbps。**这不是故障，是协商结果。** 想跑满，路由器或交换机、网线三样都要跟上。

**看用的是哪家的网卡**

```bash
lspci | grep -i ethernet
```

输出里能看到网卡芯片的厂商和型号。排查驱动问题时要用到（第 5 卷）。

**网线**

网线上印着 `Cat 5e`、`Cat 6` 这类标识。**要跑 2.5 Gbps 以上，线和交换机都要跟得上**，随机附的短线不一定够。线材等级和实际能跑到的速率之间的对应关系，本项目[来源目录](../../reference/source-catalog.md)里没有收录来源，**需要核验**，以线材和交换机厂商的说明为准。判断办法很简单：按下面“端口速率怎么实测”那一节测一次，比查表可靠。

## Wi-Fi 和蓝牙

Wi-Fi 和蓝牙通常做在同一块模块上，有的机型这块模块插在一个独立的 M.2 插槽里，可以换（第 13 章说过 M.2 插槽的事）。**具体到你这台是焊死的还是可换的，需要核验。**

**看 Wi-Fi**

```bash
nmcli device wifi list
```

列出周围的 Wi-Fi 名称。这条和[第 1 卷第 11 章](../01-开箱与安装/11-收货验收.md)是同一条。

```bash
iw dev
```

列出无线设备。看到设备说明模块认到了、驱动也加载了。

连上之后看当前的连接质量：

```bash
iw dev wlp2s0 link
```

把 `wlp2s0` 换成 `ip -br link` 里 `wl` 开头的那个名字。输出里有当前信号强度和协商速率。

**搜不到网络先看三件事**：天线拧上了没有（有的机型天线单独包装）、`rfkill list` 里是不是被屏蔽了、模块认没认到。处理办法在[第 1 卷第 12 章“搜不到 Wi-Fi”](../01-开箱与安装/12-硬件问题处理.md)，本章不重抄。

**看蓝牙**

```bash
bluetoothctl show
```

输出里有 `Powered: yes` 就是开着的。这条和[第 1 卷第 11 章](../01-开箱与安装/11-收货验收.md)是同一条。

**这台机器当服务用的时候，蓝牙基本用不上。** 它主要是接键鼠和耳机用的。用不到就不用管，没必要关。

## USB4 或雷电接口能做什么

**先确认你这台机器上到底有没有**

**不要看形状判断。** USB-C 形状的口，可能是普通的 USB 数据口，可能支持视频输出，可能是完整的 USB4，各家不同、同一台机器上不同的口也不同。[第 1 卷第 2 章](../01-开箱与安装/02-接口与接线.md)已经写过同一件事：不是所有 USB-C 口都支持视频输出，只有标着 DisplayPort 图标或 `DP` 字样的那个支持。

三条办法确认：

```bash
lsusb -t
```

`-t` 是按树状列出 USB 设备。每一行末尾的 `5000M`、`10000M` 这类数字是这条总线的速率，单位 Mbps。数字越大说明这条总线的规格越高。

```bash
ls /sys/bus/thunderbolt/devices/
```

Linux 把 USB4 和雷电放在同一个子系统下管理。这个目录里有内容，说明系统认到了这类控制器；**目录不存在或者是空的，属正常**，说明这台机器没有这类口，或者内核没认出来。

```bash
sudo dmesg | grep -i -E "thunderbolt|usb4"
```

从内核日志里找相关的行。什么都没有也属正常。

**上面三条的输出格式随内核版本变化，本项目未在 Max395 机型上实测过，需要核验。** 最终以厂商规格表和机身标识为准。

**能做的四件事**

**一、外接存储**

移动固态硬盘接上去，速度比普通 USB 口高出一截。用法上和普通 U 盘一样：插上、系统自动挂载、在“文件”里能看到。

> **⚠️ 拔外接存储之前要先在“文件”里点弹出（或者用 `sudo umount`），系统还在往里写的时候直接拔会丢数据。** 拔早了导致文件损坏的，事后没有恢复办法，只能从备份重来。

模型文件放在外接盘上跑不跑得动，取决于外接盘的实际速度和你的用法。**加载模型是一次性的大量顺序读**，慢一点就是加载久一点；但如果框架在运行中还要反复读盘（比如内存放不下、靠映射文件顶着），外接盘的速度会直接影响体验。第 6 卷会讲这一层。

**二、外接显示器**

支持 DisplayPort Alt Mode 的 USB-C 口可以直接接显示器，一根线同时走视频和数据。

这台平台上有一条相关记录：[Ubuntu 24.04.4 发行说明](https://documentation.ubuntu.com/release-notes/24.04/4/)（Canonical，访问日期 2026-08-13）写明该版本集成的内核修复了**影响 Strix Halo 无缝启动与 Type-C 视频输出的缺陷**。所以 USB-C 接显示器没画面的时候，除了确认这个口支不支持视频，**也要看系统版本是不是太旧**。系统更新见[第 1 卷第 9 章](../01-开箱与安装/09-系统更新.md)，驱动那一层见第 5 卷。

**三、机器之间传数据**

两台都有 USB4 口的机器可以用一根线直连传文件，比走千兆网快。**这条路的配置方式随内核版本和发行版变化，本项目未实测，需要核验。** 日常搬几十 GB 的模型文件，更省事的办法是走有线局域网，或者用一块移动固态硬盘。

**四、扩展坞**

一个口扩出多个 USB、网口和视频输出。要注意两件事：扩展坞上的设备共用同一条通道的带宽；进 BIOS 的时候扩展坞上的键盘不一定能用（第 7 章记录过，进不去 BIOS 要把扩展坞和集线器拔掉，键盘直插后面板）。

**本教材不覆盖的**

**外接显卡（eGPU）不在本教材范围内。** 这台设备的整套方案建立在统一内存和 iGPU 上（第 3 章到第 6 章），外接独立显卡是另一条技术路线，涉及的驱动、显存和功耗问题都不一样。

另外，[第 1 卷第 11 章](../01-开箱与安装/11-收货验收.md)记录过 GMKtec 部分批次带 OCuLink 口，那是外接显卡用的另一种接口，**本教材同样不覆盖它的功能，验收时只确认接口存在且无变形**。

## 这台设备做本地服务时网络该怎么接

这台机器的典型用法是：它放在一个地方长期开着跑模型，你和同事从别的电脑连上来用（第 6 卷的局域网访问、第 10 卷的产品化）。这个用法对网络的要求和办公用机不一样。

**有线优先，六条理由**

1. **速率是确定的。** 网口协商到多少就是多少，不会因为隔壁开了微波炉就掉一半；
2. **Wi-Fi 是共享介质。** 同一个信道上的设备互相挤，人多的办公室里波动很大；
3. **延迟和抖动更小。** 交互式对话里，延迟的波动比平均速率更容易被感觉到；
4. **大文件传输不容易断。** 模型文件动辄几十 GB（第 13 章），中途掉线要重来；
5. **服务端需要一个稳定的地址。** 客户端要能一直找得到它，有线加固定地址最省事；
6. **无线模块有省电策略。** 空闲一段时间之后降速或断开，对一台长期挂机的服务机是麻烦不是优点。

**这不是说不能用 Wi-Fi。** 只有 Wi-Fi 的环境照样能跑，代价是速度和稳定性要接受波动，而且排查问题时多一个变量。**做客户交付的机器，网线是标配**（第 13 卷）。

**怎么接**

1. 网线一头插机器的网口，另一头插路由器或交换机的 LAN 口；
2. 确认拿到地址：

```bash
ip -br addr
```

有线那一行后面能看到一个 IP 地址（形如 `192.168.x.x`），就是拿到了。

3. 确认通不通：

```bash
ping -c 4 223.5.5.5
```

`-c 4` 是发 4 个包。4 个都有回复、`packet loss` 是 `0%` 就正常。这条和[第 1 卷第 11 章](../01-开箱与安装/11-收货验收.md)是同一条。

**让地址固定下来**

默认情况下地址是路由器自动分配的（DHCP），可能会变。变了之后客户端就连不上了。两条路：

- **在路由器上做 DHCP 保留**（推荐）：在路由器的管理界面里，把这台机器的网卡绑定到一个固定地址。**机器这边什么都不用改**，出问题时也不会因为改错配置连不上；
- **在机器上设静态 IP**：Ubuntu 的“设置”→“网络”→有线连接的齿轮图标→`IPv4`，把方式从“自动（DHCP）”改成“手动”，填地址、子网掩码、网关和 DNS。**填错了会当场断网**，恢复办法是改回“自动”。

两条路选一条，**不要两边都做**，会冲突。

> **⚠️ 不要为了“在外面也能用”把这台机器的服务直接开到公网上。** 本地部署的价值就在于数据不出门，把端口直接暴露出去等于把这层价值扔掉，还多一个被扫描的入口。远程访问的正确做法在第 14 卷。

**双网口的机器怎么接**

有两个网口的机型，最省事的做法是**只接一个**，另一个空着。两个口都接到同一个交换机上、又都自动获取地址，系统会有两条通往同一个网络的路，出问题时很难查清是走的哪一条。

真要两个口都用（比如一个接办公网、一个接一台设备），那属于网络配置的范畴，见第 14 卷。**本章不给多网口的配置方案。**

## 端口速率怎么实测

标称速率是设备本身的规格，**实际能跑到多少要自己测**。测出来比标称低是常态：协议开销、对端设备、线材、文件系统都要吃掉一部分。

**测网口：`iperf3`**

要两台机器，两边都装：

```bash
sudo apt install iperf3
```

**一台当服务端**（就是这台 Max395 机器）：

```bash
iperf3 -s
```

屏幕停在等待状态，这是对的。按 `Ctrl+C` 退出。

**另一台当客户端**，把地址换成上面 `ip -br addr` 读到的那个：

```bash
iperf3 -c 192.168.1.100 -t 30
```

`-c` 后面是服务端地址，`-t 30` 是跑 30 秒。结果最后一行 `sender` 和 `receiver` 两个数就是实测速率，单位通常是 Mbits/sec。

**这条测的是两台机器之间整条链路**，中间的交换机、网线、对端网卡任何一环慢，测出来就慢。测出来只有一半，先换根线、换个交换机口再测一次，别急着怀疑机器。

反方向也测一次：

```bash
iperf3 -c 192.168.1.100 -t 30 -R
```

`-R` 是反过来测（服务端往客户端发）。两个方向都测，才知道是不是单向的问题。

**测 Wi-Fi**：同一套命令，把客户端换成走无线的那台。**同一个位置测三次**，Wi-Fi 的波动比有线大得多，单次结果说明不了问题。

**测外接存储**

先看盘挂在哪里：

```bash
lsblk
```

找到外接盘的挂载点，通常是 `/media/你的用户名/盘的名字` 这种形式。

**测写入**：

> **⚠️ `of=` 后面指向的文件会被覆盖。** 文件名一定要用一个不存在的新名字，不要指向已有的文件，也不要直接指向 `/dev/sdb` 这样的设备名——**指错了会清空整块盘，没有撤销**。

```bash
dd if=/dev/zero of=/media/你的用户名/盘的名字/speedtest.bin bs=1M count=4096 oflag=direct status=progress
```

拆开看：`if=/dev/zero` 是数据源（一个源源不断产生零的特殊文件），`of=` 是写到哪里，`bs=1M count=4096` 是写 4096 块、每块 1 MB，合计 4 GB，`oflag=direct` 是绕开系统缓存直接写盘（不加这个测的是内存速度，数字会好看到不真实），`status=progress` 是显示进度。

跑完最后一行给出速度。**测完把文件删掉**：

```bash
rm /media/你的用户名/盘的名字/speedtest.bin
```

**测读取**：

```bash
sudo hdparm -t /dev/sdb
```

设备名以 `lsblk` 为准。`-t` 是测连续读取速度。这条只读不写。

**上面这几条命令的可用性和输出格式在不同设备、不同文件系统上会有差别，本项目未在 Max395 机型上实测，需要核验。** 数字的用处不在于和别人比，在于记进第 16 章的基线，以后自己对照。

## 这一章涉及的可改设置

**一、装 `ethtool` 和 `iperf3`**

- **默认状态**：Ubuntu 装完之后这两个不一定装了；
- **什么情况才需要改**：要看网口支持的速率、要实测链路速度时装。不装不影响联网；
- **改完怎么验证**：`sudo ethtool` 加网口名有输出，`iperf3 -s` 能起来；
- **怎么恢复**：`sudo apt remove ethtool iperf3`。这两个包只读数据和产生测试流量，卸掉不影响系统。

**二、有线还是无线**

- **默认状态**：网线插上就走有线，没插就走 Wi-Fi，系统自动选；
- **什么情况才需要改**：这台机器长期当服务用的时候，接上网线之后把 Wi-Fi 关掉，少一个变量。桌面上手动用的机器不用改；
- **改完怎么验证**：`ip -br addr` 里只有有线那一行有地址；`ping` 通；从另一台机器还能连上来；
- **怎么恢复**：在右上角状态菜单里把 Wi-Fi 打开。**关 Wi-Fi 之前先确认有线是通的**，两个一起断就只能到机器跟前去处理了。

**三、地址是自动获取还是固定**

- **默认状态**：自动获取（DHCP）；
- **什么情况才需要改**：这台机器要给别人连、地址不能变的时候。**优先在路由器上做 DHCP 保留，机器这边不动**；
- **改完怎么验证**：`ip -br addr` 里是你要的那个地址；重启一次之后地址没变；从另一台机器 `ping` 得通；
- **怎么恢复**：“设置”→“网络”→齿轮→`IPv4`，方式改回“自动（DHCP）”，断开重连。改配置的时候**手边留一套键盘和显示器**，改断了要在机器跟前改回来。

**四、Wake-on-LAN（网络唤醒）**

- **默认状态**：随整机厂和固件而定，BIOS 和网卡两边都有开关。**先读出当前状态再说**（`sudo ethtool 网口名` 输出里的 `Wake-on` 一行），**本项目未逐机型记录，需要核验**；
- **什么情况才需要改**：本教材没有推荐改动的场景。一台长期挂机的服务机根本不关机，用不上这个；
- **改完怎么验证**：`sudo ethtool 网口名` 里的 `Wake-on` 值变了；
- **怎么恢复**：改回你记下来的原值。BIOS 那一半用 `Load Optimized Defaults`（[第 1 卷第 12 章](../01-开箱与安装/12-硬件问题处理.md)），**恢复默认之后要按第 9 章重新设一遍 UMA Frame Buffer Size**。

**五、MTU**

- **默认状态**：`1500`；
- **什么情况才需要改**：本教材没有推荐改动的场景。改大（巨帧）要求链路上每一台设备都改成同一个值，漏一台就出现“小包能过、大包丢”这种极难查的故障；
- **改完怎么验证**：`ip -br link` 里的 MTU 值；
- **怎么恢复**：改回 `1500`。

## 正常结果

`ip -br link` 能列出这台机器的网络设备，你知道有几个有线口、无线设备叫什么名字；`cat /sys/class/net/网口名/speed` 能读出当前协商速率；`sudo ethtool 网口名` 里 `Supported link modes` 和 `Speed` 两项你都看过并且能解释为什么可能不一样。

`nmcli device wifi list` 能列出周围的 Wi-Fi，`bluetoothctl show` 里有 `Powered: yes`。

你知道这台机器上的 USB-C 口是不是 USB4、支不支持视频输出，依据是厂商规格表加上 `lsusb -t` 的输出，不是接口形状。

机器接的是有线，地址已经固定下来，从另一台机器 `ping` 得通，`iperf3` 测过一次并且记下了结果。

## 看到不同结果怎么办

**`cat /sys/class/net/网口名/speed` 报错或输出 `-1`**：网线没插，或者对端没通电。插上线、确认对端设备开着，再读一次。

**`Speed` 比 `Supported link modes` 里的最高值低**：协商结果，不是故障。按顺序换：先换网线，再换交换机上的另一个口，再换对端设备。三样都换过还是低，说明对端只支持这个速率。

**两个网口，只有一个能用**：先把网线换到另一个口试一次，排除是线或交换机端口的问题。确认是接口本身的问题，按[第 1 卷第 11 章](../01-开箱与安装/11-收货验收.md)的做法记录清楚是哪一个口，联系卖方。

**`nmcli device wifi list` 什么都不显示**：先看天线装了没有、`rfkill list` 里有没有被屏蔽，处理办法见[第 1 卷第 12 章](../01-开箱与安装/12-硬件问题处理.md)。

**Wi-Fi 能连上但速度很慢、经常断**：换个位置再测一次；`iw dev 无线设备名 link` 看信号强度。这台机器当服务用就接网线，别在 Wi-Fi 上花时间。

**USB-C 接显示器没有画面**：三件事按顺序查。一，这个口支不支持视频输出（看机身标识和规格表，[第 1 卷第 2 章](../01-开箱与安装/02-接口与接线.md)）；二，系统版本是不是太旧（上面引的 Ubuntu 24.04.4 修复过 Type-C 视频输出的缺陷，[第 1 卷第 9 章](../01-开箱与安装/09-系统更新.md)）；三，换 HDMI 或 DisplayPort 直连试一次，分清是接口的问题还是显示器的问题。**不支持视频的 USB-C 口接显示器没画面，是正常的，不算故障**（第 17 章）。

**`ls /sys/bus/thunderbolt/devices/` 提示目录不存在**：属正常。说明这台机器没有 USB4 或雷电控制器，或者内核没认出来。不影响普通 USB 设备的使用。

**外接硬盘接上去速度只有标称的一小半**：先确认插的是哪个口——同一台机器上不同 USB 口的规格不一样，插错口速度差很多。再看是不是和显示器共用一个口在分带宽。都排除了再看盘本身和线材。

**`iperf3` 测出来只有标称的一半**：先换线、换交换机端口、换对端机器各测一次。三样都换过还是一半，可能是对端机器的网卡或者中间某台交换机的瓶颈。**`iperf3` 测的是整条链路，不是这台机器的网口**。

**`dd` 测写入的时候速度一开始很高然后掉下来**：正常。很多固态硬盘有一段高速缓冲区，写满之后速度回落到稳态。看的是**回落之后的稳态值**，和第 12 章看温度频率是同一个道理。

**改了静态 IP 之后连不上网**：地址、掩码、网关、DNS 里有一项填错了。在机器跟前把方式改回“自动（DHCP）”，恢复之后再重来。这也是为什么推荐在路由器上做 DHCP 保留。

**从另一台机器 `ping` 不通这台机器**：先确认两台在同一个局域网（地址前三段通常一样）；再确认这台机器的防火墙状态（第 14 卷）。**在排查完之前不要关防火墙**。
