# 07　BIOS 入口

## 完成结果

能在自己这台机器上进入 BIOS 设置界面，认得出界面上几个常见的菜单分区，知道本卷后面要改的那几项设置大致藏在哪一类菜单下，进不去的时候有一串可以逐条试的办法。

## 开始前需要准备什么

- 一台**有线**键盘，直接插在机身的 USB 口上。无线键盘、KVM 切换器、扩展坞上的键盘在自检阶段可能还没被识别，这是进不去 BIOS 最常见的原因之一；
- 一台用 HDMI 或 DP 直接接在机身上的显示器，不走转接头；
- 你这台机器的品牌和型号（[第 1 卷第 1 章](../01-开箱与安装/01-包装与配件.md)记过）；
- 手机，用来拍下 BIOS 界面的原始状态；
- **本章只带你进去看，不改任何设置。** 改 UMA 在第 9 章，改功耗档位在第 10 章，改风扇策略在第 11 章。

> **⚠️ BIOS 里改错设置可能让机器开不了机。** 本章只进去看，看完原样退出。真要改的时候，先用手机把那一屏拍下来，一次只改一项。改坏了的恢复办法是重新进 BIOS 选 `Load Optimized Defaults` 或 `Restore Defaults`，再按 `F10` 保存退出，分品牌做法见[第 1 卷第 12 章](../01-开箱与安装/12-硬件问题处理.md)。**恢复默认值会把 UMA Frame Buffer Size 一起改回出厂值，恢复之后要按第 9 章重新设回最低档。**

## 新词

**固件**（Firmware）：写死在硬件里的一段程序，负责让这块硬件自己先跑起来。它不装在硬盘上，硬盘格式化、重装系统都不会动它。主板上的那一份是最主要的固件，按下电源键之后最先跑的就是它。

**BIOS**：主板固件的设置界面。严格说 BIOS 是上一代固件的名字，现在的机器用的是 UEFI，但厂商菜单、说明书和用户都习惯把这个设置界面叫 BIOS，本教材跟随这个叫法。

**UEFI**：现在这一代主板固件的规范，取代了老的 BIOS 规范。本教材的安装方式要求启动模式是 UEFI 而不是 Legacy／CSM，这一项在[第 1 卷第 7 章](../01-开箱与安装/07-安装Ubuntu.md)装系统时已经确认过。

**自检**（POST，Power-On Self-Test）：按下电源键之后、加载操作系统之前，固件对硬件做的一轮检查。进 BIOS 的按键窗口就在这个阶段，操作系统还没参与。

**快速启动**（Fast Boot）：固件里的一个选项。开启后跳过一部分自检来缩短开机时间，代价是按键窗口变短，有的机型上等于没有。

**恢复默认值**（Load Optimized Defaults / Restore Defaults）：把 BIOS 里所有设置项一次性改回出厂状态的功能。它不动硬盘上的数据。

## 先说清楚一件事：BIOS 界面各家不一样

Max395 是 AMD 的芯片，BIOS 是**整机厂**做的。同一颗芯片，GMKtec、Beelink、Framework、HP 交出来的设置界面在布局、菜单名、选项名、能不能改上都不同，同一个品牌不同固件版本之间也会变。

所以本章给的是两样东西：**所有机器共有的那部分**（怎么进、界面大致分成哪几块、哪一类菜单管哪一类事），和**分品牌的线索**（按键、常见菜单路径）。**本章不保证你屏幕上看到的和这里写的一模一样。** 找不到对应项时，按功能去找，不要按名字硬对。

## 怎么进 BIOS

1. 机器完全关机；
2. 按下电源键；
3. 屏幕出现品牌 Logo 的**那一瞬间**开始按对应按键，每秒按两三下，一直按到设置界面出来为止。

按早了没用（固件还没开始接收键盘输入），按晚了窗口已经过去。第一次没成功就重启再来，多试两次。有的机型窗口只有 1 秒左右。

分不清按哪个键的时候，`Del` 和 `F2` 交替按，这两个覆盖了绝大多数情况。

## 分品牌按键表

| 品牌 | 进 BIOS 常见按键 | 启动设备选择菜单常见按键 |
| --- | --- | --- |
| GMKtec EVO-X2 / EVO-X3 | `Del` 或 `F2` | `F7` 或 `F12` |
| Beelink GTR9 Pro | `Del` 或 `F2` | `F7` 或 `F12` |
| Framework Desktop | `F2`，或按住电源键等待提示 | `F12` |
| HP ZBook Ultra G1a | `F10` 或 `Esc` | `F9` |
| 其他品牌 | 通常是 `Del`、`F2` 或 `F12` | 通常是 `F12` 或 `Esc` |

这张表和[第 1 卷第 7 章](../01-开箱与安装/07-安装Ubuntu.md)装系统时用的是同一份，来自项目补充材料与各品牌的通行做法，**本项目未逐机型实测，按键随固件版本变化，需要核验**。以你机器随附的说明书或品牌官网的支持页为准。

**启动设备选择菜单是另一个东西**：它只列出这次开机从哪个设备启动（硬盘、U 盘），不是设置界面。装系统和用恢复 U 盘时用它，改设置要进 BIOS。

## BIOS 界面的常见分区

多数机型的菜单大致分成下面这几块。名字各家不同，功能归属是共通的。

| 分区常见名称 | 里面是什么 |
| --- | --- |
| Main / Information / 主页 | 只读信息：机型、**固件版本号和日期**、CPU 型号、内存容量、系统时间。第 8 章要记的当前版本号就在这里 |
| Advanced / 高级 | 绝大多数功能设置。显存分配、集成显卡、USB、存储控制器多在这一类下面 |
| AMD CBS / AMD PBS | AMD 给整机厂的通用配置模板，通常挂在 Advanced 下面，层级很深。Framework Desktop 的显存分配就在这条路径里 |
| Chipset / 芯片组 | 有的机型把显存分配、集成显卡放这里，而不是 Advanced |
| Boot / 启动 | 启动顺序、UEFI 与 Legacy（CSM）的选择、Secure Boot、Fast Boot |
| Security / 安全 | 开机密码、BIOS 密码、Secure Boot 的密钥管理 |
| Power / ACPI / Power Management | 来电自启、唤醒方式，部分机型的性能与功耗档位也在这里 |
| H/W Monitor / PC Health / 硬件监控 | 温度、风扇转速、电压的实时读数，风扇策略常挂在这里 |
| Save & Exit / 退出 | 保存退出、放弃修改退出、恢复默认值 |

界面底部或右侧通常有一栏按键说明（方向键移动、`Enter` 进入、`Esc` 返回、`F9` 恢复默认、`F10` 保存退出）。**每次拿不准就先看这一栏**，它写的是你这台机器的实际按键，比任何教程可靠。

## 哪些菜单和本教材有关

| --- | --- | --- |

## 进不去怎么办

按顺序试，一次只改一个条件。

**一、按键时机和方式**

Logo 一出现就开始按，每秒按两三下。有的固件认“反复按”，有的认“按住不放”，两种都试一次。

**二、换键盘和换口**

用有线键盘，直接插机身**后面板**的 USB 口。拔掉 KVM 切换器、扩展坞、USB 集线器、无线键鼠的接收器。部分机型在自检阶段只有一部分 USB 口供电（**需要核验**，以你的机型说明书为准），所以后面板的口逐个试一遍。

**三、显示器点亮太慢，画面出来时窗口已经过去**

换成 HDMI 或 DP 直连，不走转接头、扩展坞、显示器的 USB-C 口。开机前先把显示器的输入源手动选到实际插线的那个通道，别让它自己搜。

**四、快速启动开着**

Fast Boot 开着的时候按键窗口可能短到按不进去。这一项本身在 BIOS 里，进不去就改不了，所以走下面第五条。

**五、从已经装好的 Ubuntu 里直接进**

在 Ubuntu 桌面打开终端，执行：

```bash
systemctl reboot --firmware-setup
```

机器会重启并**直接进入 BIOS 设置界面**，不需要抢按键。这条命令要求固件声明支持这个功能，不支持时会报错，报错属正常，退回按键的办法。**本项目未在 Max395 机型上实测过这条命令，需要核验。**

**六、放电重来**

拔掉电源适配器，按住电源键 10 秒（这时没通电，是把机身内的残余电放掉），再插电开机。这一步和[第 1 卷第 12 章](../01-开箱与安装/12-硬件问题处理.md)里那条是同一个动作。

**七、还是进不去**

如果同时还有“开机没有画面”“电源灯不亮”“风扇不转”这类现象，问题不在按键上，按[第 1 卷第 12 章](../01-开箱与安装/12-硬件问题处理.md)的症状表排查。

## 这一章涉及的可改设置

**快速启动（Fast Boot）**

- **默认状态**：随整机厂而定，出厂开启或关闭都有可能。进 BIOS 后在 Boot 菜单里读出你这台的当前值，先记下来（**本项目未逐机型记录，需要核验**）；
- **什么情况才需要改**：只有在按键始终进不去 BIOS、并且已经排除了键盘和显示器的原因时，才把它关掉。开机快几秒不值得为它冒任何风险；
- **改完怎么验证**：重启，Logo 停留时间明显变长，按键能进入 BIOS；
- **怎么恢复**：进 BIOS 把这一项改回你记下来的原值。忘了原值就用 `Load Optimized Defaults`，**恢复默认之后要按第 9 章重新设一遍 UMA Frame Buffer Size**。

## 正常结果

按下对应按键后，屏幕出现一个纯文字或简单图形的设置界面。你能在 Main 或 Information 里看到机型、固件版本号和日期、CPU 型号、内存容量；用方向键能在几个菜单之间移动；底部有按键说明。

看完之后，按 `Esc` 退到主界面，选 `Discard Changes and Exit`（放弃修改退出）或直接按 `Esc` 确认退出，机器重启进入 Ubuntu，什么都没变。

## 看到不同结果怎么办

**按了半天直接进了 Ubuntu**：按键时机不对或键盘没被识别，按“进不去怎么办”那一节从第一条开始试。

**屏幕一直黑的，连 Logo 都没出现**：这不是按键的问题，是显示或供电的问题，按[第 1 卷第 12 章](../01-开箱与安装/12-硬件问题处理.md)的“通电有风扇声，显示器无信号”那一节排查。

**进去了，但界面和本章描述的完全不一样**：正常。各家 BIOS 差别很大，按功能找，别按名字硬对。找“显存”就搜含 UMA、iGPU、Graphics、VRAM 字样的项，找“风扇”就搜含 Fan 字样的项。

**菜单里找不到显存分配这一项**：三种可能——藏在 AMD CBS 下面很深的层级里、被整机厂锁起来没开放、这个固件版本没有这一项。先按第 9 章“BIOS 里没有这一项”那一段处理，那里给了不改 BIOS 也能走的路。

**进 BIOS 要输入密码**：二手机或公司统一采购的机器可能被设过 BIOS 密码。密码不在你手上就联系卖方或原持有人，不要自己拆机清除，那会碰到保修问题（[第 1 卷第 12 章](../01-开箱与安装/12-硬件问题处理.md)）。

**在 BIOS 界面里就死机、自动重启、风扇狂转**：这个阶段还没加载操作系统，和 Ubuntu 无关，是硬件或供电层面的信号，按[第 1 卷第 12 章](../01-开箱与安装/12-硬件问题处理.md)处理，必要时直接联系卖方。

**按了 `F10` 之后提示保存，但你其实什么都没改**：选“否”或按 `Esc` 取消也可以。误保存一次不会出问题，因为值没变。
