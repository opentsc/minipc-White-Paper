# 04　单张跑通

## 这一章的任务

一张发票进去，一行 JSON 出来。

**这是这一卷的核心一章。** 前三章准备的东西——服务、schema、提示词——在这一章接成一条线。做完之后你有一个能跑的脚本 `~/ai/scripts/ocr_one.py`，跑一次处理一份文件。

**第 5 章那个批量脚本就是拿它当零件用的**，所以这一章的东西要跑通、要看懂。

## 开始前

- [第 2 章](02-环境准备.md)做完，`ocr-vlm` 服务在跑。**先跑一句 `systemctl status ocr-vlm --no-pager` 确认它是 `active (running)`**；
- [第 3 章](03-定义字段.md)做完，`~/ai/scripts/invoice_schema.json` 这个文件在；
- 手上有一份单据，PDF 或者图片都行；
- 本章要装一个小工具，几 MB；
- 60 分钟。

## 新词

**`pdftoppm`**：**把 PDF 的每一页转成一张图片。** [第 7 卷第 2 章](../07-RAG/02-收集与整理文档.md)装过的 `poppler-utils` 那一包里就有它，那一章用的是同一包里的 `pdftotext`。**两个工具方向相反**——那个是从 PDF 里抽字，这个是把 PDF 拍成图。**扫描件里没有字可抽，所以这一卷用的是后者。**

**DPI**（每英寸点数，Dots Per Inch）：**转出来的图有多清楚。** 数字越大，图越大越清楚，占的视觉 token 也越多、跑得越慢。**这一卷默认给 200**，小字看不清再往上调。

**临时目录**：程序运行中间临时用一下、用完自动删掉的一个目录。**PDF 转出来的那些图片就放在这里**，脚本跑完它们自己没了，不占你的硬盘。

**标准库**：Python 装好就自带的那些功能，不用另装。**本章这个脚本只用标准库**，一句 `pip install` 都不用跑——[第 6 卷第 8 章](../06-本地模型/08-局域网API.md)那个虚拟环境在这一卷用不着。

**命令行参数**：跑脚本的时候跟在后面的那些东西，形如 `--dpi 300`。**它们让同一个脚本能干不一样的活，不用改代码。**

## 完整脚本

新建文件 `~/ai/scripts/ocr_one.py`，**下面这一整段照抄进去，一个字不要漏**：

```python
#!/usr/bin/env python3
# ocr_one.py —— 一张单据进去，一行 JSON 出来
# 用法：python3 ~/ai/scripts/ocr_one.py ~/ai/data/invoices-2026-08/票据-0731-018.pdf
# 前提：第 2 章那个 ocr-vlm 服务在跑，第 3 章那份 schema 文件在

import argparse
import base64
import json
import subprocess
import sys
import tempfile
import urllib.error
import urllib.request
from pathlib import Path

API_BASE = "http://127.0.0.1:8090/v1"
SCHEMA_FILE = Path.home() / "ai" / "scripts" / "invoice_schema.json"

IMAGE_SUFFIXES = {".png", ".jpg", ".jpeg", ".bmp", ".tif", ".tiff", ".webp"}
MIME_TYPES = {
    ".png": "image/png",
    ".jpg": "image/jpeg",
    ".jpeg": "image/jpeg",
    ".bmp": "image/bmp",
    ".tif": "image/tiff",
    ".tiff": "image/tiff",
    ".webp": "image/webp",
}

PROMPT = (
    "这是一张发票的图片。把票面上的信息读出来，严格按给定的 JSON 结构输出，"
    "不要输出 JSON 以外的任何文字。看不清或者票面上没有的字段，填空字符串，"
    "不要猜，也不要编。金额和日期照票面原样抄，不要换算，不要改写格式。"
)


def response_format(schema):
    """告诉服务：输出必须长成 schema 这个样子。

    这个写法随 llama.cpp 版本变化。下面这一行对不上的时候，换成 OpenAI 那一套：
    return {"type": "json_schema",
            "json_schema": {"name": "invoice", "strict": True, "schema": schema}}
    """
    return {"type": "json_schema", "schema": schema}


def http_json(url, payload=None, timeout=600):
    """发一个请求，把回来的 JSON 解析成 Python 的字典。payload 留空就是 GET。"""
    data = None
    headers = {}
    if payload is not None:
        data = json.dumps(payload).encode("utf-8")
        headers["Content-Type"] = "application/json"
    request = urllib.request.Request(url, data=data, headers=headers)
    with urllib.request.urlopen(request, timeout=timeout) as response:
        return json.loads(response.read().decode("utf-8"))


def detect_model(api_base, timeout=30):
    """问服务现在加载的是哪个模型，省得自己抄名字。"""
    info = http_json(api_base + "/models", timeout=timeout)
    return info["data"][0]["id"]


def load_schema(schema_path):
    """把第 3 章那份 schema 读进来。"""
    return json.loads(Path(schema_path).read_text(encoding="utf-8"))


def to_images(src, dpi, max_pages, workdir):
    """PDF 先转成图片；本来就是图片的原样用。"""
    suffix = src.suffix.lower()
    if suffix in IMAGE_SUFFIXES:
        return [src]
    if suffix != ".pdf":
        raise ValueError("只认 PDF 和常见图片格式，这个认不了：" + src.name)
    prefix = str(Path(workdir) / "page")
    subprocess.run(
        [
            "pdftoppm", "-png",
            "-r", str(dpi),
            "-f", "1",
            "-l", str(max_pages),
            str(src), prefix,
        ],
        check=True,
    )
    return sorted(Path(workdir).glob("page*.png"))


def to_data_uri(image_path):
    """把一张图读成一串文本，好塞进 JSON 里发出去。"""
    path = Path(image_path)
    mime = MIME_TYPES.get(path.suffix.lower(), "image/png")
    encoded = base64.b64encode(path.read_bytes()).decode("ascii")
    return "data:" + mime + ";base64," + encoded


def read_one(src, schema, api_base, model, dpi=200, max_pages=2, timeout=600):
    """一份单据进来，一个字典出去。这个函数第 5 章还要用。"""
    with tempfile.TemporaryDirectory() as workdir:
        pages = to_images(src, dpi, max_pages, workdir)
        if not pages:
            raise RuntimeError("一页都没转出来，先确认这个文件能正常打开")
        content = [
            {"type": "image_url", "image_url": {"url": to_data_uri(page)}}
            for page in pages
        ]
        content.append({"type": "text", "text": PROMPT})
        payload = {
            "model": model,
            "messages": [{"role": "user", "content": content}],
            "response_format": response_format(schema),
            "temperature": 0,
            "max_tokens": 2048,
        }
        answer = http_json(api_base + "/chat/completions", payload, timeout=timeout)
    text = answer["choices"][0]["message"]["content"]
    return json.loads(text)


def main():
    parser = argparse.ArgumentParser(description="一张单据转成一行 JSON")
    parser.add_argument("src", help="要读的那份 PDF 或者图片")
    parser.add_argument("--api", default=API_BASE, help="第 2 章那个服务的地址")
    parser.add_argument("--model", default=None, help="模型名，不填就问服务要")
    parser.add_argument("--schema", default=str(SCHEMA_FILE), help="第 3 章那份 schema")
    parser.add_argument("--dpi", type=int, default=200, help="PDF 转图片的清晰度")
    parser.add_argument("--max-pages", type=int, default=2, help="最多读前几页")
    parser.add_argument("--timeout", type=int, default=600, help="最多等多少秒")
    args = parser.parse_args()

    src = Path(args.src).expanduser()
    if not src.is_file():
        sys.exit("找不到这个文件：" + str(src))

    schema_path = Path(args.schema).expanduser()
    if not schema_path.is_file():
        sys.exit("找不到 schema 文件：" + str(schema_path) + "，先做完第 3 章")
    schema = load_schema(schema_path)

    try:
        model = args.model or detect_model(args.api)
        record = read_one(
            src, schema, args.api, model,
            dpi=args.dpi, max_pages=args.max_pages, timeout=args.timeout,
        )
    except urllib.error.URLError as error:
        sys.exit("连不上服务（" + args.api + "）：" + str(error.reason))

    print(json.dumps(record, ensure_ascii=False, indent=2))


if __name__ == "__main__":
    main()
```

**用文本编辑器新建这个文件，粘贴，保存。** 终端里的做法是 `nano ~/ai/scripts/ocr_one.py`，粘完 `Ctrl+O` 回车、`Ctrl+X`。

## 这个脚本在干什么

**从上往下六段，一段一段说。**

### 一、开头那一堆 import 和几个常量

```python
API_BASE = "http://127.0.0.1:8090/v1"
SCHEMA_FILE = Path.home() / "ai" / "scripts" / "invoice_schema.json"
```

**会变的东西拎到最上面**，这是[第 6 卷第 8 章](../06-本地模型/08-局域网API.md)那个 `BASE` 和 `MODEL` 的老做法。地址是第 2 章那个服务，schema 是第 3 章那份文件。

`IMAGE_SUFFIXES` 和 `MIME_TYPES` 两张表管的是同一件事的两面：**哪些后缀算图片**，以及**每种后缀在 data URI 里该写成什么**。JPG 写成 `image/jpeg` 而不是 `image/jpg`，这一格写错的话服务可能认不出这是图。

`PROMPT` 就是[第 3 章](03-定义字段.md)最后那四句话，**原样搬过来的**。要改提示词就改这里。

### 二、`response_format`：把 schema 交给服务

```python
return {"type": "json_schema", "schema": schema}
```

**这一行就是[第 3 章](03-定义字段.md)说的那个约束。** 它跟着请求一起发过去，服务在模型每吐一个字的时候拿它比一遍。

**上面那段说明文字里还写了另一种写法。** 这个写法随 llama.cpp 版本变化，**服务报参数不认的时候，把那一行换成说明里那三行**，其余一个字不用动。

### 三、`http_json` 和 `detect_model`：跟服务说话

`http_json` 是这个脚本里唯一一个发网络请求的地方。**给了 `payload` 就是 POST，没给就是 GET**，两种都用得上。

- **`timeout=600`** —— 最多等 600 秒。**这一项不能省**，[第 6 卷第 8 章](../06-本地模型/08-局域网API.md)说过理由：模型第一次要加载，图又大，默认不设超时的话程序会卡死在那儿；
- **`ensure_ascii` 那些细节在最后一行**，先不管。

`detect_model` 干的是[第 2 章](02-环境准备.md)你手动做过的那一步——**问 `/v1/models`，把 `id` 拿出来**。有了它你不用把模型名抄进脚本，**换模型重启服务之后脚本照样跑**。

### 四、`to_images`：PDF 先变成图

**模型只看得懂图，看不懂 PDF。** 所以进来的东西分两种走法：

- **本来就是图片**（PNG、JPG 这些），原样用，不做任何处理；
- **是 PDF**，用 `pdftoppm` 转成 PNG；
- **两样都不是**，直接报错。Word 文档、Excel 表格走不到这一卷来。

那条 `pdftoppm` 命令的四个参数：

- **`-png`** —— 转成 PNG 格式；
- **`-r 200`** —— 每英寸 200 个点，就是上面新词里那个 DPI。这个数从命令行传进来；
- **`-f 1 -l 2`** —— 从第 1 页转到第 2 页。**发票通常就一页，给 2 页是留个余量**——有些扫描件把票和附件扫在一起了；
- **最后两项** —— 输入文件，和输出文件的前缀。转出来的文件会叫 `page-1.png`、`page-2.png` 这样。

**这些图全写在临时目录里**，函数返回之后自动删掉。

### 五、`to_data_uri` 和 `read_one`：拼请求，发出去

`to_data_uri` 就是[第 2 章](02-环境准备.md)那条 `base64 -w 0` 命令的 Python 写法，**做的事一模一样**。

`read_one` 是这个脚本的正主，**四步**：

1. **开一个临时目录**，PDF 转成图放进去；
2. **拼 `content`**。[第 2 章](02-环境准备.md)新词里那个“图文一起发”——先是若干张图，最后跟一句提示词。**顺序是图在前、话在后**；
3. **拼 `payload`**。除了 `model`、`messages` 和上面那个 `response_format`，还有两项：
   - **`"temperature": 0`** —— [第 6 卷第 8 章](../06-本地模型/08-局域网API.md)那张参数表里的那一个。**抄东西这件事不需要创造性，往 0 靠**，同一张票跑两遍结果尽量一样；
   - **`"max_tokens": 2048`** —— 生成长度的上限。**八个字段的 JSON 远用不到这么多**，给足了免得被截断（[第 6 卷第 8 章](../06-本地模型/08-局域网API.md)那个 `finish_reason` 变成 `length` 的情况）；
4. **发出去，把 `choices[0].message.content` 拿出来，`json.loads` 解析成字典。**

**最后这一步能直接解析、不用写容错，全靠第 3 章那个约束。** 没有它的话这里要写一堆代码去把 JSON 从一段废话里抠出来。

**`read_one` 这个函数第 5 章会直接拿去用**，所以它把该传的东西全做成了参数，没有写死。

### 六、`main`：把命令行上的东西接进来

`argparse` 那一段定义了七个东西：一个必须给的（要读的文件），六个可选的开关。**跑一句 `python3 ~/ai/scripts/ocr_one.py --help` 能把它们全列出来。**

后面三段是三道门，**每一道都在出错的时候告诉你该去哪儿**：

- 文件找不到；
- schema 文件找不到，**顺带提醒你回第 3 章**；
- 连不上服务，**把地址一起打出来**。

最后 `json.dumps(..., ensure_ascii=False, indent=2)` 把结果打印出来。**`ensure_ascii=False` 这一项少不得**——不写的话中文会被打成 `发票` 这样的东西，看不了。

## 两个会用到的开关

**`--dpi`**：

```bash
python3 ~/ai/scripts/ocr_one.py 那份文件.pdf --dpi 300
```

**小字读不出来、或者读得零零散散的时候，把它调到 300 再试一次。** 代价是图变大，占的视觉 token 变多，跑得慢一些。**300 以上再往上调通常不划算**，图片本身糊的话调多高都没用。

**`--max-pages`**：

```bash
python3 ~/ai/scripts/ocr_one.py 那份文件.pdf --max-pages 1
```

**确定每份就一页的话调成 1**，少发一张图，快一点，也少一个串页的机会。

## 结果对不对，怎么看

**这一节要真的做，做完你对这条路的判断才建立得起来。**

**把 JSON 和原单据并排放着，一格一格对。** 别只看一眼觉得像就过了——[第 6 卷第 11 章](../06-本地模型/11-视觉模型.md)那句话在这里是纪律：**它错的时候语气一样肯定，输出一样漂亮。**

**按这个顺序对，前三格最要紧：**

**一、价税合计。** 这是台账里唯一一个会被拿去加总的数，**错一位就是错几千块**。对完顺手做一次心算：金额加税额，等不等于价税合计。**等不上就是有一格读错了**，具体哪一格再找。

**二、发票号码。** 一位一位念着对，别扫一眼。**十几二十位的数字串，中间错一位看不出来。**

**三、开票日期。** 看它有没有替你改格式。**票面写 `2026年07月18日`，它给你 `2026-07-18`，这就是没照原样抄**——回第 3 章那段提示词，把最后一句加重一点。

**四、购买方和销售方。** 最常见的错是**两个反了**。发票上这两栏挨着，位置一错整行数据的方向就反了。

**五、发票种类。** 看它是不是老老实实从那四个里挑的。

**六、金额和税额。** 看有没有把大写那个填进来。

**对完之后你手上有一份东西：这一张的哪几格错了。** 拿它去做两件事：

- **回第 3 章改提示词。** 同一格连着几张都错，多半是那段话没说到位；
- **记下来，留给第 7 章。** 那一章要写校验规则，规则拦什么，就照这份记录里最常错的那几格来定。

> **一张对完不够，至少对 10 张。** 一张的结果说明不了什么——**它可能正好是最清楚的那张，也可能正好是最糊的那张。**

## 有做不出来的地方

两种最常见的，先自己看一眼：

- **连不上服务** —— 脚本会直接告诉你 `连不上服务`。跑 `systemctl status ocr-vlm --no-pager` 看它在不在跑，不在就 `sudo systemctl start ocr-vlm`，然后等模型加载完；
- **说找不到 `pdftoppm`** —— 上面那个 `poppler-utils` 没装成，回去再跑一次。

其余的到[第 15 卷：故障排查](../15-故障排查/README.md)按症状查。
