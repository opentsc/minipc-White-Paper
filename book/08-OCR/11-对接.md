# 11　对接

## 这一章的任务

把台账送到客户已经在用的地方去。

**前十章做出来的东西，终点是 `~/ai/projects/invoice-ocr/ledger.csv`。** 这个文件在你的机器上，客户的人不在你的机器上。

**这一章解决最后那一段路。** 三条常见的去处，各给一条做法：

```text
一、进 Excel　　　客户最多的一类。他要的就是一张表，能筛、能透视、能发给别人
二、进数据库　　　客户已经有一个装着别的数据的地方，这张台账要并进去
三、给别的系统　　客户有一套自己的软件，它要来取这批数据
```

**这三条里，第一条覆盖大多数客户，而且最省事。** 后面两条不是升级版，是不同的场合——**别因为数据库听着专业就往那边推**。

**这一章还要说一件跟技术没关系、但更影响收入的事**：**对接是这门生意里最容易超出报价的地方**，最后一节专讲。

## 新词

**xlsx**：Excel 2007 以后那种文件格式，就是文件名以 `.xlsx` 结尾的那些。**它和 CSV 的区别是它能存格式、公式和多个工作表**（[第 5 章](05-批量处理.md)那一节说过）。

**openpyxl**：一个 Python 包，**用来读写 xlsx 文件**。它不是 Python 自带的，要单独装。

**数据库**：**一个专门用来存表格数据、并且能按条件快速查出来的东西。** 一个数据库里可以有很多张表。

**表**（table）：数据库里的一张表。**和 Excel 里的一张表是一个意思**——第一行是列名，下面是很多行数据。

**SQL**：**跟数据库说话用的那套写法。** 形如 `SELECT 销售方名称 FROM ledger WHERE 金额 > 1000`——从 `ledger` 这张表里，把金额大于 1000 的那些行的销售方名称挑出来。**它是一种查询语言，不是编程语言**，句子读起来跟英语差不多。

**SQLite**：**最省事的一种数据库。** 它不是一个要开机跑着的服务，**它就是硬盘上的一个文件**。Python 自带了它，一句 `pip install` 都不用跑。**这一章的数据库那一节全部用它。**

**MySQL、PostgreSQL**：**另外两种数据库，要单独装、要有一个服务一直跑着。** 公司里已经有的数据库，多半是这两个中的一个。

**HTTP 接口**（也常被叫作 API）：**一个程序在某个端口上等着，别的程序按约定好的地址来问，它按约定好的格式答。** [第 6 卷第 8 章](../06-本地模型/08-局域网API.md)那个 Ollama 的接口就是一个，这一卷第 2 章那个 `ocr-vlm` 服务也是一个。**这一章要自己开一个。**

**只读接口**：**只能来取、不能往里写的接口。** 这一章给的那个就是只读的——对方读得到台账，改不了你的台账。

## 对接之前先问四个问题

**这一节比后面所有代码都重要。**

**问清楚这四件事再动手。** 没问就动手，八成要返工，而且返工的时间不在报价里。

### 一、你们现在拿什么装这些数据

**这句话要原样问出口，不要问“你们要什么格式”。**

客户回答“要什么格式”的时候，答案常常是他以为你想听的那个；回答“现在拿什么装”的时候，答案是实情。

常见的三种回答：

- **“现在是小王手工录进这个 Excel 表里”** —— 那就走第一条路，**而且要看一眼小王那张表长什么样**；
- **“录进我们的财务软件／进销存”** —— 走第三条路，**先问清楚那套软件叫什么、有没有导入功能**；
- **“录进我们自己开发的系统”** —— 走第二条或者第三条，**这一类要找到客户那边的技术人员，越早越好**。

### 二、字段怎么对应

**你的台账列名是你定的**（[第 3 章](03-定义字段.md)那份 schema），**客户那边的列名是他早就定好的。**

**这两套名字要摆在一起，一格一格对。** 常见的对不上有三种：

- **名字不一样，意思一样。** 你叫“价税合计”，他那张表叫“含税金额”；
- **你有他没有。** 你抽了“发票种类”，他那张表根本没有这一列；
- **他有你没有。** 他那张表有一列“部门”“项目号”“记账凭证号”，**这些票面上根本没有**，[第 3 章](03-定义字段.md)那句“票面上一定有吗”在这里再响一次——**票面上没有的，模型给不了你，这一列只能人填或者从别的地方来。**

**第三种是最容易出事的一种**，因为客户会默认它也归你。**要当场说清楚。**

### 三、多久要一次

- **一个月一次** —— 手动跑一遍，导出来发过去，够了；
- **每天一次** —— 接[第 6 章](06-文件夹监测.md)那个定时任务；
- **随时都要最新的** —— 那才需要第三条路那个接口。

**大多数客户回答的是第一种。** 别按第三种去做第一种的活。

### 四、数据不对的时候找谁

**这一条最容易被跳过，也最容易在三个月后变成麻烦。**

台账进了客户的系统，**过一阵子一定会有人发现某一行不对**。这时候要有人说得清：

- 这一行是**读错了**（回[第 7 章](07-错的怎么拦.md)那套复核），
- 还是**原件本来就那样**，
- 还是**进他们系统之后被别人改过**。

**做法是留一条回溯的路**：台账第一列那个文件名（[第 5 章](05-批量处理.md)那句“回溯的钥匙”）**要跟着数据一起进客户的系统**，哪怕他们那张表本来没有这一列。

**这一列要不要留、留在哪儿，是要跟客户谈的**，不是你单方面决定的。

## 一、进 Excel

**这是最常见的一条路，也是最短的一条。**

### 最省事的做法：CSV 直接打开

`ledger.csv` 双击就能用 Excel 或者 LibreOffice Calc 打开（[第 5 章](05-批量处理.md)那个 `utf-8-sig` 记号管的就是这件事）。

**客户只是要一张表看看、筛一筛、发给会计**，到这里就结束了，**不需要写任何代码**。

**要存成 xlsx 的话，[第 5 章](05-批量处理.md)那条最省事的路还在**：用 LibreOffice Calc 打开，另存为 Excel 2007-365（.xlsx）。

### 什么时候值得写脚本

**三种情况下，手动另存为会变成负担：**

- **每周或者每天都要交一次。** 手动点五下，一年点一千下；
- **客户要格式。** 表头加粗、金额靠右保留两位小数、首行冻结、列宽合适、能直接点筛选；
- **交出去的东西要一次比一次一样。** 手动做，做十次有十个样子。

**这三条里只要中一条，就写下面这个脚本。**

### 完整脚本

新建 `~/ai/scripts/ledger_to_xlsx.py`，**下面这一整段照抄进去**：

```python
#!/usr/bin/env python3
# ledger_to_xlsx.py —— 把台账 CSV 写成一个带格式的 xlsx
# 用法：python3 ~/ai/scripts/ledger_to_xlsx.py ~/ai/projects/invoice-ocr/ledger.csv
# 前提：装过 openpyxl

import argparse
import csv
import sys
from pathlib import Path

try:
    from openpyxl import Workbook
    from openpyxl.styles import Alignment, Font, PatternFill
    from openpyxl.utils import get_column_letter
except ImportError:
    sys.exit("没装 openpyxl。先跑：python3 -m pip install --user openpyxl")

# 这几列按数字存、靠右对齐，别的一律当文本。名字对不上就当文本处理
NUMBER_COLUMNS = {
    "金额", "税额", "价税合计",
    "数量", "单价", "合计数量", "合计金额",
}

MIN_WIDTH = 8
MAX_WIDTH = 40


def read_rows(csv_path):
    """把 CSV 读成一个列表，第一行是表头。"""
    with csv_path.open("r", newline="", encoding="utf-8-sig") as handle:
        return list(csv.reader(handle))


def text_width(text):
    """估一个宽度。中文按两格算，英文和数字按一格。"""
    width = 0
    for char in str(text):
        width += 2 if ord(char) > 127 else 1
    return width


def to_number(text):
    """把票面上的金额变成一个数。变不了就返回 None。"""
    cleaned = str(text).replace(",", "").replace("，", "").replace(" ", "")
    if cleaned == "":
        return None
    try:
        return float(cleaned)
    except ValueError:
        return None


def write_header(sheet, header):
    """第一行：加粗、灰底、居中。"""
    sheet.append(header)
    bold = Font(bold=True)
    grey = PatternFill("solid", fgColor="DDDDDD")
    for index in range(1, len(header) + 1):
        cell = sheet.cell(row=1, column=index)
        cell.font = bold
        cell.fill = grey
        cell.alignment = Alignment(horizontal="center")


def format_numbers(sheet, header):
    """金额那几列转成数，保留两位小数，靠右。转不了的原样留着。"""
    for index, name in enumerate(header, start=1):
        if name not in NUMBER_COLUMNS:
            continue
        for line in range(2, sheet.max_row + 1):
            cell = sheet.cell(row=line, column=index)
            value = to_number(cell.value if cell.value is not None else "")
            if value is None:
                continue
            cell.value = value
            cell.number_format = "0.00"
            cell.alignment = Alignment(horizontal="right")


def fit_widths(sheet, header):
    """列宽按这一列最长的那格定，卡在上下限之间。"""
    for index, name in enumerate(header, start=1):
        widest = text_width(name)
        for line in range(2, sheet.max_row + 1):
            value = sheet.cell(row=line, column=index).value
            widest = max(widest, text_width("" if value is None else value))
        letter = get_column_letter(index)
        sheet.column_dimensions[letter].width = min(
            max(widest + 2, MIN_WIDTH), MAX_WIDTH,
        )


def main():
    parser = argparse.ArgumentParser(description="台账 CSV 转成带格式的 xlsx")
    parser.add_argument("csvfile", help="第 5 章那张 ledger.csv")
    parser.add_argument("--out", default=None, help="写到哪儿，不填就是同名的 .xlsx")
    parser.add_argument("--sheet", default="台账", help="工作表叫什么名字")
    args = parser.parse_args()

    csv_path = Path(args.csvfile).expanduser()
    if not csv_path.is_file():
        sys.exit("找不到这个文件：" + str(csv_path))

    rows = read_rows(csv_path)
    if not rows:
        sys.exit("这个 CSV 是空的：" + str(csv_path))

    header = rows[0]
    body = [row for row in rows[1:] if row]

    book = Workbook()
    sheet = book.active
    sheet.title = args.sheet

    write_header(sheet, header)
    for row in body:
        sheet.append(row)

    format_numbers(sheet, header)
    fit_widths(sheet, header)

    sheet.freeze_panes = "A2"
    sheet.auto_filter.ref = "A1:%s%d" % (
        get_column_letter(len(header)), sheet.max_row,
    )

    out_path = Path(args.out).expanduser() if args.out else csv_path.with_suffix(".xlsx")
    book.save(str(out_path))
    print("写好了 %d 行（不算表头）：%s" % (len(body), out_path))


if __name__ == "__main__":
    main()
```

```bash

```


**这个脚本做了五件手动另存为做不了的事：**

- **表头加粗、灰底、居中** —— 交出去的东西一眼看得出哪一行是表头；
- **金额那几列转成数** —— **这一条最要紧**。CSV 里所有东西都是文本（[第 3 章](03-定义字段.md)那条“全部用字符串”），文本状态的金额**在 Excel 里求不了和**。转成数之后客户选中一列，底下状态栏直接显示合计；
- **保留两位小数** —— `3296` 显示成 `3296.00`，和票面对得上；
- **首行冻结** —— 往下翻一百行，表头还在上面；
- **打开就带筛选** —— 客户点一下就能按销售方、按日期筛。

> **`NUMBER_COLUMNS` 那张表是要你改的。** 跑物流单那个变体（[第 9 章](09-变体-物流单与表格件.md)）的时候，`lines.csv` 里的数量和单价也要转成数；跑档案那个变体（[第 10 章](10-变体-旧档案批量数字化.md)）的时候，六格里一个数都没有，**这张表可以整个清空**。

> **发票号码不要放进 `NUMBER_COLUMNS`。** 二十位的数字串一旦被当成数，Excel 会显示成 `2.4417E+19`，**而且是不可逆的**——它先把后几位抹掉再显示。**这是这一节唯一一处会毁数据的地方，改那张表的时候盯一眼。**

### 客户有自己的模板怎么办

**很多客户不要你的表，要你把数据填进他那张表。**

**别把那张模板改成你的样子。** 那是他的表，上面可能有公式、有别的部门在用、有他习惯的顺序。

**做法是加一层对照**：在脚本最上面写一张“我的列名 → 他的列名”的表，写出来的时候按他的列名和顺序排。

```python
# 我的列名 → 客户那张表里的列名。没有对应的写 None，那一列就不输出
COLUMN_MAP = {
    "文件名": "凭证附件号",
    "发票号码": "发票号",
    "开票日期": "业务日期",
    "销售方名称": "往来单位",
    "价税合计": "含税金额",
    "发票种类": None,
}
```

**这张表放在脚本最上面，跟[第 7 章](07-错的怎么拦.md)那四项一个道理**——**会变的东西拎到最上面**，换一个客户只改这一处。

**这张对照表要客户确认过。** 你自己猜的对应关系，第一次交付就会被打回来。

## 二、进数据库

### 什么时候才需要它

**先说什么时候不需要：客户只是要一张表看，不需要。**

**需要它的信号有三个：**

- **数据要跟别的数据一起用。** 台账要和客户的付款记录、合同台账对着看；
- **量已经大到 Excel 不舒服。** 几万行的 CSV，打开慢、筛得慢、发不动；
- **别的程序要来读。** 第三条路那个接口，后面那半截通常也是从数据库里取。

**第一条最常见。** 而且注意它是客户那边的事——**是他有一个装着别的数据的地方，不是他想要一个数据库。**

### 从 SQLite 起步

**SQLite 的好处是它没有安装这一步。** Python 自带，数据库就是一个文件，**拷走、备份、删掉都跟一个普通文件一样**。

**它的边界也说清楚**：它是给一个程序、一台机器用的。**很多人同时往里写的场合它不合适**，那时候才轮到 MySQL 和 PostgreSQL。

### 完整脚本

新建 `~/ai/scripts/ledger_to_sqlite.py`，**照抄**：

```python
#!/usr/bin/env python3
# ledger_to_sqlite.py —— 把台账 CSV 装进一个 SQLite 数据库文件
# 用法：
#   python3 ~/ai/scripts/ledger_to_sqlite.py ~/ai/projects/invoice-ocr/ledger.csv
#   python3 ~/ai/scripts/ledger_to_sqlite.py ~/ai/projects/invoice-ocr/ledger.csv --ask "SELECT ..."
# 只用 Python 自带的东西，什么都不用装

import argparse
import csv
import sqlite3
import sys
from pathlib import Path

TABLE = "ledger"
KEY_COLUMN = "文件名"


def quoted(name):
    """列名带中文、带空格都行，两边加双引号交给 SQLite 自己认。"""
    return '"' + str(name).replace('"', '""') + '"'


def read_rows(csv_path):
    """把 CSV 读成表头加正文两部分。"""
    with csv_path.open("r", newline="", encoding="utf-8-sig") as handle:
        rows = list(csv.reader(handle))
    if not rows:
        sys.exit("这个 CSV 是空的：" + str(csv_path))
    return rows[0], [row for row in rows[1:] if row]


def create_table(conn, header):
    """每次重建这张表。列全部是文本，和 schema 那条“全部用字符串”一个道理。"""
    columns = ", ".join(quoted(name) + " TEXT" for name in header)
    conn.execute("DROP TABLE IF EXISTS " + quoted(TABLE))
    conn.execute("CREATE TABLE " + quoted(TABLE) + " (" + columns + ")")
    if KEY_COLUMN in header:
        conn.execute(
            "CREATE UNIQUE INDEX idx_ledger_key ON " + quoted(TABLE)
            + " (" + quoted(KEY_COLUMN) + ")",
        )


def insert_rows(conn, header, body):
    """一行一行装进去。格数对不上的、重名的，跳过并报一行。"""
    marks = ", ".join("?" for _ in header)
    columns = ", ".join(quoted(name) for name in header)
    statement = ("INSERT INTO " + quoted(TABLE)
                 + " (" + columns + ") VALUES (" + marks + ")")
    kept = 0
    skipped = 0
    for row in body:
        if len(row) != len(header):
            skipped += 1
            print("这一行有 %d 格，表头有 %d 格，跳过：%s"
                  % (len(row), len(header), row[:1]), file=sys.stderr)
            continue
        try:
            conn.execute(statement, row)
        except sqlite3.IntegrityError:
            skipped += 1
            print("这一行的 %s 前面已经有了，跳过：%s"
                  % (KEY_COLUMN, row[:1]), file=sys.stderr)
            continue
        kept += 1
    return kept, skipped


def show(conn, statement):
    """跑一句 SQL，把结果打在屏幕上。"""
    cursor = conn.execute(statement)
    names = [item[0] for item in cursor.description or []]
    rows = cursor.fetchall()
    if names:
        print(" | ".join(names))
    for row in rows:
        print(" | ".join("" if value is None else str(value) for value in row))
    print("（%d 行）" % len(rows))


def main():
    parser = argparse.ArgumentParser(description="台账 CSV 装进 SQLite")
    parser.add_argument("csvfile", help="第 5 章那张 ledger.csv")
    parser.add_argument("--db", default=None, help="数据库文件放哪儿，不填就是同目录的 ledger.db")
    parser.add_argument("--ask", default=None, help="装完之后跑一句 SQL")
    args = parser.parse_args()

    csv_path = Path(args.csvfile).expanduser()
    if not csv_path.is_file():
        sys.exit("找不到这个文件：" + str(csv_path))

    db_path = Path(args.db).expanduser() if args.db else csv_path.with_name("ledger.db")
    header, body = read_rows(csv_path)

    conn = sqlite3.connect(str(db_path))
    try:
        with conn:
            create_table(conn, header)
            kept, skipped = insert_rows(conn, header, body)
        print("装进了 %s" % db_path)
        print("表名 %s，%d 列，%d 行" % (TABLE, len(header), kept))
        if skipped:
            print("跳过 %d 行，原因看上面那几句" % skipped)
        print("---")
        show(conn, args.ask or ('SELECT * FROM ' + quoted(TABLE) + ' LIMIT 3'))
    finally:
        conn.close()


if __name__ == "__main__":
    main()
```

```text
表名 ledger，10 列，128 行

文件名 | 发票种类 | 发票号码 | 开票日期 | 购买方名称 | 销售方名称 | 金额 | 税额 | 价税合计 | 处理时间

（3 行）
```

### 三处值得单说

**一、每次都是重建，不是往后追加。**

```python
conn.execute("DROP TABLE IF EXISTS " + quoted(TABLE))
```

**这是[第 5 章](05-批量处理.md)那条刻意设计的延续**——那一章的台账每次从 `out/` 里重头汇，**这里的数据库每次从台账重头装**。

**好处是同一件事只有一个源头**：`out/` 里那堆 JSON 是唯一的真相，台账和数据库都是它的投影。**改了 JSON、重跑一遍，两边一起更新，不会出现哪一头是旧的。**

> **代价要知道**：客户在数据库里手改过的东西，下次重建会被冲掉。**所以这个数据库不是给人改的地方，是给人查的地方。** 要改回[第 7 章](07-错的怎么拦.md)那条路——改 JSON。

**二、文件名那一列上加了一个唯一索引。**

```python
conn.execute("CREATE UNIQUE INDEX idx_ledger_key ON ...")
```

**它做两件事**：查得快，以及**不许出现两行同名**。

同名意味着同一份单据被记了两次。**这在主线里不会发生**（[第 5 章](05-批量处理.md)那个设计），**但你把几个月的台账合起来装的时候就会发生**——那正是这一条该响的时候。

**三、列名全是中文，脚本里全部加了双引号。**

```python
def quoted(name):
    return '"' + str(name).replace('"', '""') + '"'
```

**SQL 里列名带中文、带空格、和关键字撞名，都要用双引号裹起来。** 不裹的话数据库会看不懂你在说哪一列。

### 查几句看看

```bash
python3 ~/ai/scripts/ledger_to_sqlite.py ~/ai/projects/invoice-ocr/ledger.csv \
  --ask 'SELECT "销售方名称", COUNT(*) FROM ledger GROUP BY "销售方名称"'
```

作用：**按销售方数一数，各有几张票。** `GROUP BY` 是按某一列归堆，`COUNT(*)` 是数每一堆有几行。

再来两句常用的：

```bash
--ask 'SELECT "文件名", "价税合计" FROM ledger ORDER BY CAST("价税合计" AS REAL) DESC LIMIT 10'
```

作用：**金额最大的十张。** `CAST(... AS REAL)` 是**把文本临时当成数来排序**——列是文本存的，不转的话 `900` 会排在 `1000` 前面（文本比大小是一位一位比的）。

```bash
--ask 'SELECT "开票日期", COUNT(*) FROM ledger GROUP BY substr("开票日期", 1, 7)'
```

作用：**按月份数。** `substr(..., 1, 7)` 取前 7 个字符，`2026-07-18` 取出来是 `2026-07`。

> **注意最后这一句只对 `2026-07-18` 那种写法成立。** 主线的提示词要求日期照票面原样抄（[第 3 章](03-定义字段.md)），票面写的是 `2026年07月18日` 的话，前 7 个字符是 `2026年07`——**照样能归堆，但字符数要重新数一遍**。**这就是“照原样抄”的代价，它换来的是可回溯**，两边各有各的道理。

### MySQL 和 PostgreSQL

**客户那边已经有一个数据库的话，多半是这两个之一。**

**逻辑和上面一模一样**：建一张表、把每一行插进去、按条件查。**不一样的只有两件事：**

- **连法不一样。** SQLite 是打开一个文件，这两个是连一个地址——要主机名、端口、库名、账户和口令。**Python 那边也要另装一个连接用的包**（`PyMySQL`、`psycopg` 这一类，名字随版本变，以它们自己的文档为准）；
- **建表语句的写法有出入。** 列的类型名、加索引的写法、引号用哪一种，**三种数据库各有各的脾气**。

**这一章不展开那两条路，理由很实在：** 那是客户已有的系统，**账户口令、网络、备份、谁能写谁只能读，全部是客户那边的规矩**，不是你在自己机器上能定的事。

> **这一节要落在一句话上**：**客户已有的数据库，连接信息由客户那边给，而且建表和写入要客户点头。** 你把一张表塞进别人的生产库，出了事说不清楚。**做法是先给一个 SQL 文件或者一个 CSV，让他们那边的人执行。**

## 三、给别的系统

**第三条路的场合是这样的**：客户有一套自己的软件，它要来取这批数据，**而且要的是最新的**。

### 路一：导出成对方要的格式

**先试这一条。** 大多数业务软件都有导入功能，**问清楚它要什么格式，导成那个格式就行。**

三种最常见的要求：

- **一个特定列顺序的 CSV** —— 上面那张 `COLUMN_MAP` 就够了；
- **一个 xlsx 模板** —— 同上；
- **一个 JSON 文件** —— 一句话的事：

```bash
python3 -c 'import csv,json,sys;print(json.dumps(list(csv.DictReader(open(sys.argv[1],encoding="utf-8-sig"))),ensure_ascii=False,indent=2))' \
  ~/ai/projects/invoice-ocr/ledger.csv > ~/ai/projects/invoice-ocr/ledger.json
```

作用：**把台账 CSV 转成一个 JSON 文件。** `csv.DictReader` 把每一行读成一个字典（列名对值），`json.dumps` 把整个列表打成 JSON，`ensure_ascii=False` 保住中文（[第 4 章](04-单张跑通.md)那一条）。

**导出文件这条路能覆盖八成场合，而且它最省事**——没有服务要维护，没有端口要开，没有认证要做。

### 路二：给一个能取数的接口

**只有一种情况才走这条路**：对方的系统要自己来拿，**而且要的是随时最新的**。

新建 `~/ai/scripts/ledger_api.py`，**照抄**：

```python
#!/usr/bin/env python3
# ledger_api.py —— 让别的程序能来取台账，一个最小的只读接口
# 用法：python3 ~/ai/scripts/ledger_api.py ~/ai/projects/invoice-ocr/ledger.csv
# 只用 Python 自带的东西。默认只听本机，要给内网别的机器用见正文那一节。

import argparse
import csv
import json
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer
from pathlib import Path
from urllib.parse import parse_qs, urlparse

LEDGER_PATH = None
PAGE_LIMIT = 500


def load_ledger():
    """每次请求都重读一遍台账文件。台账一天才变几次，重读的代价可以忽略。"""
    with LEDGER_PATH.open("r", newline="", encoding="utf-8-sig") as handle:
        return list(csv.DictReader(handle))


def pick_number(query, name, fallback):
    """从网址后面那串参数里取一个数，取不到就用默认值。"""
    try:
        return max(0, int(query.get(name, [fallback])[-1]))
    except (TypeError, ValueError):
        return fallback


def fix_path(raw):
    """请求行是按 latin-1 读进来的，网址里直接写中文的话要先掰回 UTF-8。"""
    try:
        return raw.encode("latin-1").decode("utf-8")
    except (UnicodeEncodeError, UnicodeDecodeError):
        return raw


class Handler(BaseHTTPRequestHandler):

    server_version = "ledger-api"

    def do_GET(self):
        parsed = urlparse(fix_path(self.path))
        if parsed.path.rstrip("/") == "/health":
            self.reply(200, {"状态": "在"})
            return
        if parsed.path.rstrip("/") != "/ledger":
            self.reply(404, {"错误": "这个接口只有 /ledger 和 /health 两条路"})
            return
        try:
            records = load_ledger()
        except OSError as error:
            self.reply(500, {"错误": "读不了台账：" + str(error)})
            return

        query = parse_qs(parsed.query)
        for name, values in query.items():
            if name in ("limit", "offset"):
                continue
            wanted = values[-1]
            records = [
                row for row in records
                if wanted in str(row.get(name) or "")
            ]

        offset = pick_number(query, "offset", 0)
        limit = min(pick_number(query, "limit", 100), PAGE_LIMIT)
        page = records[offset:offset + limit]
        self.reply(200, {
            "总数": len(records),
            "本次": len(page),
            "起点": offset,
            "数据": page,
        })

    def reply(self, code, payload):
        body = json.dumps(payload, ensure_ascii=False, indent=2).encode("utf-8")
        self.send_response(code)
        self.send_header("Content-Type", "application/json; charset=utf-8")
        self.send_header("Content-Length", str(len(body)))
        self.end_headers()
        self.wfile.write(body)

    def log_message(self, fmt, *args):
        print("%s %s" % (self.address_string(), fmt % args), flush=True)


def main():
    global LEDGER_PATH
    parser = argparse.ArgumentParser(description="一个只读的台账接口")
    parser.add_argument("csvfile", help="第 5 章那张 ledger.csv")
    parser.add_argument("--host", default="127.0.0.1", help="听哪个地址，默认只听本机")
    parser.add_argument("--port", type=int, default=8099, help="听哪个端口")
    args = parser.parse_args()

    LEDGER_PATH = Path(args.csvfile).expanduser()
    if not LEDGER_PATH.is_file():
        raise SystemExit("找不到这个文件：" + str(LEDGER_PATH))

    server = ThreadingHTTPServer((args.host, args.port), Handler)
    print("台账接口起来了：http://%s:%d/ledger" % (args.host, args.port))
    print("按 Ctrl+C 停掉。")
    try:
        server.serve_forever()
    except KeyboardInterrupt:
        print("")
        print("停了。")
    finally:
        server.server_close()


if __name__ == "__main__":
    main()
```


作用：**把销售方名称里含“白鹭”两个字的挑出来，最多给五条。** 列名就是台账的表头，**含哪几个字就算命中，不用写全**。

### 这个接口有三条边界，要说在前面

**一、它是只读的。** 只有 `GET`，没有任何往里写的路。**对方读得到，改不了。**

> **`fix_path` 那个函数是这个脚本里唯一一处不明显的地方。** Python 自带的这个小服务器**把请求的网址按 latin-1 读进来**，网址里直接写了中文列名的话，读到的是一串乱码。那三行把它掰回 UTF-8。**网址里的中文本来就该转义成 `%e7%99%bd` 那种写法**，转义过的不受影响；这三行管的是没转义、直接把汉字打在网址里的那一种。

**二、它默认只听本机。**

```python
parser.add_argument("--host", default="127.0.0.1", help="听哪个地址，默认只听本机")
```

**`127.0.0.1` 的意思是只有这台机器上的程序连得上**（[第 6 卷第 8 章](../06-本地模型/08-局域网API.md)那一节讲过同一件事）。要给内网别的机器用，把它改成 `0.0.0.0`——**但改之前先读第三条。**

**三、它没有任何认证。**

**这是最要紧的一条。** 改成 `0.0.0.0` 之后，**同一个内网里任何一台机器都能把整张台账拉走**，不需要账户、不需要口令。

台账里是什么东西？**客户的每一笔往来单位和金额。**

**所以这条路有三个前提**，缺一个都不要开：

- **只在客户内网里开**，不要往公网上放；
- **防火墙上只放行对方那台机器**（[第 14 卷](../14-运维安全/README.md)）；
- **认证和 HTTPS 是另一件事**，怎么加在[第 10 卷](../10-产品化/README.md)和[第 14 卷](../14-运维安全/README.md)。**这一章给的是最小可用的形状，不是能直接交付的成品。**

> **一句话记住它**：**这个接口能拿来演示、能拿来在内网里对接，不能拿来当产品交付。** 交付要走[第 10 卷](../10-产品化/README.md)那一整套。

### 要让它一直跑着

**上面那个跑法，你一关窗口它就没了。** 要它开机自己起来，做法和[第 2 章](02-环境准备.md)那个 `ocr-vlm` 服务一样——写一个 systemd 服务文件。**[第 6 章](06-文件夹监测.md)最后那一节给过同样形状的例子，本章不重抄。**

## 对接为什么最容易超出报价

**这一节和技术无关，但它决定这一单赚不赚钱。**

**前十章那些活是可估的**：单据长什么样你看得见，跑多久你能测（第 13 章），错的怎么拦你有一套办法。

**对接不是。** 原因就一条：**客户的系统千奇百怪，而且你在报价的时候看不见它。**

### 四种把工期吃掉的情况

**一、那套软件没有导入功能。** 官网上写着有，装的那个版本没有，或者要买另一个模块。

**二、有导入功能，但它要的格式很怪。** 固定列宽的文本、某个年代的 Excel 格式、一种只有他们厂商知道的编码。

**三、客户那边没有人能回答问题。** 系统是几年前一个走掉的同事做的，或者是外面一家公司做的，**那家公司现在收费才肯说话**。

**四、字段对不上，而且对不上的那几格票面上没有。** 上面第二个问题里那一类——他要“部门”“项目号”，**票上没有**。这时候要谈的是“这几列谁来填”，**而这件事根本不是技术问题**。

**这四种里，第三种最费时间，第四种最伤感情。**

### 做法：把对接单独列一项

**报价的时候，不要把对接摊进“OCR 单据处理”那个总价里。**

**单独列一行，而且写清楚它包含什么、不包含什么。**

```text
包含：把台账导出成 CSV、xlsx 或者一份 JSON，交给客户
包含：按客户提供的列名对照表调整列名与顺序，一次
不包含：客户方系统的导入调试
不包含：客户方系统的账户、权限、网络与防火墙调整
不包含：票面上没有的字段（部门、项目号、凭证号一类）的补录
超出部分：按次或者按人天另计
```

**上面这段是一个起点，不是合同文本。** 具体怎么写在[第 11 卷](../11-客户与报价/README.md)（那一卷有专门的一章讲接口费），合同文本的事在[第 13 卷](../13-项目交付/README.md)。

### 一句可以照念的话

> “数据出到 CSV 和 Excel 这一段是包含的。要进你们那套系统，我得先看一眼它的导入功能长什么样，看完我单独给你报这一项。你们那边谁最熟这套系统？”

**最后那一句是这段话的正主。** 它把“找到能回答问题的人”这件事，**放在报价之前，而不是开工之后。**

## 事实来源和版本日期

- **`openpyxl` 的用法**（`Workbook`、`Font`、`PatternFill`、`Alignment`、`get_column_letter`、`freeze_panes`、`auto_filter.ref`、`number_format` 的写法）：**本项目未在这台设备上验证，需要核验**，事实状态 `candidate`。[第 5 章](05-批量处理.md)已就“用 `openpyxl` 直接写 xlsx”标注过同一条并把它留到本章。**该包的接口随其版本变化，以它自己的文档为准**；
- **Excel 把长数字串显示成科学计数法并丢失末几位**：属电子表格软件的通用行为，**各版本 Excel 与 LibreOffice 的表现可能不同，需要核验**。正文因此要求发票号码不进 `NUMBER_COLUMNS`；
- **Python 标准库里 `sqlite3`、`csv`、`json`、`argparse`、`pathlib`、`http.server`、`urllib.parse` 的行为**，以及 SQL 里 `SELECT`、`GROUP BY`、`ORDER BY`、`CAST`、`substr`、`CREATE UNIQUE INDEX` 与双引号裹标识符的写法：属通用行为与 SQLite 的通用语法，**未针对本项目设备单独实测**；
- **`python3 -m pip install --user` 在新版 Ubuntu 上可能被 externally managed environment 拦下**：属发行版行为，**本项目未在这台设备上核对，需要核验**。正文给的替代路径是[第 6 卷第 8 章](../06-本地模型/08-局域网API.md)那个虚拟环境；
- **MySQL 与 PostgreSQL 的连接方式、所需 Python 包的名字与建表语句差异**：**本项目未验证，需要核验**，事实状态 `candidate`。**正文只写“逻辑一样、连法不同”，不给任何具体写法与包名版本**；
- **`ledger_api.py` 这个接口没有认证、没有 HTTPS、默认只听本机**：这是本章给出的形状本身的性质，不依赖任何外部资料。**认证、HTTPS、防火墙的做法在[第 10 卷](../10-产品化/README.md)与[第 14 卷](../14-运维安全/README.md)，本章不给**；
