# AMD Ryzen AI Max+ 395 本地 AI 工作站

从开箱、安装和本地模型开始，完成一个可以演示、报价、交付和维护的本地 AI 产品。

Roland Wayne 著。本项目免费开源，欢迎在线或本地阅读与分享。

当前版本：`0.2.1`。主教材 16 卷 215 章约 100 万字，另有 6 套产品交付手册和 14 个分级实验。

## 从这里开始

1. 先读[第 0 卷 使用说明](book/00-使用说明/README.md)，它说明这台设备是什么、哪些人适合用、这套资料怎么用；
2. 按[主教材目录](book/README.md)从第 1 卷往下做，每一卷都有完成结果和检查点；
3. 只想先看这台设备能卖什么的，去[产品交付手册](playbooks/README.md)。

## 这套资料写给谁

主要读者是第一次使用 Linux 和本地 AI 工作站的人。读者可以只会接电源、显示器、键盘和鼠标。

本项目不把“读完”当作完成。读者需要按照检查表完成安装、部署、产品演示、报价、交付和维护。

## 从 0 到 100

| 进度 | 完成结果 |
| --- | --- |
| 0 | 认识设备、接口和随机器材 |
| 10 | 开机、安装 Ubuntu、连接网络 |
| 20 | 管理文件、用户、软件和服务 |
| 30 | 远程管理、备份和恢复设备 |
| 40 | 完成 BIOS、UMA、驱动和 ROCm 检查 |
| 50 | 运行本地模型、网页界面和内部 API |
| 60 | 完成知识库、OCR 或自动化实验 |
| 70 | 把实验整理成有输入、输出和验收标准的产品 |
| 80 | 完成客户需求确认、演示和报价 |
| 90 | 完成一次小范围交付和验收 |
| 100 | 建立监控、维护、续费和第二次销售流程 |

## 先做哪套产品

建议顺序：

1. 预装本地 AI 工作站；
2. 安装与运维支持；
3. 企业私有知识库；
4. OCR 和文档抽取；
5. 企业内部 AI API；
6. Agent 和 RPA 工作流。

这些方向已有不同程度的公开产品、交付或需求证据。它们不等于普通买家已经获得确定收入。证据等级和推导边界见 [`evidence/README.md`](evidence/README.md)。
