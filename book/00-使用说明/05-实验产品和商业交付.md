# 05　实验、产品和商业交付

## 完成结果

能区分实验、产品和商业交付，知道它们各自的完成标准，知道证据和收入之间的关系。

## 开始前需要准备什么

只需要读，不需要操作。读过[第 4 章](04-0到100学习路线.md)会更好理解，因为本章用到那里的进度编号。

## 新词

**实验**（labs）：按固定步骤验证某个功能是否能在设备上运行，使用测试数据，有停止和恢复方法，有验收标准。实验完成不等于产品完成。

**产品化**：把实验整理成可以演示、安装、验收和恢复的交付形式，有文档，有验收标准，客户可以按文档独立操作。

**商业交付**：有真实客户、明确的输入和输出、双方同意的验收标准、约定好的维护范围的项目。它不是实验，也不是演示。

**RAG**（Retrieval-Augmented Generation，检索增强生成）：先在文档里检索相关段落，再把这些段落作为上下文提供给模型，让模型回答时可以引用具体来源，而不是只凭记忆生成内容。

**OCR**（Optical Character Recognition，光学字符识别）：把图片、扫描件或 PDF 中的文字提取成可以编辑的文本格式。

**Agent**：按照给定的任务和权限范围，自主决定使用哪些工具来完成任务的程序。它不等于简单脚本，也不是能自主判断所有边界的通用系统。

**RPA**（Robotic Process Automation，机器人流程自动化）：通过程序模拟人的操作（如点击、填表、复制粘贴）完成重复的数字流程，不需要修改现有系统。

**Docker**：把程序及其运行环境打包在一起的工具，让同一个程序在不同设备上运行时有一致的环境。

## 实验是怎样组织的

实验按等级编号，等级号和[第 4 章](04-0到100学习路线.md)的进度节点一一对应。等级 60 的实验就是进度 60 要完成的操作，两套编号说的是同一件事，不用分开记。

每个实验写明准备条件、操作步骤、正常结果、错误处理方法、停止方法、恢复方法、验收标准和可以出售的结果。实验使用测试数据，不提交真实客户资料、密钥或内网地址。

当前已有实验见[实验目录](../../labs/README.md)。

## 6 套商业产品方向

本教材整理了 6 套围绕这台设备的商业产品方向，来自公开市场、服务商案例和需求材料：

| 产品 | 典型客户 |
| --- | --- |
| 预装本地 AI 工作站 | 没有本地 AI 运维人员的小团队 |
| 企业私有知识库 | 律所、会计、咨询、研究团队 |
| OCR 与文档抽取 | 财务、物流、合同和档案部门 |
| 企业内部 AI API | 有现有软件和云端调用的团队 |
| Agent 与 RPA | 有重复后台流程的团队 |
| 安装与运维 | 已购买 AI 工作站的用户 |

每套产品手册包含：客户画像、问题描述、最小演示方案、输入和输出格式、系统架构、安装步骤、验收标准、报价依据、交接方法、售后范围和回退计划。详情见[产品手册目录](../../playbooks/README.md)。

## 从实验到产品的区别

实验和产品的主要区别是对象和标准：

- **实验**：自己用测试数据验证功能是否能跑通。结果给自己看，用自己的设备，数据是虚构的或公开的。
- **产品**：客户使用真实数据，结果需要让客户满意，客户要能验收并判断是否符合要求。

同一个功能，从实验变成产品，通常需要完成以下工作：

1. 写安装和使用文档，客户可以按文档操作，不需要问你每一步怎么做；
2. 定义输入格式和输出格式，客户知道提交什么、得到什么；
3. 写出验收标准，双方可以用同一套标准检查是否完成；
4. 准备恢复方法，出问题时有明确的回退步骤，不用等你来现场处理；
5. 确认维护范围，什么在服务合同内，什么不在，边界清楚。

## 商业交付不是收入保证

本教材说明这 6 套产品有哪些公开市场证据，但不承诺以下内容：

- 按照教材完成实验后就可以获得收入。
- 这些产品在你的市场或客户群体中一定有需求。
- 某个报价区间一定能成交。

收入需要真实客户、真实交付和双方确认的验收标准。完成实验证明功能可以运行，不证明有人愿意为它付钱。

## 正常结果

读完本章，你能说出实验和产品的具体区别，并知道教材里的商业内容不是收入承诺。

## 看到不同结果怎么办

**实验目录里还没有你想找的那一级实验**：实验按卷推进，后面的等级会陆续补齐。当前有哪些，以[实验目录](../../labs/README.md)实际列出的为准，目录里没有的就是还没写。

**你按实验跑通了功能，但客户不接受**：实验的验收标准是自己设的，产品的验收标准要和客户一起定。回到本章“从实验到产品的区别”，逐条对照缺哪一项。

**你看到某套产品有公开报价，想直接照搬**：公开报价是别人的挂牌价，不是你的成交价。第 6 章讲这两者的区别。

**你不确定某个方向值不值得做**：先看[证据库](../../evidence/README.md)里这一类材料的等级，再决定投入多少时间，不要只凭一页报价页判断。
