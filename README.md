## 关于本书

这本书写给第一次使用 Mini PC 的人。

全书按主题分章。每章只处理一个问题。章内再按 section 展开。所有完整案例集中放在第 6 章，不分散到其他章节。

## 写作规则

- 一章只讲一个主题。
- 案例只放在第 6 章。
- 其他章节可以解释方法，但不展开完整案例。
- 每个案例写清输入、过程、结果、失败、恢复和证据状态。
- 性能、成本和收入都绑定具体设备和运行记录。
- Markdown 是正文来源，PDF 后续生成。
