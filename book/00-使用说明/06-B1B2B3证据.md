# 06　B1、B2、B3 证据

## 完成结果

能读懂本教材中的证据分级标记，知道各级证据说明什么、不说明什么。

## 开始前需要准备什么

只需要读，不需要操作。

## 新词

**证据分级**：按来源类型和可信程度对商业材料分类。不同分级支持不同强度的结论，不可以混用。

**挂牌价**：服务商或电商平台公开列出的价格，是公开报价，不等于实际成交价，也不等于你的客户会接受这个价格。

**项目预算**：采购方在招标或询价时公布的预算上限或参考金额。不等于中标价，也不等于该项目一定会采购。

**中标价**：采购项目最终成交的合同金额。需要有合同文件或公开公告支持，不能从挂牌价或预算推导。

**服务商自述**：服务商在自己的网站、案例页面或营销材料中发布的内容。是一种来源，但不等于独立的第三方客户确认。

**邻近案例**：使用型号相近但不完全相同硬件（如其他品牌的高内存 AI 工作站）完成的案例。不能直接等同于 Max395 精确案例。

## 证据分级说明

本教材和证据库使用以下标记：

| 标记 | 含义 | 例子 |
| --- | --- | --- |
| H | 精确 Max395 设备的购买、交付或实际使用记录 | Max395 设备的发货截图、使用记录 |
| B1 | 有产品、服务、价格、购买或咨询入口 | 服务商的本地 AI 部署报价页面 |
| B2 | 有生产使用、客户部署或服务商第一方交付说明 | 服务商描述了具体交付流程的案例页面 |
| B3 | 有采购需求、外包询价或公开预算 | 外包平台上寻找本地模型基础设施专家的发包，或企业公开的知识库采购信息 |
| D | 从硬件能力和邻近市场材料推导的可售产品 | 市场上已有本地 RAG 产品和企业部署，推导出私有知识库可以设计成一套产品，同时列明引用准确率等仍需本地验证的项目 |
| X | 不采用或需要降级的材料 | 无法核验来源的截图，或有误导性表述的页面 |

## 各级证据说明什么

**H 级**：说明这台 Max395 设备在对应场景有真实购买或使用记录，来源可以直接对应到这款硬件。

**B1 级**：说明这类服务在市场上有人在卖、有挂牌价格、有购买入口。它不说明某个具体交付已经完成，也不说明普通买家能以该价格成交，更不说明你可以以该价格成交。

**B2 级**：说明这类服务有人实际交付过，来源是服务商的第一方描述。它不等于独立的客户确认（客户自己说的），也不等于可以直接复制的典型案例。服务商描述自己的交付不代表交付结果已经经过客户独立核验。

**B3 级**：说明市场上有组织在寻找这类服务。当前材料主要是外包平台的公开发包、社区用户公布的预算和企业采购信息。发包和预算说明有人认为这件事值得花钱，不说明采购已经成立，也不说明这笔钱会流向使用 Max395 的个人或小团队。

**D 级**：这一级不是找到的材料，是推导出来的。推导链条是：设备能完成某项任务，市场上有人在卖相近方案，把能力限制成明确的输入和输出，建立测试和验收，再按设备、项目、工作量或维护周期收费。每条推导都同时列出仍需本地验证的项目，比如私有知识库这条要验证引用准确率、用户数和客户数据怎么接入。推导链的最后一步要靠本项目自己的试点、报价、交付和客户确认补上，材料本身补不上。

**X 级**：材料被排除，不进入正文。通常是因为来源无法核验，或表述有误导性。

当前证据库的分类和来源见[证据库目录](../../evidence/README.md)。

## 常见误读

**价格不混用。** 挂牌价、项目预算、中标价和实际付款是四种不同的数字，含义和来源不同，不能用来互相支持同一个结论。看到一个数字先问它属于哪一种。

**邻近案例不等于 Max395 精确案例。** 用其他硬件完成的案例，不能直接写成 Max395 也能完成同等任务的证据，需要单独核验。

**服务商自述不等于客户确认。** 服务商说自己完成了某个交付，不等于客户也这么说，也不等于该交付可以重复。

## 事实状态标记

教材和证据库中，每条重要事实都标注状态：

| 状态 | 含义 |
| --- | --- |
| `local_checked` | 在指定设备和版本上完成了本地操作检查 |
| `official_source` | 有官方文档支持 |
| `case_material` | 来自具体案例，只适用于该案例范围 |
| `candidate` | 还没有完成验证 |
| `human_accepted` | 作者已确认可以作为对外内容 |
| `published` | 已在真实公开渠道核验 |

`local_checked` 不等于 `human_accepted`。在设备上跑通了某个步骤，不自动意味着这个结果可以作为对外声明使用。`human_accepted` 不等于 `published`，确认内容可以对外不等于已经发布。

## 当前材料的边界

截至本教材编写时，现有材料足以支持 6 套商业产品的设计框架，但公开材料未形成“普通买家使用 Max395 提供某项服务并取得可独立核验收入”的完整证据链。这一判断见[证据库](../../evidence/README.md)，后续随材料更新而调整。

## 正常结果

读完本章，你能看懂教材中的 B1、B2、B3 和 D 标记，并能说出为什么不能把挂牌价直接用来预测成交价。

## 看到不同结果怎么办

**你在正文里看到一个数字，但没写等级**：按未核验处理，不要拿它做决策。可以到[证据库](../../evidence/README.md)查这条材料的分类，查不到就是还没有归档。

**你自己找到一条材料，不知道算哪一级**：先问它是谁发布的。服务商自己发的最高到 B2，采购方或发包方发的是 B3，只有能对应到 Max395 实际购买或使用的才是 H。判断不了就先放 X，不进正文。

**你看到的页面内容和教材写的不一致**：公开页面会改，价格和服务范围随时变。以你访问当天看到的为准，并把访问日期记下来。

**你想引用一条社区帖子或截图**：能不能核验来源是分级的前提。无法核验来源的截图按 X 处理。
