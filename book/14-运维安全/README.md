# 14　运维安全

完成结果：一套能出示记录的运维流程，包含巡检记录、备份演练记录、月度报告。客户问「你们怎么维护」时，提供这些记录。

对应学习路线的进度 100。

## 运维是月费产品

这一卷不是操作手册，写的是月费产品交付什么。客户每月付的钱买四样：

有人盯着、坏了有人管、数据有备份、定期有报告。

前三样在平安无事的月份客户感知不到，第四样是它们的出口。[第 1 章](01-维护费卖什么.md)写清了平安无事的月份客户想少付钱，出事的月份客户觉得你没做好，解法是让平安无事这件事被看见。

## 三条硬规矩

告警发给自己，不发给客户。 客户看到告警会恐慌，你要的是在他发现之前解决。[第 2 章](02-盯着.md)。

演练过的备份才算备份。 每季度真的还原一个文件、记下耗时、写一页给客户。这一页是四样里最有说服力的。[第 3 章](03-备份.md)。

先恢复服务，再找原因。 给客户的话里，「多久能好」换成「多久再联系」，约了就要打。[第 7 章](07-出事了.md)。

## 这一卷不给数字

不写月费多少、响应几小时、巡检几次、一个人能维护几台。这些都由你和客户约定，并且要在说明书、验收单、合同三处一致。正文里出现的数字都是虚构示例，不是建议值。

引用的市场月费参照逐条标了证据等级，全部是服务商的报价页，没有一条有打款记录，也没有一条是这台机器上的。人民币区间引[第 11 卷第 5 章](../11-客户与报价/05-报价.md)，标注是估算。
