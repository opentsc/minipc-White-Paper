# 13　项目交付

**完成结果**：跟着一次完整交付的全记录走完自己的第一单，手上有进场信息表、交接单和项目复盘表。

对应学习路线的进度 90。

## 这一卷是一个案例

整卷不是交付方法论，是**一次交付的全记录**：一家 20 人的虚构律所买合同库，50 份旧合同起步，从签约那天写到尾款到账、第二单开口。八章就是这一单的八个阶段，每章配一份可打印的表。

| 编号 | 标题 | 这一章的阶段 |
| --- | --- | --- |
| 01 | [这一单是什么](01-这一单是什么.md) | 客户档案、合同要点、三个固定、付款节点 |
| 02 | [进场之前](02-进场之前.md) | 把该问的问完，五组三十来格 |
| 03 | [装机](03-装机.md) | 母盘写回、出厂检查、运到现场接上 |
| 04 | [灌数据跑试点](04-灌数据跑试点.md) | 真实文档进库，试点两周 |
| 05 | [教会他们用](05-教会他们用.md) | 半天培训，只教用不教修 |
| 06 | [验收签字](06-验收签字.md) | 当着客户跑完，签字收尾款 |
| 07 | [交接与售后边界](07-交接与售后边界.md) | 交九样、划边界、谈月维护 |
| 08 | [这单之后](08-这单之后.md) | 复盘，决定第二单调什么 |

## 三处值得先看

**[第 2 章](02-进场之前.md)的进场信息表。** 每一格问不清，进场当天就要停工等。这一单里「扫描件有几份」先猜 7 份、现场数出 18 份，工期就是被这一格决定的。

**[第 6 章](06-验收签字.md)两道不合格题的处理。** 一道当场剔除，因为答案本来就不在给的文件里；另一道是真不合格，**但当天不改，约下周重测**——开场说过「中间我不动任何设置」，改完前面十三道全废。记分时那道题「没瞎编」照实勾，把「漏了」记成「瞎编」，整张表的可信度就垮了。

**[第 8 章](08-这单之后.md)的复盘偏差。** 报价时估 42 小时，实际 67.5 小时，超了六成。七处偏差逐条写了原因，其中「重测与第二次签字」这一格报价时压根没有。每小时的实际收入从估的约 505 元落到约 311 元。这一栏是全卷最有价值的东西。
